# 営業スライド作成キット 📊

営業用のプレゼン資料を**かんたん・きれい・速く**作るためのセットアップです。
Markdown（マークダウン）という簡単な書き方で文章を書くだけで、プロっぽいスライドが自動で完成します。

---

## 📁 何が入っているか

| フォルダ／ファイル | 中身 |
|---|---|
| `templates/営業スライド_テンプレート.md` | 空のテンプレート（これをコピーして使う） |
| `slides/サンプル_提案資料.md` | 記入済みのお手本サンプル |
| `themes/sales.css` | スライドの見た目（デザイン） |
| `README.md` | この説明書 |

---

## 🚀 いちばんかんたんな使い方（おすすめ）

**むずかしい操作は不要です。チャットで私（Claude）に頼むだけ。**

例えばこう言ってください：

> 「新しい提案資料を作って。商品は◯◯で、相手は△△業界の会社です」
>
> 「サンプル資料の料金プランを書き換えて」
>
> 「この内容でPDFにして」

そうすると私が、スライドの作成・修正・PDF化までやって、GitHubに保存します。

---

## ✍️ 自分で中身を書く場合

1. `templates/営業スライド_テンプレート.md` をコピーして `slides/` の中に置く
2. `◯◯` や `△△` の部分を実際の内容に書き換える
3. 「保存して」と私に伝える（GitHubに保存されます）

### 書き方のミニ知識
- `#` … 大きな見出し
- `##` … 中くらいの見出し
- `-` … 箇条書き（・のリスト）
- `**文字**` … 文字を**強調**（オレンジ色になる）
- `---`（ハイフン3つ）… ここでスライドが次のページに変わる

---

## 🖼️ スライド（PDF / PowerPoint）に変換する

文章（Markdown）を、実際に見せるスライド形式に変換できます。
私に「PDFにして」「PowerPointにして」と頼めば実行しますが、自分で行う場合は以下のコマンドです。

```bash
# 準備（最初の1回だけ）
npm install

# PDFを作る
npx marp slides/サンプル_提案資料.md --theme themes/sales.css -o output/提案資料.pdf

# PowerPoint（.pptx）を作る
npx marp slides/サンプル_提案資料.md --theme themes/sales.css --pptx -o output/提案資料.pptx
```

## 💡 ポイント

- **テンプレートを使い回す**ほど、作成がどんどん速くなります。
- デザイン（色・フォント）を会社のカラーに変えたい場合は、私に「テーマの色を緑にして」などと頼んでください。
- 作ったものは push（保存）すれば GitHub に残るので、消える心配はありません。
