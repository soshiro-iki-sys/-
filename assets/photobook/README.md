# 参考画像（撮影完成イメージ）の置き場

`slides/build/build_photobook.py` は、このフォルダの **`<カット番号>.png` / `.jpg`** を
撮影指示書の写真枠に自動で差し込みます。

```
A-1.png  A-2.png  A-3.png  A-4.png
B-1.png  ...  C-1.png  ...  L-3.png
```

- **ファイル名＝カット番号**（半角ハイフン）。大文字小文字はそのまま
- 拡張子は `.png` `.jpg` `.jpeg` のいずれか
- **全部そろっていなくてよい。** 無いカットはプレースホルダーのまま出力される
- 画像があるページは、写真下のキャプションが「撮影前・参考枠」→
  **「AI生成・撮影参考」**（見本と同じ文言）に自動で切り替わる

## サイズ

写真枠は **6.15 × 4.22 in（アスペクト比 1.457 ≒ 3:2 横位置）**。
比率が違う画像は**中央を基準に自動トリミング**されるので、多少ずれていても入ります。
推奨は 3:2 の横長（例 1536×1024）。

## プロンプト

各カットの生成プロンプトは [docs/画像生成プロンプト_撮影指示書.md](../../docs/画像生成プロンプト_撮影指示書.md)。
`python3.13 slides/build/make_prompts.py` で `photobook_cuts.py` から再生成できます。

## ビルド

```
python3.13 slides/build/build_photobook.py
```

置き場を変えたいときは `PHOTOBOOK_ASSETS=<dir>` を指定します。
