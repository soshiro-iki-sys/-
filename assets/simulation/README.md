## 作り方

    pdftoppm -r 110 -png レポート.pdf s
    # s-1.png 〜 s-9.png を sim1.jpg 〜 sim9.jpg として保存（quality=88）

PDF から直接書き出しているので、フォント置換による崩れはない。
