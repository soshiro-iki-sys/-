# セミナー出席確認シート

太陽光・蓄電池セミナーの受付で使用する出席確認シート（A4縦・2ページ）です。

- 1ページ目：**午前の部**（受付 10:00～ ／ 講座 10:30～12:00）／ 申込 7名
- 2ページ目：**午後の部**（受付 13:00～ ／ 講座 13:30～15:00）／ 申込 4名

各ページの表は `No. / お名前 / お電話番号 / 人数 / 出席（□）` の構成で、
飛び入り参加用の空欄をそれぞれ 5 行ずつ設けています。
開催日・会場は当日記入できるよう空欄にしています。

## 生成方法

Word ファイル（`出席確認シート.docx`）はバイナリのためリポジトリには含めず、
生成スクリプトのみを管理しています。以下で再生成できます。

```bash
npm install docx
node docs/出席確認シート_生成スクリプト.js
```

## データについて

申込フォームの回答をもとに作成しています。反映時の判断は次のとおりです。

- 廣川克仁さんは 8/30・9/1 に 2 件の申込がありましたが、電話番号・メールアドレスが
  同一で同一人物のため、1 行にまとめています（午前の部 No.4）。
- 永井さん・タカノさんは電話、村上さんは FAX での申込分です。
