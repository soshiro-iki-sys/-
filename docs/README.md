## 商談の全体像（これだけは覚える）

```
       ▲ 契約までの4ステップ（下から積み上げる）
      ╱1╲     STEP4 金額訴求   自分でも払えそうな金額だと理解させる
     ╱ 2 ╲    STEP3 時期訴求   今導入するのがお得だと認識させる
    ╱  3  ╲   STEP2 必要性訴求 太陽光・蓄電池は必要だと思ってもらう
   ╱___4___╲  STEP1 聴く姿勢   この営業の話を聞きたいと思わせる
```

- 前準備（①）→ 聴く姿勢作り（②〜⑥）→ 必要性訴求（⑦〜⑫）→ 時期訴求（⑬〜⑮）→ 金額訴求（⑯〜⑳）
- ゴールは**その日の仮契約（即決）**。日をおいて△が〇になることは少ない
- 営業マン：お客様の発言比率は **6：4**、ラリー数は **30回**

### 経済メリット訴求パート（22枚）

必要性訴求パートの続き＝③経済メリット。アプローチブック p.20・p.21 と
エネがえる診断レポートの見せ方を扱う。設計は
[骨子_経済メリットパート.md](骨子_経済メリットパート.md)、
レポートの構成は [知識_シミュレーション.md](知識_シミュレーション.md)。

- **講義25分（18枚）＋ ロープレ30分 ＋ まとめ5分**。講師の講義を20〜30分に収める設計
- **基本方針は伝え方②**（電気代の減収分のみ）。ローンの話は後、**販売金額は最後**
- フレーミングの両面：**削減額は大きい単位／支払額は小さい単位**
- 合宿資料（購入＝価値÷価格／分割して伝える／✕金額◎安心感／信頼×比較）と
  第3回資料（③は決め手であって入り口ではない／伝え方①②／田中様ご夫婦）から要素を継承
- ビルドは `TRAINING_ASSETS=assets python3 slides/build/build_econ.py`
  （画像は `assets/approachbook/` と `assets/simulation/`）
