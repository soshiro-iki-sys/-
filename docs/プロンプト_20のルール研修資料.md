# 「20のルールポイント解説」研修資料 作成プロンプト

第2回〜第5回の研修資料を作るときに、そのまま貼って使うプロンプトです。
1回分ずつ作る想定なので、`【今回作る回】` の行だけ書き換えて使ってください。

# 研修の主題：セット販売（これが全回を貫く軸）

この研修は**太陽光と蓄電池をセットで売るための訓練**であって、
蓄電池単体（シングル販売）や太陽光単体の研修ではありません。以下を全ページで外さないこと。

- **太陽光と蓄電池は切り離さず、常にセットで話を進める**（営業ルール⑥の「2つの当然意識」②）

- 「蓄電池を売る」「太陽光を売る」という書き方をしない。**「スマートハウス（太陽光＋蓄電池）を導入いただく」**と書く

| ① | **シングル販売は「価格市場」に移行していく** | 導入期→成長期→成熟期と進むにつれ、成約の決め手は「実績」→「価格」→「紹介」へ移る。D2Cモデルの参入で価格崩壊が起きている地域もある |
| ② | **セット販売は「空白市場」である** | 太陽光設置済み約240万（総世帯の4％）に販売店が集中する“いびつな構造”。持家は約3,000万（52％）、総世帯は約5,700万ある |
| ③ | **経済合理性がセットにある** | 売電単価（15円）＜買電単価（30円）。売るより貯めて使う方が得なので、太陽光だけでは最適化できない |
| ④ | **設備面でもセットが前提になった** | ハイブリッドパワコンが広く普及（1台で制御でき変換効率も高い）。ZEH住宅の要件に蓄電池が必須になる基準案が提出されている |
| ⑤ | **セット販売の成功事例が出ている** | 陽幸＝セット比率99％で月販110台／日本ライフサポート＝月販90台／プレジャーハウス＝正社員7名で月販30台 |

# 2時間の時間配分（毎回この型）

| 時間 | パート | 枚数の目安 |
|---|---|---|
| 0:00-0:10 | オープニング（表紙・本日のゴール・アジェンダ・前回の振り返り） | 4枚 |
| 0:10-0:20 | 全体像の再確認（契約までの4ステップ＋20のルール表で今日の範囲を色で示す） | 2枚 |

# 1ルールあたりのスライドの型（必ずこの2枚1組）

**1枚目：ルールの理解**

- 見出し（▌）＝ その回の章名（例：`聴く姿勢作り`）
- ページ内タイトル（24pt太字）＝ `ルール①：商談テーブルの確認`
- その下に赤字1行で **POINT**（ナレッジの「POINT」をそのまま使う）
- 左：**考え方**（なぜこのルールがあるのか。ナレッジの「考え方・事例」を3〜5行に圧縮）
- 右：図解・表・写真のいずれか（テキストだけの枚は作らない）

**2枚目：現場での使い方**

- 見出しは1枚目と同じ
- `＜具体的なトーク＞` としてセリフを「」で列挙（ナレッジの逐語をそのまま使う）
- よくあるネガと切り返しがある場合は2列の表にする
- 最下部に**この1枚で持ち帰ってほしい一文**を赤字か黄マーカーで置く

# ワーク／ロープレのページ

各回に必ず入れる。以下の型で。

- **ワーク指示ページ**：やること／時間／ペア構成／使う資料を箇条書き
- **ロープレ設定ページ**：顧客設定（家族構成・築年数・月々の電気代・断り文句）を表で提示
- **チェックシートページ**：その回で扱ったルールを行にして、○△×で自己採点できる表
  - 第2回なら「①〜⑨のうち何個できたか」
  - 発言比率6:4・ラリー数30回も評価項目に入れる

# 各回の固有の作り込み

- **第2回**：冒頭に上記「セットで売るべき根拠」を1〜2枚。ルール②の「自社ストーリー5段構成（企業理念／創業ヒストリー／コダワリ／サービス内容／営業マンの信条）」は**受講者が自社版を書き込むワークシートページ**にする。ルール③の3つのオープンクエスチョンは声に出す練習まで。ルール⑤⑥は**「太陽光は当たり前」→「今は蓄電池とのセットが標準」**という接続がヤマなので、ここに1枚多く割く。
- **第3回**：災害トークは「第三者話法でしか伝えない」「時間をかけずサラッと」が肝なので、**やりすぎ例／適切な例の対比ページ**を入れる。ルール⑫の「1日の電気の流れ」は**太陽光で創る→蓄電池に貯める→夜に使う**という**セットでないと成立しないサイクル**として図解し、そのままシミュレーションへの受け渡しトークにつなぐ。
- **第4回**：金額の伝え方（1日あたり→1か月あたり→総額）のフレーミングを**3枚に分けて段階的に**見せる。⑯の「総額を聞かれたときの逃げ方3つ」は表で。⑰は**太陽光の設置容量を先に決め、蓄電池はその1.5倍で自動的に決まる**という順序を明示する。
- **第5回**：解説は最小限にして、**通しロープレの進行台本と評価シートを主役**にする。20のルール全部を1枚のチェックリストにまとめる。評価項目に**「最後までセット提案を崩さなかったか」**を必ず入れる。

# 書式（docs/研修資料フォーマット仕様.md §1〜§8 に完全準拠）

- スライドサイズ **10.833 × 7.5 インチ**
- 上帯（y=0, 高さ0.60"）と下帯（y=7.264", 高さ0.236"）＝ `9BBB59`、ヘッダー文字は白12pt HGP創英角ｺﾞｼｯｸUB で `2026年度　住宅用太陽光・蓄電池研修`
- ページ番号は右下・白・12pt
- 本文ページの見出しは **黒の角丸縦棒（x=0.157" w=0.14" h=0.51"）＋28pt HGP明朝E**
- 表紙は 住宅写真＋単色80%オーバーレイ＋72pt太字 BIZ UDPゴシック白。**回ごとにオーバーレイ色を変える**
  - 第2回＝`00B050`（緑）／第3回＝`F79646`（オレンジ）／第4回＝`4BACC6`（水色）／第5回＝`8064A2`（紫）
- 本文 20pt／小見出し 24pt太字／結論 28pt太字。フォントは HGPｺﾞｼｯｸE と 游ゴシック
- 強調は **赤 `FF0000` と黄マーカー `FFFF00` のみ**。装飾ライン・アクセントバーは使わない
- 表は縞模様を付けず、カテゴリごとにセル色を変える。4列表の列幅は 0.87"/1.41"/2.34"/5.74"
- 章の頭に「20のルール表から該当行だけ抜き出した表＋契約までの4ステップピラミッド」を置く
- 最終ページに奥付（機密情報／無断転用禁止）

# 執筆ルール

- **数字は docs/知識_数値ファクト集.md から取る。** 資料間で食い違う数値は以下を正とする
  - 電気代の上昇：**2011年以降45％・約5.5万円**（2010年 ¥119,602 → 2025年 ¥180,675）
  - 再エネ賦課金：**13年で18倍**、2026年 4.18円/kWh・世帯負担 22,990円/年
  - 30年間の電気代：**月12,000円で432万円**を基本とし、月2万円のケースは「700万円以上」と併記
- トークのセリフはナレッジの逐語をそのまま使い、要約しない
- 講師の口頭補足は**スライドに書かずノート欄に**入れる（`・` 始まりの短文）
- 受講者は営業経験の浅い人を含む。専門用語は初出時に1行で説明する
- 「シュミレーション」ではなく「**シミュレーション**」と表記する
- **単体販売を前提にした書き方をしない。**「蓄電池を提案する」→「太陽光＋蓄電池をセットで提案する」、「蓄電池の商談」→「創蓄セットの商談」と書く
- ロープレの顧客設定は**太陽光も蓄電池も未導入の世帯**を基本にする。卒FIT客（太陽光設置済み・蓄電池のみ追加）を扱う場合は「これはシングル販売のケース」と明示して区別する

# 完成後にやること

1. `markitdown 出力.pptx` で内容・誤字・順序を確認
2. `python scripts/office/validate.py 出力.pptx --original templates/研修資料_フォーマット見本.pptx`
3. PDF化して全ページを目視し、**文字のはみ出し・要素の重なり・0.5"未満の余白**がないか確認
4. プレースホルダの残骸（`XXX`・`ここに記入`）が無いか grep
5. **セット販売の軸がぶれていないか**を通しで確認。「蓄電池だけ」「太陽光だけ」を売る書き方になっているページが1枚も無いこと
6. できたファイルは `slides/` に置き、ブランチにコミットしてプッシュ

## 使い方

1. 上のコードブロックをコピーして、`【今回作る回】` を作りたい回に書き換える
2. そのまま Claude に貼る
3. 第3回以降は「第2回と同じ書式で」と添えると揃いやすい

## 事前に決めておきたいこと

このプロンプトでは以下を仮置きしています。違う場合は書き換えてください。

| 項目 | 仮置きした内容 |
|---|---|
| ファイル分割 | **1回＝1ファイル**（全4ファイル）。通しの1冊にすることも可能 |
| 枚数 | 1回30枚前後 |
| ルールの割り振り | 第2回＝①〜⑨／第3回＝⑩〜⑫／第4回＝⑬〜⑳／第5回＝通し |
| 表紙の色 | 回ごとに 緑→オレンジ→水色→紫 |
| 食い違う数値 | アプローチブック側（5.5万円・13年で18倍）を正とする |
| ロープレ用の顧客設定 | **太陽光・蓄電池とも未導入の世帯**を基本に作成（既存の「顧客設定集」があれば差し替え） |
| セット販売の根拠ページ | 第2回の冒頭に1〜2枚。すでに第1回で扱っていれば復習1枚に圧縮 |
