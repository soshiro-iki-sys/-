# 1. この研修は何か

## 1-1. 主題は「セット販売」

太陽光と蓄電池を**セットで売るための訓練**であり、
蓄電池単体（シングル販売）や太陽光単体の研修ではありません。全ページで以下を外さないこと。

- **太陽光と蓄電池は切り離さず、常にセットで話を進める**（営業ルール⑥「2つの当然意識」②）
- トーク例・図解・シミュレーションはすべて**「創蓄セット」を導入した前提**で書く
- 「蓄電池を売る」「太陽光を売る」と書かない。**「スマートハウス（太陽光＋蓄電池）を導入いただく」**と書く
- 蓄電池の容量は選択肢を与えず **太陽光容量 × 1.5** で提案する（ルール⑰）

**セットで売るべき根拠**（第2回の冒頭で1〜2枚使って共有する。第3回以降は不要）

| # | 根拠 | 中身 |
|---|---|---|
| ① | シングル販売は「価格市場」に移行していく | 導入期→成長期→成熟期と進むにつれ、成約の決め手は「実績」→「価格」→「紹介」へ移る。D2Cモデルの参入で価格崩壊が起きている地域もある |
| ② | セット販売は「空白市場」である | 太陽光設置済み約240万（総世帯の4％）に販売店が集中する“いびつな構造”。持家は約3,000万（52％）、総世帯は約5,700万 |
| ③ | 経済合理性がセットにある | 売電単価15円 ＜ 買電単価30円。売るより貯めて使う方が得なので、太陽光だけでは最適化できない |
| ④ | 設備面でもセットが前提になった | ハイブリッドパワコンが広く普及（1台で制御でき変換効率も高い）。ZEH住宅の要件に蓄電池が必須になる基準案が提出されている |
| ⑤ | セット販売の成功事例が出ている | 陽幸＝セット比率99％で月販110台／日本ライフサポート＝月販90台／プレジャーハウス＝正社員7名で月販30台 |

## 1-2. ゴールは「アプローチブックを使って商談できるようになること」

**アプローチブック「スマートハウスのある暮らし」（全26ページ）は、営業マンが商談で
実際にお客様の前でめくる唯一の資料です。** この研修は営業ルールの座学ではなく、
**このアプローチブックを使いこなせるようになるための訓練**です。

資料はすべて「**アプローチブックのどのページで、何を言い、お客様に何と言わせるか**」を
教えるものとして作ってください。ルールの解説が主で資料の使い方が従、ではなく、その逆です。

**受講者の到達状態（毎回の冒頭で提示する）**

- アプローチブックを見ながら、そのページで**言うべきこと**が口から出る
- 各ページの**緑帯の結論一文**を、資料を見ずに言える
- ページごとの**ゴール（お客様に言わせたい台詞）**を引き出す質問が打てる
- ページをめくる**順番と理由**を説明できる

# 7. 1ルールあたりのスライドの型（必ずこの2枚1組）

営業マニュアルの解説ページと同じ構造にする。**アプローチブックの実物ページを必ず左に置く**のが肝。

## 1枚目：ルールの理解 ＋ 対応ページ

```
┌──────────────────────────────────────┐
│ ▌必要性訴求                              ← 見出し（28pt HGP明朝E）│
│ ルール⑦：直近数か年の電気代推移の理解        ← 24pt太字        │
│ POINT　「しばらく電気代が下がっていない」事実に納得させる ← 赤字1行 │
│ ┌────────────┐  ┌────────────────┐ │
│ │            │  │ ゴール（お客様の反応）      │ │
│ │ アプローチ  │  │ 「10年間で5.5万円も電気代は │ │
│ │ ブック p.9  │  │  上がっているのですね」     │ │ ← 吹き出し
│ │ の実物画像  │  └────────────────┘ │
│ │            │  ┌────────────────┐ │
│ │            │  │ 説明のポイント（3〜4行）    │ │
│ └────────────┘  └────────────────┘ │
└──────────────────────────────────────┘
```

- **ゴールは必ずお客様の台詞として**書く（営業マンの説明ではなく、引き出す反応）
- 説明のポイントは、ナレッジの「説明のポイント」＋「考え方・事例」を3〜4行に圧縮

## 2枚目：現場での使い方（トーク）

- 見出しは1枚目と同じ
- `＜具体的なトーク＞` としてセリフを「」で列挙。**ナレッジの逐語をそのまま使い、要約しない**
- **使っている話法を右端にラベル表示**（第三者話法／YES取り／二者択一話法／Yes,but法／損失回避 など）
- よくあるネガと切り返しがある場合は2列の表にする
- 最下部に**そのページの緑帯の結論一文**を黄マーカーで置く
  （＝これが言えれば合格、という基準になる）

## ページが無いルール（①③④⑪⑯〜⑳）の型

左半分は画像の代わりに、**その場で何を手に持っているか／何を見ているか**を図示する。
（例：①＝検針票と図面の写真、⑯＝概算見積のイメージ、⑳＝お礼ハガキの実物例）

# 8. ワーク／ロープレのページ

各回に必ず入れる。**ロープレは必ずアプローチブックの実物を手に持ってめくらせる**こと。

- **ワーク指示ページ**：やること／時間／ペア構成／**使うアプローチブックのページ範囲**
- **ロープレ設定ページ**：顧客設定（家族構成・築年数・月々の電気代・断り文句）を表で提示。
  **太陽光・蓄電池とも未導入の世帯**を基本にする
- **チェックシートページ**：列は以下を固定
  - `ルール` / `該当ページ` / `お客様から狙った台詞を引き出せたか` / `緑帯の結論を言えたか`
  - 発言比率6:4・ラリー数30回も評価項目に入れる
- **暗唱チェック**：各回の最後に、その回で扱ったページの**緑帯の結論一文を資料を見ずに言う**時間を取る

# 9. 各回の固有の作り込み

**第2回（①〜⑨）**
- 冒頭に「**アプローチブック26ページの全体地図**」を1枚（Paragraph01〜03と、どの回でどこを扱うか）

- ルール③の**3つのオープンクエスチョン**は声に出す練習まで
- ルール⑤⑥は「**太陽光は当たり前**」→「**今は蓄電池とのセットが標準**」という接続がヤマ。ここに1枚多く割く

**第3回（⑩〜⑫）**
- 災害トークは「第三者話法でしか伝えない」「時間をかけずサラッと」が肝。
  **やりすぎ例／適切な例の対比ページ**を入れる
- **ルール⑪は「アプローチブックに該当ページが無い理由」を1枚使って説明**し、
  メーカー事例（Panasonic／SmartStar／ニチコン）で補う方法を教える
- ルール⑫の「1日の電気の流れ」は**太陽光で創る→蓄電池に貯める→夜に使う**という
  **セットでないと成立しないサイクル**として図解し、
  p.21の「具体的なシミュレーションを見ていきましょう！」への受け渡しトークにつなぐ
- 扱うルールが3つと少ないので、**ロープレの比重を上げる**（Paragraph02を通しで2周）

**第4回（⑬〜⑳）**
- 金額の伝え方（**1日あたり → 1か月あたり → 総額**）のフレーミングを**3枚に分けて段階的に**見せる
- ⑯の「総額を聞かれたときの逃げ方3つ」は表で
- ⑰は**太陽光の設置容量を先に決め、蓄電池はその1.5倍で自動的に決まる**という順序を明示
- ⑯以降はアプローチブックを離れる局面。
  「**p.26を閉じて、どう見積りにつなぐか**」の受け渡しトークを必ず1枚入れる
- 8ルールと多いので、⑲⑳は**推奨事項として軽めに**（マニュアルでも厳密なルールではないと明記）

**第5回（通し）**
- 解説は最小限。**アプローチブック26ページを頭から終わりまで通す実演＋ロープレを主役**にする
- 20のルールとアプローチブックのページを対応させた**1枚のチェックリスト**を作る
- 評価項目に「**最後までセット提案を崩さなかったか**」を必ず入れる

# 11. 執筆ルール

- **数字は docs/知識_数値ファクト集.md から取る。** 食い違う数値は以下を正とする
  - 電気代の上昇：**2011年以降45％・約5.5万円**（2010年 ¥119,602 → 2025年 ¥180,675）
  - 再エネ賦課金：**13年で18倍**、2026年 4.18円/kWh・世帯負担 22,990円/年
  - 30年間の電気代：**月12,000円で432万円**を基本とし、月2万円のケースは「700万円以上」と併記
- トークのセリフは**ナレッジの逐語をそのまま使い、要約しない**
- 講師の口頭補足は**スライドに書かずノート欄に**入れる（`・` 始まりの短文）
- 受講者は営業経験の浅い人を含む。専門用語は初出時に1行で説明する
