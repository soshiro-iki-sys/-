# 研修テキスト（講師用スクリプト）作成プロンプト

スライドに対応する「話す言葉」を全パート分つくるためのプロンプトです。
1回分ずつ作る想定なので、冒頭の `【今回作る回】` の行だけ書き換えてください。

---

## そのまま貼るプロンプト

````
# 依頼

住宅用 太陽光＋蓄電池の「セット販売」営業研修（全5回・各2時間）の
**講師用スクリプト（読み原稿）** を作ってください。

【今回作る回】第2回「聞く姿勢づくり＆必要性訴求①」
【対応スライド】slides/2026営業研修_第2回_聞く姿勢づくり＆必要性訴求①.pptx（全35枚）
【出力先】docs/script/第2回_講師用スクリプト.md

──────────────────────────────────────
# 1. このテキストは何か

**スライドを開いた講師が、上から読めばそのまま研修が成立する台本**です。
要約やメモではなく、**実際に口から出す言葉を逐語で**書いてください。

想定読者は「この研修を初めて担当する社員」です。
その人が読んで、間の取り方・問いかけのタイミング・アプローチブックをめくる位置まで
迷わない状態がゴールです。

## 1-1. 2つの語り口を必ず区別する

このスクリプトには性質の違う2種類の言葉が混ざります。**記号で明確に分けてください。**

| 記号 | 誰が誰に | 例 |
|---|---|---|
| （地の文） | **講師 → 受講者** | 「ここが今日いちばん大事なところです。ルール③を見てください。」 |
| **【実演】** | **営業 → お客様**（講師が演じて見せる） | 【実演】「どうしてこれまでは太陽光を導入されてこなかったのですか？」 |
| **【問】** | 講師が受講者に投げる質問 | 【問】「みなさんなら、ここで何と返しますか？　隣の人と30秒で話してください」 |
| **【操作】** | 資料の操作・板書の指示 | 【操作】アプローチブックを配り、p.9を開かせる |

**【実演】の中身は docs/知識_*.md の逐語をそのまま使い、要約・改変しないこと。**
地の文（講師の言葉）は新しく書き起こして構いません。

──────────────────────────────────────
# 2. 分量の設計

- 話速は **300字／分** で計算する
- 2時間のうち講義パートは約70分（休憩10分・ワーク/ロープレ25分・まとめ15分を除く）
- したがって **1回あたり 20,000〜24,000字** が目安
- 講義スライド1枚あたり **700〜900字**。ワーク／休憩／章扉のスライドは短くてよい
- **各ブロックの冒頭に想定所要時間（分）を必ず書く**。合計が120分になるか自分で検算すること

「短くまとめる」のではなく、**時間どおりに話せる分量を書く**のが要件です。

──────────────────────────────────────
# 3. 出力フォーマット

Markdownで、スライド1枚＝1ブロック。以下の型を厳守してください。

```markdown
## S12｜ルール②：自社の概要・今回の訪問趣旨の理解
**所要 4分**／アプローチブック p.2

### 話すこと
（ここに逐語の読み原稿。段落は3〜5行で改行する）

【操作】アプローチブックのp.2を開かせる

【実演】「本日は3つのことをお話しします。1つ目が……」

【問】「では、なぜ最初に構成を伝えるのだと思いますか？」

### このスライドの着地点
受講者が「金額を聞かれる前に構成を伝える」理由を自分の言葉で言える

### 想定Q&A
- **Q**「うちはパンフレットが無いのですが」
  **A**「名刺とお礼状でも成立します。大事なのは……」
```

- 見出しの `S12` は **スライド番号と一致させる**（スライドが無い回は自分で採番する）
- `### 想定Q&A` は受講者から出そうな質問。**1ブロックに0〜2件**、無ければ省略可
- `### このスライドの着地点` は1行。**受講者の状態**で書く（「〜を理解する」ではなく「〜を言える」）

──────────────────────────────────────
# 4. 書き方のルール

## 文体
- **敬体（です・ます）**。受講者への呼びかけは「みなさん」
- 一文は50字以内を目安に短く切る。読み上げたときに息が続く長さにする
- 専門用語は初出時に必ず1行で言い換える（例：「卒FIT、つまり固定買取の10年が終わった状態ですね」）

## 講師の運び
- 各ブロックは「**問いかけ → 受講者の答えを受ける → 解説 → 着地**」の順で組む。
  いきなり解説から入らない
- スライドが変わる位置で必ず一拍置く言葉を入れる（「では次に」「ここまでで質問はありますか」）
- 受講者が手を動かす場面（ワークシート記入・アプローチブックをめくる）は【操作】で明示する
- **前回の内容を1回は参照する**（第2回なら第1回の業界知識、第3回なら第2回のルール①〜⑨）

## 内容
- **数字は docs/知識_数値ファクト集.md からしか引かない**。記憶で書かない
- **セット販売の軸を外さない。**「蓄電池を売る」ではなく「太陽光＋蓄電池をセットで」と話す
- アプローチブックのページに触れるときは、必ず **ページ番号と、そのページの結論一文**をセットで言う
- 心理法則（一貫性の法則・包み込みの法則・プロスペクト理論など）は、
  **名前を出すだけで終わらせず「だから商談ではこうする」まで言い切る**

## やらないこと
- スライドに書いてある文字をそのまま読み上げるだけの原稿
- 「〜について説明します」で終わり、中身が無い行
- 講師の主観や体験談の創作（ナレッジに無い事例を作らない）

──────────────────────────────────────
# 5. 参照するナレッジ（このリポジトリ内）

| ファイル | 用途 |
|---|---|
| `docs/知識_営業ルール20.md` | 20のルールの解説・話法・切り返し（**【実演】の逐語はここから**） |
| `docs/知識_アプローチブック.md` | 26ページの流れ、各ページのゴールと結論一文 |
| `docs/知識_数値ファクト集.md` | 数字。**ここからしか引かない** |
| `docs/知識_業界と商品.md` | 業界構造・商品知識（第1回の内容。復習の参照用） |
| `docs/プロンプト_20のルール研修資料.md` | スライド側の設計。ルール↔ページ対応表もここ |
| `slides/2026営業研修_第○回_….pptx` | 対応するスライド本体 |

──────────────────────────────────────
# 6. 各回の対象範囲

| 回 | テーマ | 扱うルール | アプローチブック | スライド |
|---|---|---|---|---|
| 第2回 | 聞く姿勢づくり＆必要性訴求① | ①〜⑨ | p.2〜p.17 | 作成済み（35枚） |
| 第3回 | 必要性訴求②＆ロープレ | ⑩〜⑫ | p.18〜p.21 | 未作成 |
| 第4回 | 時期・料金訴求＆ロープレ | ⑬〜⑳ | p.23〜p.26 ＋ 見積り | 未作成 |
| 第5回 | 総仕上げ通しロープレ | ①〜⑳ 通し | p.2〜p.26 通し | 未作成 |

**スライドが未作成の回は、先にこのスクリプトを書いてください。**
書き上がったスクリプトが、そのままスライドの設計図（＝S番号ごとの1枚）になります。

## 回ごとに必ず入れるもの

- **第2回**：ルール②の自社ストーリー記入ワークの進行台本／ルール③の3つの質問を声に出させる練習の回し方
- **第3回**：ルール⑪で「アプローチブックに該当ページが無い理由」を説明する段落／
  災害トークの「やりすぎ例」を講師が一度わざと演じて見せる台本
- **第4回**：金額を1日→1か月→総額の順に出すデモンストレーションの逐語／
  「総額を聞かれたときの逃げ方3つ」を受講者に選ばせるワークの回し方
- **第5回**：通しロープレの進行・タイムキープ・フィードバックの言い方（**褒め方の型も含める**）

──────────────────────────────────────
# 7. ワーク／ロープレのブロック

講義パートと同じ密度で書いてください。特に以下を落とさないこと。

- **指示の逐語**（「3人1組になってください。時計回りに営業役・ご主人役・奥様役です」）
- **時間の宣言**（「5分でやります。合図したら交代してください」）
- **机間指導で見るポイント**（発言比率6:4／ラリー数30回／セット提案が崩れていないか）
- **フィードバックの言い方**
  - 良い点を先に、**「比較」と「人を褒める」の型**で（docs/知識_営業ルール20.md §7）
  - 直す点は1人1つだけに絞る

──────────────────────────────────────
# 8. 完成後にやること

1. **文字数を数える。** 20,000〜24,000字に収まっているか。少なければ薄いブロックを特定して加筆する
2. **所要時間を合計する。** 120分になるか。合わなければ各ブロックの分数を調整する
3. **S番号がスライドと1対1で対応しているか**を確認する（抜け・重複がないか）
4. 数字を docs/知識_数値ファクト集.md と突き合わせる
5. 「蓄電池だけ」「太陽光だけ」を売る書き方になっている箇所が無いか grep
6. 声に出して2ブロック読んでみて、息が続かない一文があれば切る
7. `docs/script/` に置き、ブランチにコミットしてプッシュ
````

---

## 使い方

1. 上のコードブロックをコピーして、`【今回作る回】` `【対応スライド】` `【出力先】` の3行を書き換える
2. そのまま Claude に貼る
3. 第3回以降はスライドが無いので、**このスクリプトを先に作ってからスライドを作る**

## 受講者用テキスト（配布用の冊子）にしたい場合

同じ素材から作れますが、性格が違うので指示を差し替えてください。

| | 講師用スクリプト（既定） | 受講者用テキスト |
|---|---|---|
| 読む人 | 講師 | 受講者 |
| 文体 | 話し言葉の逐語 | 書き言葉。要点は箇条書き |
| 【実演】 | 講師が演じるセリフ | **暗記用のトークスクリプト**として枠で囲う |
| 【問】 | 投げる質問 | **記入欄**にする |
| 想定Q&A | 講師の備え | 巻末にFAQとしてまとめる |
| 分量 | 20,000〜24,000字 | その6〜7割 |

差し替えるときは、上のプロンプトの「# 1. このテキストは何か」と「# 3. 出力フォーマット」を
この表の右列の内容に置き換えてください。

## 前提

| 項目 | 内容 |
|---|---|
| 対象 | 第2〜5回（第1回は実施済み） |
| 生成単位 | 1回ずつ |
| 形式 | Markdown（`docs/script/第○回_講師用スクリプト.md`） |
| 分量 | 1回あたり 20,000〜24,000字（話速300字／分 × 講義70分） |
| 第3〜5回 | スクリプトを先に書き、それをスライドの設計図として使う |
