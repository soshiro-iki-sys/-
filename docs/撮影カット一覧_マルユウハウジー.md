## 5. 前回の撮影指示書から引き継ぐルール

### 5-1. 1カット＝7項目で指定する

パワポに起こすときは、全カットをこの7項目で書きます（前回と同じ形式）。

```
 撮影場所／登場人物／服装／使用する小物／動作／カメラ位置・構図／表情
 ＋ ① HP使用場所  ② この写真で伝えること  ③ NG・撮影注意事項
```

### 5-2. NGの5つの判断軸

| # | 軸 | このサイトで特に効くところ |
|---|---|---|
| 1 | **個人情報を写さない** | アルバムの顔／書類・通帳の文字／**車両ナンバー**／見積書の氏名・住所 |
| 2 | **演技をしない** | カメラ目線の笑顔／大げさな握手／わざとらしい笑顔 |
| 3 | **実態以上に見せない** | 料金表と合わない豪華な現場／過大な買取訴求 |
| 4 | **乱雑・危険に見せない** | 放り投げる／無理な姿勢／過積載／交通妨害 |
| 5 | **敬意を欠かない** | 遺品・仏壇・人形・写真の扱い |

### 5-3. ★前回との重要な違い

前回の指示書は**遺品整理専門店**のもので、NG欄に以下がありました。

> 「新品同様の仕上げや本格清掃の表現を避ける」「磨き上げた室内の演出を避ける」
> 「実際の供養実施と誤認する儀式演出を避ける」

**マルユウハウジーは「ハウスクリーニング」と「供養」をサービスとして掲げています。**
→ **この2つのNGは、今回はそのまま当てはめてはいけません。**

- 本格清掃を**実際に提供しているなら**、磨き上げた仕上がりを見せてよい（むしろ見せるべき）
- 供養を**自社または提携寺院で実際に実施しているなら**、その様子を見せてよい
- **提供していない／相談のみなら**、前回と同じ制約をそのままかける

→ **§6の確認事項②で確定させてから撮影に入ります。**

### 5-4. 撮り方の共通ルール

- **1シーンにつき「引き・寄り・手元」の3パターン**を押さえる
- **横長で撮る。** ただしスマホ表示を考えて、**縦トリミングしても成立する構図**にする
- **文字を乗せる余白**を意識する（特にA-1、I-3）
- モデル（お客様役）と住宅の**利用許諾**を事前に取る
- 作業着のロゴの向き・汚れを撮影前に確認
- 各ロケーションの**撤収前**に、撮影責任者と現場責任者でチェックリストを確認

## 6. 確認したいこと

| # | 確認事項 | なぜ必要か |
|---|---|---|
| ① | **「ハウスクリーニング」と「供養」は別サービスか、1つか** | 下層ページの数が変わる。別なら C は 6→7セット（+3カット） |
| ② | **本格清掃・供養を実際に提供しているか**（相談のみか） | §5-3。NGの線引きが正反対になる |
| ③ | **「選ばれる理由」の項目**（いくつ・何） | B-1〜6 を実際の項目に差し替えたい |
| ④ | **「料金目安」は間取り別か、作業内容別か** | 間取り別なら D-1〜3 が必要、作業別なら不要 |
| ⑤ | **「ご利用の流れ」は何ステップか** | E の枚数が決まる |
| ⑥ | **女性スタッフはいるか** | B-2 が撮れるかどうか |
| ⑦ | **自社トラックの台数・ロゴの有無** | F-1・G-4 の撮り方 |
| ⑧ | **古物商／一般廃棄物の許可番号を誌面に出すか** | B-4 で番号まで写すかどうか |
| ⑨ | **実案件の現場で撮れるか**（空き家・モデルルームを使うか） | H（Before/After）が撮れるかの前提 |
| ⑩ | **撮影は何日取れるか** | 56カットを何回に割るか |

> **①〜⑤はサイトを見れば分かります。** `/okataduke/` の Basic 認証の ID/PW、
> または各セクションのキャプチャをいただければ、この一覧を実際の構成に合わせて確定します。
