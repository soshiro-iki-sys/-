# 撮影指示書フォーマット仕様（PHOTO DIRECTION BOOK）

`templates/撮影指示書_フォーマット見本.pptx`（遺品整理専門店 撮影指示書 30CUT・全23枚）の書式。
**研修資料のフォーマットとはまったく別系統**。混ぜないこと。

| | 研修資料 | **撮影指示書** |
|---|---|---|
| 判型 | 10.833 × 7.5 in（4:3） | **11.693 × 8.267 in（A4横・297×210mm）** |
| 主色 | 黄緑 `9BBB59` | **ネイビー `102D46`** |
| フォント | HGP創英角ｺﾞｼｯｸUB／HGP明朝E ほか | **Noto Sans CJK JP のみ** |
| 性格 | 講義資料（文字で説明する） | **指示書（撮る人が現場で見る）** |

## 3. この書式が守っているルール

| # | ルール | どこに出ているか |
|---|---|---|
| 1 | **1カット＝1ページ。** 複数カットを1枚にまとめない | B |
| 2 | **仕様は7項目固定。** 項目名も順番も全ページ共通 | B-3 |
| 3 | **写真は必ず「完成イメージ」と明示する** | B-2 の3点キャプション |
| 4 | **NGは必ず書く。** そこだけ暖色で区別する | B-4 の③カード |
| 5 | **「どこで使うか」を最初のカードに置く** | B-4 の①カード（HP使用場所） |
| 6 | **暖色はNG以外に使わない** | 全体 |
| 7 | **本文は10.5pt、ラベルは9.75pt Bold** で全ページ統一 | B・C |
| 8 | **最後に必ず現場で確認する紙（チェックリスト＋署名欄）を付ける** | D |

## 4. 再現するときの最小セット

python-pptx で作る場合、この書式は**矩形とテキストボックスだけ**で再現できる

```python

NAVY, BLUE, SKY  = '102D46', '23658D', 'B9D9E9'
TEXT, SUB, RULE  = '263843', '62747E', 'CBD8DE'
TINT1, TINT2     = 'F3F7F9', 'E8F1F5'
NG_BG, NG_LINE, NG_TEXT = 'FBF4F1', 'D6AA9E', '884333'
FONT = 'Noto Sans CJK JP'
SPEC_ROWS = ['撮影場所','登場人物','服装','使用する小物','動作','カメラ位置・構図','表情']
```
