### p.3 “脱炭素社会”に向け、太陽光＋蓄電池のお家は必須になる

「あったらいいね」から「必須のもの」へ。**オール電化・太陽光・蓄電池の3点セット**で賢い家づくりが完成する。

| 要素 | 訴求内容 |

| ③蓄電システム | 2019年問題を経て需要拡大／電気代削減＋停電対策／環境省がセット導入を推奨／**2024年度 導入件数158,852台・導入容量1.35GW** |

- **ゴール**：皆さん太陽光・蓄電池をつけているのですね／当たり前になりつつあるのですね
- **説明のポイント**：年間・累計で多くの太陽光・蓄電池が設置されていることを**数字で示す**
- 緑帯：なるべく少ないご負担で“スマートハウス”作りを進めましょう！

### p.5 大手ハウスメーカーでは“蓄電池のあるお家”が当たり前に

**ZEH（ネット・ゼロ・エネルギー・ハウス）**＝使うエネルギーが作るエネルギーと同じかそれより小さい家。

- **積水ハウス**：2025年度の戸建住宅ZEH率 **96％**。ZEH累積世界No.1。「グリーン・ファースト」など環境商品を提案
- **大和ハウス**：2011年、大阪府堺市に「スマ・エコタウン晴美台」誕生。**全65区画をZEH**にしたZET（ゼロ・エネルギー・タウン）。1戸あたり太陽光5.2kW・蓄電池6.2kWh

- **ゴール**：これからはスマートハウスが当たり前になるのですね
- **説明のポイント**：電気を作る太陽光と貯める蓄電池を設置した家が当たり前になる／ハウスメーカーが本格的に導入を進めている

### p.6 喜ばれているからこそ太陽光発電の輪が広がっている

設置件数の多いSHARPの「お客様の声」を掲載。

- **ゴール**：色々な方が導入し、満足しているのですね
- **説明のポイント**：**自社の実際のお客様の声・施工写真があればそちらに差し替える**。「**第三者話法**」で紹介し、実際の声を基にメリットを訴求

### p.7 極力電気を買わないスマートハウスのお家が標準に…

「未導入のお家」と「太陽光＋蓄電池」の対比図。

- **ゴール**：じゃあ太陽光・蓄電池つけた方がいいかもねえ
- **説明のポイント**：「**二者択一話法**」で「未導入 or 創蓄設置、どちらが良さそうですか？」とテストクロージングし、「**YES取り**」を行う。第三者話法に続き、なぜ多くの方が導入しているのかを一緒に見ていく

- **ゴール**：10年間で5.5万円も電気代は上がっているのですね
- **説明のポイント**：電気代が具体的にいくら上がっているのかを**ヒアリングし、正解を伝えてあげる**

### p.10 「電力自由化」でも電気代は上がってしまいました

2016年4月から電力小売が自由化され、消費者が電力会社を選べるようになった。

| 年度 | 単価 |
|---|---|
| 2016年 | 21円/kWh |
| 2025年 | 32円/kWh |

新電力の参入で選択肢は広がったが、**単価は11円ほど上昇**。

- **ゴール**：政府が電力自由化の法改正をしても電気代は上がっているのですね
- **説明のポイント**：政府が電気代を下げるために法改正まで行ったのに、高騰に歯止めが効いていない
- 緑帯：制度のねらいに反し、電気代はむしろ高くなっているのです

### p.11 電気代高騰の原因は2つの料金単価が上昇しているから

```
電気料金 ＝ 基本料金
         ＋ 電力量料金 {(電力量料金単価 × 使用電力量) ± (燃料費調整単価 × 使用電力量)}
         ＋ 再エネ賦課金（単価 × 使用電力量）
```

- **ゴール**：電気代の内訳はこんな感じなんですね
- **説明のポイント**：使用電力量が減っていても**単価が上がることで結果的に電気代が高騰**していることを計算式で説明
- 緑帯：毎月の支払料金は見ても、内訳まで見る人はいません…

### p.12 電気料金が上昇する理由：①全国的な電力単価の値上げ

円安・国際情勢による燃料価格高騰で各電力会社が経産省に値上げ申請。2023年5月に受理、同年6月使用分から反映。

**各電力会社の平均値上げ幅**：北海道21％／東北24％／北陸42％／東京14％／中部（このタイミングでは値上げなし）／関西29％／中国25％／四国18％／九州38％

- 東北電力の例：福島県沖地震で財務基盤が毀損する中、ウクライナ侵攻で輸入燃料価格が高騰。燃料費調整制度の上限を超える負担が継続的に増加したため、**2023年6月1日より平均25.47％の値上げ**を実施
- **ゴール**：全国的に電気代は上昇しているのですね
- **説明のポイント**：お客様の地域だけでなく全国的に上昇。背景はロシア・ウクライナ戦争による火力発電用石炭の輸入停止

### p.13 電気料金が上昇する理由：②再エネ賦課金の上昇

**再エネ賦課金とは**：再生可能エネルギーで発電された電気を電力会社が買い取るために、消費者から集めるお金。FIT制度により国が定める割高な価格での買い取りが義務づけられており、その原資を利用者に割り当てて負担させている。集められた賦課金は最終的に再エネで電気を作っている人へ届く。

- **現在の単価：4.18円/kWh**
- **ゴール**：再エネ賦課金が上昇することで、電気代が上昇するのですね
- 緑帯：全国民が電気料金とともに再エネ賦課金を負担しているのです

### p.15-16 電気料金が上昇する理由：③燃料調整費の上昇

**中東情勢悪化 → ホルムズ海峡封鎖 → 原油・LNG価格高騰 → 輸入燃料価格を3か月平均で算定 → 2か月後の料金に反映 → 5〜6月請求分の電気代が高騰**

加えて、**政府の電気・ガス料金支援が2026年3月使用分（4月請求分）で終了**。値上げ反映と補助終了が重なるため負担が大きくなる。

東北電力・低圧の燃料調整単価（2026年）：

| 月 | 単価 |
|---|---|
| 1月 | −8.76円 |
| 2月 | −13.26円 |
| 3月 | −13.14円 |
| 4月 | −10.00円 |
| 5月 | −8.42円 |
| 6月 | −8.36円 |

→ 6月のマイナス調整額は2月比で**約5.1円減少**＝1kWhあたり5.1円負担が増えているという意味。

## Paragraph 03「お得に導入できるのは？」

### p.23 かしこいスマートハウスの導入時期について（10年後に設置 vs すぐ設置）

すぐ設置した場合と10年後に設置した場合を時間軸で比較。10年後設置なら、その10年間は**電気料金を払い続けるだけ**（一般家庭12,000円/月なら**10年で144万円**）。

- 緑帯：設置を遅くするにつれ、経済メリットは少なくなります！
- **ゴール**：今、設置した方が将来的にお得なのですね
- **説明のポイント**：設置までの10年間の電気代と、売電単価減少による売電収入の減少という**デメリットしかない**

### p.24 待っても安くならないの？

総務省統計局「消費者物価指数（2020年基準）」。2020年1月を100とすると**2026年3月時点で112.7％**。

- **6年で物価は12.7％増加**
- 緑帯：待っていても必ずしも安くなるとは限らないのです
- **ゴール**：待っても物価は安くなるどころか上がっていく一方なのですね
- **説明のポイント**：消費者物価指数は上昇している。よって**今が一番お得に導入できるタイミング**

### p.25 まとまった費用をかけずに導入する方法

```
実質負担額 ＝ 設置費用 − メリット
```

太陽光が生み出す経済メリットが、導入時の実質負担を軽くする（＝**設置費用は太陽光が稼いでくれる**）。

| 賃貸住宅 | 持ち家 |
|---|---|
| 払い続ける | 払い終わる → **財産になる** |

| 電気代 | 太陽光・蓄電池 |
|---|---|
| 払い続ける | 払い終わる → **財産になる**（＋メリットも出る） |

- 緑帯：持ち家と同じように、長期的な財産になるものなのです
- **ゴール**：長期的には、財産になるのですね
- **説明のポイント**：家賃を払いたくないから持ち家を買う。電気代を払いたくないから創蓄を導入する。**創蓄は支払時も経済メリットが出る**ことを説明し、実質負担額の考え方を改めて提示

### p.26 かしこいスマートハウスの導入時期について（生涯比較）

フラット35などの住宅ローンと同じ原理で、**太陽光＋蓄電池ローンは15年で財産になる**。それ以降は光熱費0円生活。

| 何もしなかった場合 | 太陽光＋蓄電池を賢く同時導入 |
|---|---|
| 生涯光熱費 **400万円** を払い続ける | 月々15,000円 × 15年でローン支払期間終了 → 30年後は光熱費0円 |

- 緑帯：費用対効果でみれば、**早いうちにセット導入するのがお得**です！
- **ゴール**：早く設置したら、その分お得ですね
- **説明のポイント**：「**二者択一話法**」を用いる。家と同じように15年後には資産になる。ローン支払い後は光熱費0円の生活になる

## 使うときの共通ルール

1. **緑帯の一文が結論**。ページごとに必ずそこで締める
2. **ゴール（お客様の反応）を言わせる**のが目的。説明しきることが目的ではない
3. 各Paragraphの切れ目でテストクロージング（二者択一話法／YES取り）を必ず入れる
4. 災害パートは**第三者話法のみ**で、時間をかけずサラッと
5. p.6のお客様の声は**自社の実例に差し替える**のが望ましい
