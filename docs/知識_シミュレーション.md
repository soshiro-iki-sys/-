## 2. P6「1ヶ月のシミュレーション」── いくら減るか

### 光熱費の比較

| | 電気代 | ガス代 |
|---|---|---|
| **現在** | **15,089 円/月** | 0 円 |
| FIT期間中 | **3,844 円/月** | 0 円 |
| FIT期間終了後 | **3,844 円/月** | 0 円 |

→ 払う電気代そのものは **15,089円 → 3,844円**。**約1/4**になる。

### 削減額の内訳（★セット販売の根拠がここに出ている）

| 内訳 | FIT期間中 | FIT終了後 |
|---|---|---|
| 電気料金プラン変更 | 0 円 | 0 円 |
| **太陽光（自家消費）** | **6,612 円** | **6,612 円** |
| オール電化 | 0 円 | 0 円 |
| **蓄電池** | **4,634 円** | **4,634 円** |
| 節約額合計 | **11,246 円** | **11,246 円** |
| ＋ 売電収入 | 1,706 円 | **590 円** |
| **1カ月の実質削減額合計** | **12,952 円** | **11,836 円** |

※ いずれも「設備なしとの比較」

**この表が、太陽光＋蓄電池をセットで売る理由そのもの。**

- 太陽光だけ … 6,612円／月
- 蓄電池を足すと … **11,246円／月（＋4,634円、1.7倍）**
- 蓄電池の4,634円は「昼に貯めて夜に使う」ことで買わずに済んだ電気の価値

### FIT後に削減額が下がる理由

12,952円 → 11,836円（**−1,116円**）。
下がったのは**売電収入だけ**（1,706円 → 590円。買取単価が 24円 → 8.3円 になるため）。

**節約額合計 11,246円は1円も変わらない。**
＝ **自家消費の価値は、FITが終わっても減らない。**

> 「10年後（FIT後）はどうなるの？」はほぼ必ず聞かれる。
> ここで「売電の分だけ減りますが、**自分で使う分の価値は変わりません**」と即答できるかどうか。

### FIT期間の前提

| | FIT期間中 | FIT期間終了後 |
|---|---|---|
| 年数 | 4 年 | 21 年 |
| 買取単価 | 24 円/kWh | 8.3 円/kWh |

※ このサンプルは**既設太陽光があり、FIT残り4年**という設定。新規設置なら10年になる。
**お客様の設置時期で年数が変わる**ので、この欄は毎回読み替える。

## 4. P7「長期シミュレーション」── 25年でいくら残るか

| 実質光熱費累計 | FIT期間中（4年） | FIT終了後（21年） | 合計（25年） |
|---|---|---|---|
| 設備導入なしの場合 | 746,311 円 | 5,053,496 円 | **5,799,807 円** |
| 導入した場合 | 108,232 円 | 1,138,544 円 | **1,246,776 円** |
| **実質削減額** | 638,079 円 | 3,914,952 円 | **4,553,031 円** |

- **電気料金上昇率の想定：年率2％**
- **上昇率0％で計算した場合：25年間で 3,604,277 円**
- 実質光熱費とは：**光熱費から売電収入を減じた額**

> **前提条件を先に口で言う**のは、ここで具体化できる。
> 「この資料は電気代が年2％上がる前提です。**まったく上がらないとしても360万円**です」
> と先に言えば、「盛っている」と思われない。0％の数字が同じページに載っているのが強み。

### 投資回収の目安

| | 金額 |
|---|---|
| 分割支払額合計 | 4,196,880 円 |
| 25年間の実質削減額（年率2％） | 4,553,031 円 |
| 差 | **＋356,151 円** |
| 25年間の実質削減額（年率0％） | 3,604,277 円 |
| 差 | **−592,603 円** |

**年率0％だと25年では回収しきらない。**ここは正直に扱う。
売り方は「回収する投資」ではなく「**払い先を電力会社から自分の設備に替える**」。

数字が苦手なお客様には、この2枚を並べて「**買う電気が1/7になります**」と言うほうが速い。

### 1ヶ月の電気の流れ（P4・kWh）

```
発電 504 ─┬─ 自家消費 228 ──────────→ 家で使う  (6,612円の価値)
          ├─ 蓄電 199 → 放電 180 ──→ 家で使う  (4,634円の価値)
          └─ 売電  71 ────────────→ 電力会社   (1,706円の収入)
購入  62 ───────────────────────→ 家で使う  (3,844円の支払い)
```

- 使用のピークは **19時〜20時**。太陽光が発電しない時間帯。
  → **だから蓄電池が要る**、が数字で言える
- 8月（P9・蓄電が最大の月）は 自給率 **92.17％**、購入が 1日 1.54 kWh まで下がる
