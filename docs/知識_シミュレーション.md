# 経済効果シミュレーション（エネがえる診断レポート）の構成

**数字は案件ごとに変わるが、構成は毎回同じ。**
だから覚えるのは数字ではなく「どのページの、どこに、何が置かれているか」。
ここを身体で覚えると、初見のレポートでも同じ順番で、同じ場所を指して話せる。

学習用サンプル：「ダミーシミュレーション①」（2025/11/07 診断／関西電力エリア）。
個別の数値は §7 に付録としてまとめてある。

---

## 1. 全体の設計 ── 9ページ＝4ブロック

```
┌─ ブロック1  前 提 ─────────────────────────┐
│  P1  診断条件              何を提案し、いまどうなっているか        │
└────────────────────────────────────┘
┌─ ブロック2  現 象 ─────────────────────────┐
│  P2  太陽光 月別発電量      どれだけ発電するか                 │
│  P3  現在の電気の使い方      ┐                            │
│  P4  FIT期間中の使い方       │ 同じ枠に3つの状態を流し込む       │
│  P5  FIT終了後の使い方       ┘                            │
└────────────────────────────────────┘
┌─ ブロック3  金 額 ─────────────────────────┐
│  P6  1ヶ月のシミュレーション  ★ いくら減るか                  │
│  P7  長期シミュレーション     それが積み上がるとどうなるか        │
│  P8  お支払いシミュレーション ★ いくら払うか                  │
└────────────────────────────────────┘
┌─ ブロック4  補 足 ─────────────────────────┐
│  P9  自家消費優先（特定月）   いちばん効く月はこうなる            │
└────────────────────────────────────┘
```

### 綴じ順＝話す順

**「前提 → 現象 → 金額」**という、見積りの説明としてまっとうな順番で綴じてある。
商談でページを飛ばす必要はない。**めくる速度を変えるだけ**でいい。

| ブロック | めくり方 |
|---|---|
| 前提（P1） | 開かない。自分が事前に確認する |
| 現象（P2〜P5） | **P3とP4だけを対比で一瞬**。P2・P5は聞かれたら |
| 金額（P6〜P8） | **ここが本番。P6 → P7 → P8 をゆっくり** |
| 補足（P9） | 開かない。聞かれたら |

> **見せるのは実質 P3・P4・P6・P7・P8 の5枚、主役は P6 と P8 の2枚。**

## 2. 全ページ共通の枠

9ページすべてが同じ額縁に入っている。

```
┌──────────────────────────────────────────┐
│ ［ロゴ］エネがえる診断レポート   ┌─ご提案商材─────┐   ╭───────────╮ │
│                          │FIT中 太陽光 蓄電池 □│   │  ページ名   │ │ ← 濃いティールのピル
│ 診断日時／世帯ID／診断ID      │FIT後 太陽光 蓄電池 □│   ╰───────────╯ │
│                          └──────────────┘                 │
├──────────────────────────────────────────┤
│                                                          │
│                        本  体                             │
│                                                          │
├──────────────────────────────────────────┤
│ 注意事項：シミュレーション結果は…あくまで目安としてご利用ください。      [頁] │
└──────────────────────────────────────────┘
```

| 要素 | 意味 | 商談での使い方 |
|---|---|---|
| **ご提案商材マトリクス** | FIT中／FIT後 × 太陽光／蓄電池／オール電化 | 「今回は太陽光と蓄電池のセットでご提案しています」と**1回だけ指す**。セット提案であることが全ページに刷られている |
| **ページ名のピル（右上）** | そのページの見出し | **そのまま読み上げてページを切り替える**合図になる。自分で見出しを考えない |
| 診断日時／世帯ID／診断ID | 個別診断の証跡 | 「○○様専用に出した診断です」の根拠。聞かれたら指す |
| **注意事項（最下部）** | 全ページ同一文 | **省略しない。** 一度だけ口に出して、以降は触れない |

## 3. ページごとのレイアウト

### P1 診断条件 ── 左が「これから」、右が「いま」

```
┌─────────────────┬─────────────────┐
│ ☀ 太陽光      ご提案 │ 🏠 オール電化提案    なし │
│   合計パネル出力      │   エコキュート…×4項目    │
│   年間予測発電量      ├─────────────────┤
├─────────────────┤ ⚡ 現在の電気料金プラン    │
│ 🔋 蓄電池      ご提案 │   会社名／料金プラン      │
│   メーカー／型番／名称   ├─────────────────┤
├─────────────────┤ 💧 現在のガス料金プラン    │
│ 🔘 蓄電池運転モード    │   会社名／料金プラン      │
│   FIT中／FIT終了後    │                 │
└─────────────────┴─────────────────┘
      これから入れるもの            いまの状態
```

**左右対比がレポート全体の設計思想**で、以降のページもすべてこの考え方で並んでいる。

- 各見出しの右に **「ご提案」／「なし」** のラベルが出る。提案に含まれるものだけ「ご提案」
- **蓄電池運転モードが FIT中／FIT後 の2行**ある。ここが以降の全ページの前提
- 提案しない項目は「−」で埋まる（空欄にはならない）

### P2 太陽光 月別発電量 ── 左右で FIT中／FIT後

```
┌──── FIT期間中 ──年数──┬──── FIT期間終了後 ──年数──┐
│       買取単価         │        買取単価          │
├────────────────┼─────────────────┤
│   積み上げ棒グラフ（12ヶ月）  │   積み上げ棒グラフ（12ヶ月）   │
│   橙=自家消費 緑=蓄電 黄=売電 │   （発電量は同じ）          │
├────────────────┼─────────────────┤
│   月別の数表（4行×14列）     │   月別の数表（4行×14列）      │
└────────────────┴─────────────────┘
```

**発電量そのものは左右で同じ。**変わるのは年数と買取単価だけ。
→ **「発電する量は変わりません。変わるのは売る値段だけです」**が、このページの形そのもの。

### P3・P4・P5 電気の使い方 ── 同じ枠に3つの状態

3ページとも**完全に同じレイアウト**。違うのは流し込まれた数字だけ。

```
┌──── 1ヶ月の電気利用の流れ（平均）────┬──── 1日の電気利用の流れ（平均）────┐
│                            │                           │
│   ［家・パネル・蓄電池・電柱の絵］      │   ［24時間の積み上げグラフ］         │
│    発電 →┬→ 自家消費 →家         │    0時〜23時                  │
│          ├→ 蓄電 → 放電 →家      │                           │
│          └→ 売電 →電柱          ├───────────────────┤
│    購入 ←────────電柱        │   1日の平均使用量              │
│    （各フローに金額が括弧で付く）        │   使用／発電／蓄電／売電／購入      │
├────────────────────┼───────────────────┤
│   1ヶ月の使用量／自給率／CO2削減量      │   使用のピーク（時間帯・利用量）      │
├────────────────────┤                           │
│   現在の／最適な 電気料金プラン         │   ［凡例］                    │
└────────────────────┴───────────────────┘
```

**この3枚は「同じ枠・違う中身」なので、ビフォーアフターとして成立する。**

| | P3 現在 | P4 FIT期間中 | P5 FIT終了後 |
|---|---|---|---|
| 左の絵 | 発電・蓄電・売電が**すべて0** | 全フローに数字が入る | P4と同じ |
| 自給率 | **0％** | 大きく上がる | P4と同じ |
| 右下のプラン欄 | **現在の**電気料金プラン | **最適な**電気料金プラン | 同じ |
| P4との違い | − | − | **売電収入の金額だけ** |

> **P4とP5はほぼ同じ絵**。並べて見せると「さっきと同じでは」と言われる。
> P5は開かず、違いは P6 の表で見せるほうが伝わる。

> 左の絵には **「使用のピーク」が右下に出ている**。発電できない時間帯にピークが来ていれば、
> **蓄電池が要る理由がこのページの形で説明できる**。

### P6 1ヶ月のシミュレーション ★主役①

```
┌─────────────────────────┬──────────────┐
│  横棒グラフ                       │   光熱費の表        │
│   現在       ████████████████  │   ┌──┬────┬───┐ │
│   FIT期間中   ███▒▒▒▒▓▓▓▓▓▓▓  │   │現在│電気代│    │ │
│              ▬▬                │   │   │ガス代│    │ │
│   FIT期間終了後 ███▒▒▒▒▓▓▓▓▓▓▓  │   │FIT中│電気代│   │ │
│              ▬                 │   │   │ガス代│    │ │
│   ［凡例6色］                     │   │FIT後│電気代│   │ │
│                               │   │   │ガス代│    │ │
└─────────────────────────┴──────────────┘
┌───── FIT期間中 ──年数─────┬───── FIT期間終了後 ──年数─────┐
│        買取単価            │         買取単価              │
├─────────────────┼──────────────────┤
│ 節約額 │電気料金プラン変更        │ 節約額 │電気料金プラン変更         │
│       │太陽光(自家消費)   ╭────╮│       │太陽光(自家消費)   ╭────╮ │
│       │オール電化       │1カ月の││       │オール電化        │1カ月の│ │
│       │蓄電池          │実質  ││       │蓄電池           │実質  │ │
│       │  節約額合計      │削減額││       │  節約額合計       │削減額│ │
│ 売電収入                 ╰────╯│ 売電収入                ╰────╯ │
└─────────────────┴──────────────────┘
```

**構成の肝が3つある。**

**① 棒の全長は「現在の光熱費」で固定されている**

3本の棒の長さは同じ。中身が割れているだけ。

```
現在        │███████████████████████████│  すべて灰色＝まだ払う光熱費
FIT期間中    │███│▒▒▒▒▒▒│▓▓▓▓▓▓▓▓▓▓│  灰＝残る分 ▒＝蓄電池で減った分 ▓＝太陽光で減った分
            │▬▬│                       ↑ 下の小さい棒＝売電収入（別建て）
```

→ **「払う総額が減るのではなく、同じ金額の中身が『まだ払う分』と『自分で作った分』に割れます」**
  という話が、グラフの形そのままで言える。

**② 売電収入だけ棒が別になっている**

削減（支出が減る）と売電（収入が入る）は性質が違うので、棒を分けてある。
→ FIT後に短くなるのは**この別建ての棒だけ**。積み上げ部分は変わらない。

**③ 下段は左右対称**

FIT期間中とFIT終了後がまったく同じ並びで置かれている。
→ **読み方を1回教えれば、2つとも読める。**

**節約額の内訳4項目は、提案内容に対応している。**

| 内訳 | 何の効果か |
|---|---|
| 電気料金プラン変更 | プラン見直しの効果（提案しなければ0） |
| **太陽光（自家消費）** | 作った電気を自分で使ったぶん |
| オール電化 | エコキュート・IHの効果（提案しなければ0） |
| **蓄電池** | 貯めて使ったぶん |

→ **この4行が、そのままセット販売の根拠**になる。
  太陽光の行だけだといくら、蓄電池の行を足すといくら、が同じ表の中に並ぶ。

### P7 長期シミュレーション

```
┌──────────────────────────────────────┐
│  積み上げ棒グラフ（1年〜40年）                        │
│  灰=設備なし 濃灰=導入後 赤=削減額                     │
│  ［凡例］        電気料金上昇率 想定：年率 ○ ％          │
├──────────────────────────────────────┤
│        ○年間の実質削減額は 累計  ◆◆◆◆◆◆ 円          │ ← 1ページ1つの大きな数字
├──────────────────────┬───────────────┤
│  表（3列×3行）              │  上昇率0％の場合の数字    │
│         FIT中│FIT後│合計    │                     │
│  設備なし  －  │ －  │ －     │  ? 実質光熱費とは       │
│  導入した場合 －  │ －  │ －     │    （用語の定義）       │
│  実質削減額 －  │ －  │ －     │                     │
└──────────────────────┴───────────────┘
```

**構成として優れている点が2つ。**

- **想定（上昇率）が、グラフのすぐ横に書いてある。**
  前提を隠していないことが、ページの作りで示されている
- **同じページに「上昇率0％の場合」が併記されている。**
  → 「盛っているのでは」に、**ページをめくらずにその場で答えられる**

グラフは**40年まで目盛りがあるがシミュレーションは25年**なので、右側が空白になる。
指摘されたら「25年で計算しています」と答える。

### P8 お支払いシミュレーション ★主役②

```
┌─────────────────┬──────────────────┐
│  ローンの条件            │  金額の積み上げ             │
│   年率                 │   販売金額                 │
│   支払い年数             │   − 頭金                  │
│   ボーナス月加算          │  ─────────────       │
│   加算支払回数            │   ローン対象金額      ⓐ      │
│                      │   分割支払手数料      ⓑ      │
│                      │  ─────────────       │
│                      │   分割支払額合計    ⓐ+ⓑ      │
└─────────────────┴──────────────────┘
┌──────── FIT期間 ────────┬─────── FIT期間終了後 ───────┐
│                          │                          │
│    毎月の分割支払額           │    毎月の分割支払額            │
│  −  実質光熱費削減額          │  −  実質光熱費削減額           │
│  ─────────────       │  ─────────────       │
│  ＝  毎月の実質負担額  ◆◆◆◆   │  ＝  毎月の実質負担額  ◆◆◆◆    │
│      （1日あたり 約 ○○円）     │      （1日あたり 約 ○○円）      │
└──────────────────┴──────────────────┘
```

**このレポートで唯一の「式」が、ここに縦3行で置かれている。**

```
   毎月の分割支払額
 − 実質光熱費削減額        ← P6 の「1カ月の実質削減額合計」がそのまま入る
 ─────────────
 ＝ 毎月の実質負担額        ← 1ページ1つの大きな数字
   （1日あたり 約○○円）     ← さらに小さい単位に落とす
```

**読む順番は下から。**
いちばん上の「毎月の分割支払額」を先に読むと、そこで思考が止まる。

1. **「毎月の実質負担額」**（大きい数字）
2. **「1日あたり」**（身近な単位に落ちている）
3. 聞かれてから、上の引き算を説明する

> **P6 と P8 は数字でつながっている。**
> P6 の「1カ月の実質削減額合計」＝ P8 の「実質光熱費削減額」。
> **「さっきのこの金額が、ここに入っています」**と指でつなぐと、話が1本になる。

### P9 自家消費優先（特定月）

P3〜P5 と**同じレイアウト**で、中身が「太陽光からの蓄電が最大の月」になったもの。
平均ではなく**いちばん効く月**を見せるためのページ。開かずに持っておく。

## 4. 貫いているルール5つ

このレポートは、次の5つのルールで一貫して作られている。
**初見のレポートでもこの5つを探せば読める。**

| # | ルール | 現れているページ |
|---|---|---|
| 1 | **FIT中とFIT後は、必ず左右に並べる**（縦に積まない） | P2・P6・P8 |
| 2 | **「現在」は必ず比較対象として登場する** | P3・P6 |
| 3 | **結論は1ページに1つだけ、いちばん大きい字で出る** | P6＝実質削減額／P7＝累計削減額／P8＝実質負担額 |
| 4 | **内訳は結論の「左」に小さく置かれる** | P6・P7・P8 |
| 5 | **想定・前提は、結論と同じページに書いてある** | P7（上昇率）・P8（年率・年数）・P1（機器とプラン） |

### ルール3・4から導かれる、めくり方

**内訳 → 結論ではなく、結論 → 内訳の順で話す。**

```
     ✕  左から読む        節約額の内訳を順に説明 → 合計 → 実質削減額
     ○  大きい数字から    実質削減額 →（聞かれたら）内訳はこうです
```

レイアウトが「左に細かい字・右に大きい字」になっているのは、
**右を先に言って、左は聞かれたときのため**という設計。

## 5. 変わるもの／変わらないもの

| | 中身 |
|---|---|
| **毎回変わらない**（覚える） | 9ページの構成と順番／各ページのレイアウト／ページ名／ブロックの位置／4つの節約額内訳／引き算の3行／注意事項 |
| **案件ごとに変わる**（読み替える） | すべての金額・kWh／機器のメーカーと型番／電力会社と料金プラン／FIT残年数と買取単価／電気料金上昇率の想定／販売金額・年率・支払い年数 |
| **条件で0や「−」になる** | オール電化提案なし → P6の「オール電化」行が0、P1の右上が「−」／ガス契約なし → ガス代が0／プラン変更を提案しない → 「電気料金プラン変更」が0 |

> **0や「−」が並んでいても異常ではない。**「提案に含まれていない」という意味。
> ただしお客様に出す前に、**入っているべき欄が空のまま**になっていないかは必ず確認する
> （サンプルでは P1 の「合計パネル出力」が「−」、P4・P5 の「最適な電気料金プラン」が「0」のまま）。

## 6. 構成に沿った、めくる順番

```
  ［P1 で自分が前提を確認］※開かない
            ↓
  ①  P3 と P4 を並べる          「使う量は同じです。買う量がこれだけ減ります」
            ↓                  ＝ 現象を見せる（金額をまだ出さない）
  ②  P6 の棒グラフ             「払う総額は同じ長さ。中身が割れます」
            ↓                  ＝ 構造を見せる
  ③  P6 の実質削減額           「1ヶ月でこれだけ減ります」
            ↓                  ＝ 結論①
  ④  P7 の大きい一行           「25年ではこれだけになります」
            ↓                  ＝ 結論①が積み上がる（＋上昇率0％も同じページで）
  ⑤  P8 の実質負担額           「払うのは実質これだけ。1日にするとこれです」
                               ＝ 結論②（③の数字が引き算に入っている）
```

**ページを行き来しない。綴じ順に1回通すだけで話が完結するように作られている。**

| 聞かれたとき | 開くページ |
|---|---|
