## 3. Before / After 撮影指示

> **5ヶ所を同条件で撮る。整理作業による変化を正確に示す。**

**必須｜カメラ位置・高さ・焦点距離・画角・縦横を Before と After で完全に統一。**

| 場所 | BEFORE / 撮る状態 | AFTER / 撮る状態 |
|---|---|---|
| リビング | 部屋全体と生活用品の量。片付け前に動かさない。 | 搬出後の同室。簡易清掃の範囲にとどめる。 |
| 和室 | 押入れ・畳・仏壇周辺の状態を記録。 | 畳の経年感を保ち、不要物がなくなった状態。 |
| キッチン | 食器棚・収納・通路が見える位置。 | 残置物を除き、簡易清掃後の状態。 |
| 寝室 | ベッド・収納・床面の物量が分かる構図。 | 家財搬出後の空間。壁・床の経年感は残す。 |
| 玄関／廊下 | 玄関から廊下奥の動線と物量を記録。 | 同じ動線を妨げる物がなくなった状態。 |

> 同じ時刻帯・露出・ホワイトバランスをできるだけ揃える。
> 比較画像に写る品物の移動は撮影前に記録する。

**AFTER 側に一貫して「やりすぎない」指示が入っている**
（簡易清掃の範囲にとどめる／経年感を保つ／経年感は残す）。
原状回復業者ではなく遺品整理業者である、という線引き。

## 5. この指示書を貫いている5つの判断軸

20カットのNG欄を並べると、同じ5つの判断が繰り返されている。
**新しいカットを足すときは、この5軸でNG欄を書けばよい。**

| # | 軸 | NG欄での現れ方 |
|---|---|---|
| 1 | **個人情報を写さない** | 通帳の氏名・番号／実在の口座情報・住所・印影／個人の顔や文字／車両番号／読めない明細／契約内容 |
| 2 | **演技をしない** | カメラ目線の笑顔／大げさな握手／わざとらしい笑顔／悲しみを強調する演技／過剰な喜び |
| 3 | **実態以上に見せない** | 新品同様の仕上げ／磨き上げた室内／本格清掃の表現／過大な価格訴求／根拠のない断定 |
| 4 | **乱雑・危険に見せない** | 放り投げる／重ねて押し込む／無理な姿勢／壁に接触／過積載／交通妨害 |
| 5 | **敬意を欠かない** | 大量の写真をゴミ袋へ／床に直接投げ置く／雑な扱い／過度な儀式演出 |

### 5軸のうち、この業種で特に効いているもの

- **③ 実態以上に見せない** が繰り返し出てくる（9・10・15・16・18）。
  「遺品整理であって原状回復・ハウスクリーニング・供養の実施ではない」という
  **サービス範囲の線引きを、写真の段階で守らせている。**
- **⑤ 敬意** は仏壇・位牌・人形・写真まわりに集中（1・2・17・18）。
  同時に「**儀式を装う演出は避ける**」とも書かれていて、
  敬意は示すが宗教行為には踏み込まない、という線が引かれている。
