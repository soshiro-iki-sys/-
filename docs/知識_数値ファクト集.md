## 9. 金額提案の目安

| 項目 | 数値 |
|---|---|
| 1件あたりの購入単価 | **200万円を超えることもある** |
| 価格の「根源的分岐点」 | 予算は「1, 2, 3, 5」、購入価格は「4, 8, 18(, 27)」の循環 |
| 月1万円予算のお客様 | 実際の許容は **8,000〜18,000円** |
| 提案すべき月額 | **1万円程度（上限18,000円内）** |
| 1日あたりの言い換え | 500円 ≒ コーヒー一杯分 |
| 10年後に設置した場合の機会損失 | 月12,000円 × 10年 ＝ **144万円** |
| 1年先送りの損失（月1.2万円のメリット時） | **14万円** |
| ローン支払期間 | **15年**（それ以降は光熱費0円生活） |
| 補助金待ちの損失（トーク） | 年間 **15〜20万円以上** |
| クーリング・オフ期間 | **8日間** |
| 節電で削減できる額 | 年間 **505.39kWh／13,646円**（単価27円換算）が限界 |

## 11. 資料間で食い違っている点（要確認）

社内で数字を統一するときのチェックリスト。

| 論点 | ① 営業研修 | ③ アプローチブック | ② マニュアル |
|---|---|---|---|
| 電気代の上昇額（2010→2025） | 約6万円 | 約5.5万円（45％） | − |
| 再エネ賦課金の上昇 | 14年で19倍 | 13年で18倍 | 13年で18倍 |
| 30年間の電気代総額 | 432万円（月12,000円） | 700万円以上（月2万円） | 432万円（月12,000円） |
| 電気代の早見表の月額レンジ | 8,000〜20,000円 | 15,000〜30,000円 | − |

その他、元データ上の注意点：

- **2023年の再エネ賦課金が7,700円に急落**しているのは、化石燃料費の急高騰による例外的措置。グラフだけ見せると「下がることもある」と受け取られるので、必ず口頭で補足する
- アプローチブックの燃料調整費ページ（p.16）に、**編集途中のメモ「できれば、グラフがあればベター」がスライド上に残っている**。お客様に見せる前に削除が必要
- マニュアル表紙の英字が「**Soalr**+Battery Sales Manual」と誤記（正しくは Solar）
- 全資料を通して「シュミレーション」表記が使われている（正しくは**シミュレーション**）
- マニュアルのルール解説（3）に、**⑩⑪⑫が「時期訴求」「必要性訴求」と混在してラベルされている**箇所がある（⑩⑪⑫は必要性訴求が正）
