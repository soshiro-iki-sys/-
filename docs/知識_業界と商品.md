## 3. 再生可能エネルギー業界

### 定義（資源エネルギー庁）

> 温室効果ガスを排出せず、国内で生産できることからエネルギー安全保障にも寄与できる、有望かつ多様で重要な低炭素の国産エネルギー源

### 再エネの種類と特長

| 種類 | 特長 |
|---|---|
| 太陽光 | 地域に制限がない／用地を占有しない／遠隔地の電源／非常用電源になる |
| 水力 | 自然条件によらず安定供給／長期稼働／CO2を出さない／日本に成熟した技術 |
| 風力 | 陸上・洋上で発電可／大規模なら発電コストが低い／変換効率が良い／夜間も稼働 |
| 地熱 | 高温の蒸気・熱水を再利用／枯渇しない／昼夜問わず安定 |
| バイオマス | CO2を吸収して育つ燃料／廃棄物の再利用／農山漁村の活性化 |

### メリット／デメリット

- **メリット**：CO2削減に有効／エネルギー自給率の向上／枯渇しない／酸性雨の原因物質を抑制
- **デメリット**：発電コストが高い／エネルギー変換効率が悪い／発電量が天候に左右される

### 再エネ業界の3つの特徴（POINT）

1. **伸び盛りの業界である**
   - 世界の再エネ累積導入容量は右肩上がり（IEA Renewables 2021）
   - 日本の住宅用太陽光 累積導入件数：2001年 77,503件 → 2012年 1,409,787件 → **2022年 3,160,503件**
   - 住宅用蓄電池 累積導入：2013年 12,318 → 2014年 30,654 → **2024年 982,487件（10年で約30倍）**
2. **三方良しである**

   | 立場 | メリット |
   |---|---|
   | 世間 | 地球温暖化対策になる／エネルギー自給率が改善する |
   | 買い手 | 停電対策になる／自家消費で電気代を削減できる |
   | 売り手 | 補助金を受け取れる／企業イメージ向上／市場拡大で売上を伸ばせる |

3. **国の政策に大きく影響される**
   - 2015年 COP21で**パリ協定**合意（2020年以降の温暖化対策の世界共通枠組み）
   - 各国が削減目標を掲げ、日本も追随

## 4. なぜ電気代が上がるのか（3つのQ）

新人に必ず答えさせる3問。

| Q | A |
|---|---|
| Q1. 日本のエネルギー自給率は？ | **わずか11.3％**（2020年時点）。残り約88％は輸入 |
| Q2. 日本の火力発電の割合は？ | **約7割**（2022年度で化石燃料70.2％、2030年度エネ基では41％に下げる目標） |
| Q3. 石炭・LNGの最大輸入国と割合は？ | 火力発電の資源は**99％輸入** |

**結論：日本は自国で電気をほとんど作れず、燃料価格の高騰がそのまま電気代に乗る。**

### 電源構成の推移（資源エネルギー庁「電力調査統計」）

| 電源種別 | 2018年度 | 2022年度 | 2030年度（エネ基） |
|---|---|---|---|
| LNG（天然ガス） | 36.2％ | 30.0％ | 20％ ↓ |
| 石炭 | 29.6％ | 29.7％ | 19％ ↓ |
| 石油など | 10.9％ | 10.6％ | 2％ ↓ |
| 原子力 | 6％ | 5.3％ | 20〜22％ ↑ |
| 水力 | 7.4％ | 7.7％ | 11％ ↑ |
| バイオマス | 2.3％ | 5.1％ | 5％ ↑ |
| 地熱 | 0.2％ | 0.3％ | 1％ ↑ |
| 風力 | 0.7％ | 0.9％ | 5％ ↑ |
| 太陽光 | 6.6％ | 10.6％ | 14〜16％ ↑ |
| **自然エネルギー計** | 17.3％ | 24.5％ | 36〜38％ ↑ |
| **化石燃料計** | 76.8％ | 70.2％ | 41％ ↓ |

### 電気代の内訳

```
電気料金 ＝ 基本料金
         ＋ 電力量料金 {(電力量料金単価 × 使用電力量) ± (燃料費調整単価 × 使用電力量)}
         ＋ 再エネ賦課金（単価 × 使用電力量）
```

- **再エネ賦課金**：再エネで発電した電気を電力会社が買い取るため、消費者から集めるお金。FIT制度により国が定める割高な価格での買い取りが義務づけられており、その原資を利用者に負担させている
- **燃料費調整額**：原油・天然ガス・石炭の価格変動によるコスト増減を調整するもの。**3か月の平均値を使い、算出から2か月後の料金に反映**されるためタイムラグがある

### 節電では足りない

資源エネルギー庁のおすすめ節電対策（エアコン・冷蔵庫・照明で全体の60％）を全部やっても
**年間 505.39kWh／13,646円**（単価27円換算）程度にしかならない。

→ **電力会社から買い続ける限り、できる対策は「使用電力量を減らす」ことだけ。
そもそも買わない生活にすれば、電気代高騰を気にする必要がなくなる。**

## 5. 商品知識①：太陽光発電の仕組み

### 基礎

- 太陽光発電＝太陽光パネルに光が当たると電気が発生する現象を利用した発電
- CO2を出さない発電方法として注目されている

### 単位の関係

| 単位 | 意味 |
|---|---|
| **セル** | 太陽電池の最小単位 |
| **モジュール** | セルを組み合わせて1枚のパネルにした単位（＝太陽光パネル、ソーラーパネル） |
| **ストリングス** | モジュールを**直列**に組み合わせた単位 |
| **アレイ** | ストリングスを**並列**に組み合わせた単位 |

### 電力と電力量

- 電力（W）＝ 電圧（V）× 電流（A）
- 例：255Wのモジュール×20枚 ＝ 5,100W ＝ **5.1kWシステム**（1時間で5.1kWh発電）

### 発電の原理

N型半導体（表面）とP型半導体（裏面）を重ねて光を当てると、接合面を境にN型側に電子（−）、P型側に正孔（＋）が集まる。それぞれの電極をつなぐと電気が流れる。

### モジュールの種類

| 種類 | 特徴 |
|---|---|
| 単結晶シリコン | インゴット育成に手間と時間がかかり高価だが**変換効率が高く**、狭い屋根に多く積める。住宅用で人気 |
| 多結晶シリコン | 発電効率は単結晶にやや劣るが**価格と性能のバランスが良い**。産業用で多い |
| CIS | 銅・インジウム・セレンが主原料。朝夕・曇天・影・高温など**全天候でシリコン系より優れ、経年劣化も少ない**。シリコン不使用で省資源 |

### 2つの「効率」

- **変換効率**：太陽光エネルギーのうちどれだけを電気エネルギーに変換できるか。**現行品は20〜25％が多い**
- **発電効率**：熱や光のエネルギーがどれだけ電気になるかの割合。太陽光発電では**約20％**

発電量を左右する設置条件：**①日射量 ②方位・向き ③角度 ④温度 ⑤パネル表面の汚れ ⑥パネルの品質**

### システム構成と寿命

| 機器 | 役割 | 寿命 |
|---|---|---|
| 太陽光モジュール | 電気を生み出す | **20〜30年** |
| 接続箱 | 生み出した電気をパワコンへ送る | − |
| パワーコンディショナー | 直流を家庭で使える交流に変換する | **10〜15年** |
| 家庭用分電盤 | 各回路へ配電 | 10〜15年 |
| モニター | 発電状況・消費状況をチェック | − |

> パワコンは変換で継続的に負荷がかかるため、パネルより寿命が短い。

### まとめ（3点）

1. 太陽光パネルは「光エネルギー」を「電気エネルギー」に変換する装置
2. パネル以外にパワコンなどと併用してはじめて使える電気になる
3. 発電が太陽に依存するため、**方角・地域**で発電量が大きく変わる

## 6. 商品知識②：蓄電池の仕組み

### 市場背景

蓄電池の年間出荷台数：2011年 1,939台 →（東日本大震災を契機に市場創出）→ 2019年 115,000台（FIT切れ需要）→ 2022年 143,034台。
※2016年は補助金終了でややトーンダウン（34,569台）。

**普及の背景：①2019年問題 ②自然災害による大規模停電の増加**

### 2019年問題とは

2009年11月に始まった余剰電力買取制度（10年間同じ金額で買い取る）が、**2019年11月以降に順次満了**すること。2019年に満了する太陽光は約56万件。
**2009年当時の売電価格 48円/kWh → 卒FIT後は 11円/kWh 程度**（資源エネルギー庁の目安。電力会社が自由に設定できる）。

### 電池の分類

- **一次電池**＝使い切り（乾電池）
- **二次電池**＝充電して繰り返し使える。**家庭用蓄電池は二次電池**（モバイルバッテリーも同じ）

### リチウムイオン電池の正極材による違い

| 正極 | 特徴 |
|---|---|
| コバルト系 | 1991年に世界初の商品化。最も標準的。**熱暴走の危険性**あり。コバルト原価が高騰 |
| マンガン系 | 熱安定性が高く、原材料はコバルトの**約1/10**と安価 |
| リン酸鉄系 | **熱暴走が起こりにくく安全性が高い**。原材料は安価だが製造コストが高い |
| 三元系 | ニッケル・マンガン・コバルトの化合物系。コバルト系より安全性が高い |

負極では**チタン酸系**（高速充電が可能。ただし容量・電圧が劣る）、電解質では**リチウムポリマー**（ゲル状で液漏れしないが引火はする。形状自由でスマホ等に多用）。

### 原材料の供給リスク（＝価格が下がらない理由）

- **炭酸リチウム**：世界最大の生産国はチリ。日本は**100％輸入、うち80％をチリから**。アタカマ塩湖でかん水を**1年間天日干し**するアナログな製法。世界シェアNo.1のSQMですら半自動化にとどまる
- **コバルト**：レアメタル。コンゴ民主共和国に生産が集中。アムネスティの調査では**コンゴ産コバルトの20％が手掘り、約4万人の子供が働いている**とされ児童労働として非難 → 生産量を増やせない

> この2つが「待っても蓄電池は安くならない」という時期訴求の根拠になる。

### 家庭用蓄電池の3つの役割

1. 災害などによる停電時に電気を供給する
2. 夜間の安価な電気を蓄えて昼間に使い節約する
3. 太陽光で発電した電気を蓄えて自給自足の生活をする

### 運転モード

| モード | 動作 |
|---|---|
| 環境優先モード | 昼間に太陽光の余剰電力を充電し、夜に使う。電力会社の電気をできるだけ使わない |
| 経済優先モード | 安い深夜電力を充電し、朝や晩に使う。ピーク抑制・電気代節約 |

### 蓄電池の機能（提案時に押さえる5点）

| # | 論点 | 内容 |
|---|---|---|
| ① | **特定負荷型／全負荷型** | 特定負荷＝あらかじめ分電盤から回路を選び、停電時に使える箇所を決めておく。全負荷＝家中の電気を全て使えるので設置時に場所を選ぶ必要がない |
| ② | **サイクル数** | 充電＋放電1セットを何回繰り返せるか。現在は**10,000サイクル以上**が多い。1日1サイクルなら 10,000÷365＝**約27.4年**、理論上20年以上使える |
| ③ | **容量と出力** | 容量＝バッテリーの大きさ（kWh、貯水槽の「タンクの大きさ」）／出力＝瞬間的に取り出せるパワー（W・kW、「蛇口から出る水量」） |
| ④ | **消費電力の目安** | エアコン 800〜1,000W／液晶テレビ 50〜70W／モデム・ルーター 20〜30W／スマホ充電器 15W。4機器同時で約900W → 10kWhの蓄電池なら**約11時間稼働** |
| ⑤ | **単機能型／ハイブリッド型パワコン** | 通常は太陽光用と蓄電池用でパワコンが2台必要。**ハイブリッドは1台で制御でき、省スペースかつ変換効率も優れる** |

### 電気代削減シミュレーション例（設置10年・売電単価48円・毎月200kWh売電）

| | FIT終了前・蓄電池なし | FIT終了後・蓄電池なし | FIT終了後・蓄電池あり |
|---|---|---|---|
| 電気料金（月） | 6,000円 | 6,000円 | 3,000円 |
| ガス料金（月） | 0円 | 0円 | 0円 |
| 売電収入（月） | 9,600円（48円×200kWh） | 2,000円（10円×200kWh） | 2,000円（10円×200kWh） |
| **光熱費合計（月）** | **3,600円の利益** | **4,000円の支出** | **1,000円の支出** |

### まとめ（2点）

1. 蓄電池には「特定負荷／全負荷」「単機能／ハイブリッド」など種類があり、違いを理解することが最適提案につながる
2. 発電した電気を貯めて**電気を買わない生活を送れる**ことが蓄電池のメリット
