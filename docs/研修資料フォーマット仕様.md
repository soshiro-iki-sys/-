# 研修資料フォーマット仕様（船井総研・住宅用太陽光／蓄電池研修）

`創蓄セット販売 強化合宿（2026年5月度）` の資料（全71枚）を解析して、
そのままコピーできるレベルまで書式を書き出したものです。
今後「同じ形式で資料を作って」と言われたときは、このファイルの数値どおりに組みます。

見本ファイル：`templates/研修資料_フォーマット見本.pptx`（7枚。元資料からデザインを維持したまま代表ページだけ抜き出したもの）

**この社内資料群には3つの書式があります。**「研修フォーマット」（本文で解説）のほか、
マニュアルとアプローチブックは別書式なので、§9 を参照してください。

| 書式 | 使う資料 | 特徴 |
|---|---|---|
| **研修フォーマット** | 営業研修（109枚）、強化合宿（71枚） | 黄緑の上下帯＋「▌見出し」。§1〜§8 |
| **マニュアルフォーマット** | 太陽光＋蓄電池営業マニュアル（70枚） | 濃紺地に白いカード。§9-1 |
| **アプローチブックフォーマット** | スマートハウスのある暮らし（26枚） | 緑の見出し帯＋下部に緑の結論帯。§9-2 |

## 3. ページ見出し（本文ページの型）

全本文ページに共通する「▌見出し」の作り。**この2つは必ずセットで置く。**

| 部品 | 図形 | 位置・サイズ | 書式 |
|---|---|---|---|
| 縦棒 | 角丸四角形 | `x=0.157" y=0.757" w=0.140" h=0.512"` | 塗り＝黒(tx1)、枠線＝薄グレー |
| 見出し文字 | テキスト（四角形） | `x=0.348" y=0.736" h=0.572"`、幅は文字数に合わせて自動 | **28pt / HGP明朝E / 黒 / 太字なし** |

- 2段見出しにするときは2行目を `└サブ見出し` と書く（例：`ルール②：自社の概要・今回の訪問趣旨の理解` ＋ `└自社に関する「ストーリー」は、商談冒頭に売る`）
- 見出しは章名をそのまま繰り返す（`必要性訴求` が13枚連続など）。ページごとに言い換えない
- 本文の開始位置は **y=1.47"〜1.62"** あたり

## 4. ページの型（アーキタイプ）

### ① 表紙 / 章扉

| 部品 | 位置 | 書式 |
|---|---|---|
| 背景写真 | 全面（`x=-0.02 y=-0.03 w=10.85 h=7.53`） | 住宅（太陽光パネル付き）の写真 |
| 色オーバーレイ | 全面 `10.83 × 7.5` | **不透明度80%（alpha 80000）の単色**、枠線なし |
| 大見出し | `x=0.31 y=2.18 w=10.52 h=3.20` | **72pt 太字 BIZ UDPゴシック 白**。副題「（2026年5月度）」は同じ枠内で40pt |
| 日付・会場 | `x=5.10 y=4.89 w=5.59 h=0.40` | 白・小さめ「2026.5.21～23＠船井総研　大阪本社」 |
| ロゴ | `x=4.15 y=6.27 w=2.53 h=0.52` | Funai Soken ロゴ（下部中央） |

**オーバーレイ色で日を区別する**のがこの資料の特徴です。

| ページ | 色 |
|---|---|
| 1日目（表紙・p.1） | `00B050`（緑）80% |
| 2日目（p.19） | `accent6 = F79646`（オレンジ）80% |
| 3日目（p.40） | `accent6 = F79646`（オレンジ）80% |

### ② 章見出しページ（表＋4ステップピラミッド）

各章（聴く姿勢作り／必要性訴求／時期訴求／金額訴求）の頭に必ず入る型。

- 上：**「20のルール」表からその章の行だけを抜き出した表**（`x=0.16 y=1.55 w=10.35`）
- 下：**「契約までの4ステップ」ピラミッド図**（画像。金額訴求＝橙／時期訴求＝黄／必要性訴求＝緑／聴く姿勢＝青）
- 該当する章がひと目で分かるよう、表の左端カテゴリ列を色分けする

### ③ 一覧表ページ

| 項目 | 値 |
|---|---|
| 位置 | `x=0.16"`、幅 `10.35"`（20のルール表）／`10.54"`（営業知識表） |
| 4列表の列幅 | `0.87" / 1.41" / 2.34" / 5.74"`（項目・ゴール・ルール・詳細） |
| 3列表の列幅 | `1.48" / 4.96" / 4.09"`（営業知識・解説・具体例） |
| ヘッダー行 | 黒背景＋白文字・中央揃え |
| 本文 | 10〜14pt 游ゴシック、左揃え |
| 縞模様 | **使わない**（`banding = false`）。代わりにカテゴリごとにセル色を変える |

### ④ 解説ページ（本文＋図版）

- 本文テキストボックスは `x=0.12〜0.35"`、幅 `9.8〜11.2"`（左右いっぱいに使う）
- 本文 **20pt**、小見出し **24pt 太字**、強調結論 **28pt 太字**
- 図・写真は右または下に大きく配置（`w=5.5"` 前後）
- 会話例は `＜具体的なトーク＞` の見出しを立て、そのあとに「」でセリフを列挙する

### ⑤ 大文字メッセージページ

言いたいことを1つだけ、極端に大きい文字で置く型。

- 例：`数×質`＝88pt赤、`◎安心感`＝138pt、`信頼×比較`＝287pt
- 補足の説明文を下に 20〜28pt で添える
- 背景は白のまま。飾りは足さない

### ⑥ 奥付（最終ページ）

- 受講上の注意（複製禁止・録音録画禁止など）を8項目
- 中央に枠付きで会社名・研修名、その下に紫地＋白文字の「機密情報／無断転用禁止」
- 最下部に大阪本社／東京本社の住所・TEL・E-Mail を2段組

## 5. 文字の強調ルール

| 強調 | 指定 | 使いどころ |
|---|---|---|
| **赤 `FF0000`** | 文字色 | 結論・キーワード・「ここが研修！」など最重要語 |
| **黄マーカー `FFFF00`** | ハイライト（蛍光ペン） | 覚えてほしいフレーズを部分的に塗る |
| 青 `0070C0` | 文字色 | 補助的な強調・注記 |
| グレー `404040` / `222222` | 文字色 | 補足・出典 |

- 太字は多用する（本文の見出し行はほぼ `b=1`）
- 下線は使わない。**タイトル下のアンダーラインや装飾ラインは入れない**


## 9. もう2つの書式

スライドサイズ（10.833 × 7.5 インチ）とテーマ配色（Office標準）は3書式とも共通。
違うのは枠と見出しの作りです。

### 9-1. マニュアルフォーマット（社内・教科書）

`太陽光＋蓄電池営業マニュアル`（70枚）で使用。**紺（`003399`）で紙面を囲み、中に白いカードを置く**型。

| 部品 | 位置・サイズ | 書式 |
|---|---|---|
| 上帯 | `x=0.02 y=0 w=10.82 h=0.14` | `003399` |
| 下帯 | `x=0.02 y=7.27 w=10.82 h=0.23` | `003399`。左にコピーライト（白）、右にページ番号（白・12pt） |
| ヘッダー縦棒＋資料名 | 棒 `x=0.72 y=0.18 w=0.08 h=0.57` ／ 文字 `x=0.77 y=0.14` | `003399`／「太陽光・蓄電池営業マニュアル」 |
| **左サイドの章タブ** | ホームベース型 `x=0 w=0.61 h=1.54` を4つ縦に並べる（y=0.84 / 2.45 / 4.05 / 5.69） | **現在いる章のタブだけ `003399` で塗る**。他は白抜き |
| 章見出し | `x=0.75 y=0.30 w=7.81 h=0.44` | **20pt HGP創英角ｺﾞｼｯｸUB** |
| ルール名バー | `x=0.75 y=0.84 w=9.84 h=0.39` | **14pt HGS創英角ｺﾞｼｯｸUB** |
| **POINT表** | `x=0.74 y=1.31 w=9.85 h=0.57` | 2列。左セル＝赤字の「ＰＯＩＮＴ」、右セル＝要点1行 |
| 「考え方・事例」ラベル | 角丸 `x=0.69 y=1.97 w=3.07 h=0.32` | **14pt HGPｺﾞｼｯｸE・白文字**、紺の角丸 |
| 本文① | `x=0.95 y=2.29 w=9.43` | **12pt HGSｺﾞｼｯｸE** |
| 「実践するときのコツ」ラベル | 同サイズの角丸。y は本文①の量に応じて | 同上 |
| 本文② | `x=0.98 w=9.16〜9.85` | 12pt。表を置くこともある |

- **PART扉**は紺一色に青いボックスで `PART 01　はじめに` とだけ書く
- 1ページ＝1ルール。**「POINT → 考え方・事例 → 実践するときのコツ」の3段が絶対**
- フォントは `HGSｺﾞｼｯｸE`（本文）と `HGS/HGP創英角ｺﾞｼｯｸUB`（見出し）が主

### 9-2. アプローチブックフォーマット（お客様に見せる）

`スマートハウスのある暮らし`（26枚）で使用。**上に緑の見出し、下に緑の結論帯**で挟む型。

| 部品 | 位置・サイズ | 書式 |
|---|---|---|
| 見出し | プレースホルダ `x=0 y=0.26 w=10.84 h=0.55` | **28pt**、緑 `92D050` の帯 |
| 見出し下の細い罫 | `x=0 y=0.77 w=10.83 h=0.07` | `92D050` |
| リード文 | プレースホルダ `x=0.03 y=0.80 w=10.80 h=0.90` | **12pt メイリオ**。2〜3行で背景を説明 |
| 図版エリア | `y=1.4〜6.4` の広い領域 | グラフ／年表／対比図。数字は個別のテキストボックスで大きく置く |
| **結論帯** | 角丸 `x=0.14 y=6.56 w=10.55 h=0.75`、左端 `x=0.16` にアイコン画像（0.84×0.71） | 塗り `92D050`。文字 **24〜26.5pt メイリオ**、**キーワードだけ黄マーカー `FFFF00`** |
| 出典 | `x=2.35 y=7.31 w=8.38` | **6pt**。必ず入れる |
| ページ番号 | `x=8.19 y=7.20` | 12pt |
| コピーライト | `x=0 y=7.28` | 8pt |

- **Paragraph扉**は全面写真＋左に白抜きの `スマートハウスのある暮らし` ／ `Paragraph 01` ／ サブタイトル
- 年表ページは「縦の矢印コネクタ＋年の丸ポチ＋緑の年号（20pt）＋説明ボックス（16pt）＋累計件数の角丸バー（12pt）」の組み合わせ
- 件数は**いらすとやの家アイコンを並べて量を可視化**する（「＝30万件として図示」と注記）
- 強調色：緑 `92D050`（構造）／赤 `FF0000`（最新の数字）／黄マーカー `FFFF00`（結論のキーワード）

> **お客様に見せる資料なので、結論帯の一文だけで意味が通るように書くこと。**
