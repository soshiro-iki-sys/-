## 7. 構成の型（過去資料から継承した知見）

ページの見た目は本テンプレートに従いつつ、資料の組み立ては次の型を使う。

```
1  表紙
2  はじめに（この資料でわかること）
3  目次
4〜 各章
   ├ 定義・全体像
   ├ データ・図解（結論帯つき）
   └ 章の締め：メッセージ1枚
末尾 まとめ／次の一歩
     お問い合わせ（固定ページ）
```

- **結論帯**はほぼ全ページに置き、そのページの持ち帰りメッセージを1文で書く
- **章の入口・出口**に感情へ訴えるメッセージ1枚（`_class: message`）を挟む
- 章が変わるたび**目次を再掲**し、該当章を赤にする
- 数値・グラフには必ず出典（発行元・資料名・URL・閲覧日）
- 16:9の横幅は「引き伸ばし」ではなく**2カラム・左右対比**に使う
- 展開は **問題提起 → 根拠データ → 構造の説明 → 解決策 → 行動喚起**

## 9. 本リポジトリでの実装

### 9-1. ファイル

| ファイル | 役割 |
|---|---|
| `themes/funai.css` | **本フォーマットのMarpテーマ**（1280×720px・ロゴをdataURIで内蔵） |
| `templates/船井スタイル_テンプレート.md` | 空テンプレート（表紙〜最終ページの全パターン） |
| `.marprc.yml` | Marp共通設定（`html: true` ＝ 2カラム等に必須） |
| `assets/logo.png` / `logo_white.png` | テンプレートから抽出したロゴ |

### 9-2. 要素とMarp記法の対応

| フォーマットの要素 | Marpでの書き方 |
|---|---|
| 章タイトル（白抜き） | `# 1. 章タイトル`（h1） |
| 中タイトル（赤） | `## 中タイトル`（h2） |
| 小見出し（➢） | `### 小見出し`（h3） |
| 本文 | 通常の段落 |
| 結論帯 | ページ末尾の `> 引用` |
| 結論帯（2行） | `<blockquote class="tall"><p>1行目<br>2行目</p></blockquote>` |
| 帯の中の黄色強調 | 結論帯の中で `**強調**` または `<b>` |
| 本文中の赤キーワード | `**強調**` |
| ページ番号 | `<div class="pageno">4</div>`（手動） |
| 出典 | `<small class="src">出典：〜</small>` |
| 商標注記（右下） | `<small class="src tm">※〜</small>` |
| 表紙 | `<!-- _class: title -->` ＋ `.cover` ブロック |
| 目次 | `<!-- _class: toc -->` ＋ 番号付きリスト |
| メッセージ1枚 | `<!-- _class: message -->` |
| 全面ネイビー転換 | `<!-- _class: cover-navy -->` |
| 最終ページ | `<!-- _class: contact -->` ＋ `.contact-wrap` ブロック |
| 2カラム | `<div class="cols">` |

### 9-3. 実装ではまりやすい点

| 症状 | 原因 | 対処 |
|---|---|---|
| ヘッダー帯・フッター帯が出ない | Marpの `paginate` が `section::after` を上書きする | 帯は **`section` の背景**（multiple background）で描く。`::after` は使わない |
| カードが2列に並ばず1列に落ちる | `box-sizing` 未指定で border/padding が幅に加算 | テーマで `section *` に `box-sizing: border-box`。幅は `calc(50% - 9px)` と余裕をとる |
| `<blockquote class="tall">` が行ごとにバラける | `blockquote` が `display:flex` のため直下のインライン要素が各々アイテムになる | 中身を必ず `<p>` で包む |
| `**強調**` が文字のまま出る | 閉じ `**` の直前が `。」）` などの約物で直後が文字だと閉じ記号と認識されない | 句点を `**` の外に出すか `<b>` を使う |
| ぶら下げリストの記号が左に飛び出す | `text-indent` の負値がセクションのpaddingを越える | `display:flex` ＋ `::before { flex:0 0 33px }` で組む |
| 表の中の `<small>` が画面左上に飛ぶ | `.src` の絶対配置が素の `small` にも効く | 絶対配置は `.src` / `.tm` のみに限定 |
| `<div>` が生のHTMLとして表示される | Marp既定でMarkdown内のHTMLが無効 | `.marprc.yml` の `html: true` |
| コードブロックだけ等幅になる | 図解をアスキーアートで書いている | 図はCSSで組む（`.flow` など） |
