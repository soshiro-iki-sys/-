2つの実資料を解析して抽出した、社内標準レイアウト・配色・文章作法のリファレンス。
今後スライドを作成・修正するときは、このドキュメントの規則に従う。

| 略称 | ファイル | 用途 | 枚数 | 比率 |
|---|---|---|---|---|
| **A型：DL資料** | `2026_6_住宅用太陽光_AI_DL.pdf` | ダウンロード配布用の業界レポート | 22枚 | 16:9（960×540pt ＝ 33.87×19.05cm） |
| **B型：勉強会** | `新ZEH_GX ZEH対策勉強会ver.pptx` | セミナー・勉強会の登壇資料 | 45枚 | 4:3（27.52×19.05cm） |

> **サイズ ＝ A型（16:9 / 33.87×19.05cm）／レイアウト ＝ B型**

## 1. 共通のブランド要素

### 1-1. カラーパレット

| 役割 | HEX | 使いどころ |
|---|---|---|
| ブランドネイビー | `#002060` | 帯・見出しタブ・強調ブロックの背景。最重要色 |
| テーマ濃紺（副） | `#1F497D` | PowerPointテーマの `dk2`。図解の枠線・淡い塗り |
| 白 | `#FFFFFF` | ネイビー地の上の文字色／本文背景 |
| 警告レッド | `#FF0000` | 結論・キーワード1語だけ。**1枚に1〜2箇所まで** |
| 強調イエロー | `#FFFF00` | ネイビー帯の中でさらに強調したい語 |
| 黒 | `#000000` | 通常の本文 |
| 出典グレー | `#8A8A8A` 相当 | 出典・注記 |

> **配色の原則**：ベースは「白地＋ネイビー」。赤と黄は"最後の一撃"にだけ使う。
> 1枚のスライドで赤・黄を3箇所以上使わない。

PowerPointテーマのアクセント色（参考）：
`accent1 #4F81BD` / `accent2 #C0504D` / `accent3 #9BBB59` / `accent4 #8064A2` / `accent5 #4BACC6` / `accent6 #F79646`

### 1-2. フォント

| 用途 | フォント |
|---|---|
| 標準（テーマの major / minor） | **Meiryo UI** |
| 見出し・大書きの強調文 | Meiryo UI Bold（A型は明朝系の太字も併用） |
| 英数字の一部 | Arial |
| 補足・引用文 | メイリオ / Hiragino Sans |

原則として**全文Bold**。細字は出典・注記だけ。

### 1-3. ロゴ

- 右上に `Funai Soken` ロゴを常時配置（サイズ 2.72×1.40cm。**縦横比を変えない**）
- 表紙は白抜きロゴ、本編ページは通常版
- 最終ページは会社紹介＋ロゴ＋免責事項

## 2. 標準フォーマット（A型サイズ × B型レイアウト）

### 2-1. 変換の前提 — 縦は一切動かない

| | A型 | B型 |
|---|---|---|
| 幅 | **33.87cm** | 27.52cm |
| 高さ | **19.05cm** | **19.05cm** |

**両者の高さは 19.05cm で完全に一致する。**
したがってB型レイアウトをA型サイズへ移すとき：

- ✅ **縦座標（top）・高さ・フォントサイズは B型の実測値をそのまま使う**（換算不要）
- 🔁 **横方向だけ ×1.2306 に拡大**（33.87 ÷ 27.52）／全幅要素は 33.87cm へ
- ⚠️ ロゴ・写真など**縦横比を持つ素材は拡大しない**。右端から 0.24cm の位置に右寄せで置き直す

これが本フォーマットの核心。B型で確立された「縦のリズム」（見出し→リード文→図→結論帯）を
崩さずに、横幅だけ 6.35cm 広げた形になる。

### 2-2. 標準ページの座標定義

単位はcm（左上原点）と、Marp（1280×720px）換算のpx。
**cm × 37.8 ＝ px** / **pt × 1.333 ＝ px** で相互変換できる。

| 要素 | 位置 (L, T) cm | サイズ W×H cm | px 換算 (L,T,W,H) | 書式 |
|---|---|---|---|---|
| 章タイトル | (0.69, 0.19) | 13.54×1.53 ※長い章名は 23.87 | (26, 7, 512, 58) | **28pt Bold** |
| 区切り線 | (0.00, 1.72) | 幅 33.87 | (0, 65, 1280, –) | 細線1本 |
| ロゴ | **(30.91, 0.19)** | 2.72×1.40 | (1168, 7, 103, 53) | 右端から0.24cm。拡大禁止 |
| 小見出しタブ | (0.23, 1.85) | 7.58〜16.69×0.81 | (9, 70, 287〜631, 31) | **16pt Bold**・中央揃え・ネイビー地に白抜き |
| リード文 | (0.26, 2.72) | **26.00**×1.03〜2.56 | (10, 103, 983, 39〜97) | **18pt Bold**。1行=1.03 / 2行=1.8 / 3行=2.56 |
| 本文の図・写真 | (0〜0.7, 3.7〜4.8) | 幅 28〜33.87 | — | 上下は 3.7〜15.9cm の帯に収める |
| 結論帯 | (0.00, 16.13) | **33.87**×2.2 | (0, 610, 1280, 83) | **20〜32pt Bold**・中央揃え・ネイビー地に白抜き |
| コピーライト | (24.71, 18.47) | 9.0×0.6 | (934, 698, 340, 23) | `Copyright Funai Consulting Inc. All Rights Reserved.` |
| ページ番号 | (13.72, 18.31) | 6.42×1.01 | (519, 692, 243, 38) | 中央下 |

**結論帯の高さの使い分け**：2.0（1行）／2.2（標準）／2.4（2行）／3.0cm（2行＋余白）

### 2-3. 広がった6.35cmの使い方 — 引き伸ばさない

横幅が1.23倍になったぶん、**そのまま全部を横に伸ばすと読みにくくなる**。特にリード文は
18ptで33cm幅にすると1行が70文字を超え、視線の戻りが発生する。

| 原則 | 具体策 |
|---|---|
| **本文は伸ばさない** | リード文の幅は **26cm（≒45〜50文字）で頭打ち**。右に余白を残す |
| **帯とタブは伸ばす** | 結論帯・区切り線・全面カラーの矩形は 33.87cm の全幅に |
| **図は「大きく」ではなく「並べて」** | B型で縦に積んでいた要素を**横2カラム**にする。左に図・右に説明、など |
| **比較は左右に** | 「現状 vs 将来」「他社 vs 自社」を左右対比で置くと16:9が最も活きる |
| **16:9素材が素直に載る** | グラフ・スクリーンショット・PC画面のモックは、幅28〜33cmでトリミングなしに収まる |

### 2-4. ページ種別（この型で作る）

すべてのページに **章タイトル＋区切り線＋ロゴ** を置く。①以外は原則 **結論帯** も置く。

**① 表紙**
- A型の表紙を踏襲：斜め帯のビジュアル＋左に白抜きロゴ
- タイトル3段：`【ターゲット訴求】` → `業界名の` → `メインタイトル`
- 右下に枠付きで `YYYY年M月 発行`（登壇資料なら主催者名と開催日）

**② 標準ページ**（最頻出。全体の7割はこれ）
```
┌────────────────────────────────────────────────────┐
│ 章タイトル(28pt)                                    [Funai Soken] │
├────────────────────────────────────────────────────┤ ← 区切り線
│ ■小見出しタブ(16pt白抜き)                                       │
│ リード文(18pt太字・最大26cm幅)                                   │
│                                                                  │
│              ［図・表・グラフ・写真］                             │
│                                                                  │
│              出典：〜（7〜10pt グレー）                           │
├────────────────────────────────────────────────────┤
│ ■結論帯：このページの持ち帰りメッセージ(24pt白抜き・中央)          │
└────────────────────────────────────────────────────┘
```

**③ メッセージ1枚**
- 中央に全幅テキスト (-0.58, 5.7〜7.7) 幅 35.02cm、**54〜138pt** の特大Bold・中央揃え
- 感情に訴える一言（例：「電気代高騰で家計圧迫」66pt赤）
- 章の入口に置く

**④ 目次（再掲）**
- (0.41, 2.92) 32.77×5.73 に **32pt Bold** で4項目
- **今から話す項目だけ赤**。章の変わり目で毎回再掲する

**⑤ フルカバー転換**
- 既存ページの上に半透明ネイビー矩形 (0, 0) 33.87×19.05 を重ね、白抜き 54〜80pt で問いを投げる
- 例：「なぜここまで国は強制的に高性能化を推進するのか・・・」

**⑥ ステップ解説**（A型のAIDMAパターン。16:9で最も映えるので積極採用）
- 上部：ネイビー全幅帯に共通タイトル（全ステップで同一文言）
- その下：**進捗バー**（`A 注意 ▶ I 関心 ▶ D 欲求 ▶ M 記憶 ▶ A 行動`）
  現在のステップだけネイビー（最終ステップだけ赤）、他はグレーアウト
- 左カラム（約1/3・幅11cm）：ネイビーのカードにアイコン → 大文字 → 英語名 → 日本語名 → 白いピル型ラベルで客層名
- 右カラム（約2/3・幅21cm）：3ブロックを縦積み
  1. `配信対象のお客様の心理`（白地＋細枠）
  2. `出す広告`（薄いブルーグレー地）
  3. `具体例（訴求）`（ネイビー地・白抜き、①②③で列挙）
- 最終ステップだけ赤に切り替えてクライマックスを作る

**⑦ 事例ページ**
- 左右2ボックス＋右向き矢印でフロー図化
- 金額など核心の数字だけ 40pt 赤（例：「約275万円」）

**⑧ 比較表**
- 「項目／内容」2列テーブル。(0.69, 6.96) 32.49×11.17
- 上部にリード文3行（18pt Bold）

**⑨ 図解ページ**
- ピラミッド図／2軸マトリクス／3カラム比較
- 図の下に `≪ポイント≫` ボックス（緑枠・薄いピンク地）を置き、要点を「・」で2行

**⑩ 締め**
- 「ご清聴ありがとうございました！」54pt Bold
- 配布も兼ねる場合はA型のCTAページ（無料経営相談 `0120-958-270`）＋会社紹介＋免責を追加

### 2-5. 全体構成のテンプレート

```
1  表紙
2  タイトル＋登壇者／発行元
3  自己紹介（登壇資料の場合）
4  本日の流れ
5  本日お伝えしたい内容（結論を1枚で）
6  「なぜ？」（1語の問いかけ）
7  目次（4章）
8〜 各章
   ├ 章の入口：メッセージ1枚
   ├ 標準ページを数枚（結論帯つき）
   └ 章の出口：フルカバー転換で次章へ橋渡し
   ※章が変わるたび目次を再掲し、該当章を赤に
末尾 まとめ ／ 再掲 ／ ご清聴（＋CTA・会社紹介・免責）
```

### 2-6. 文章作法

B型（登壇用）の口語調をベースにする。

- 章タイトル：体言止め（例：「電気代高騰」「国の方向性」）
- 小見出しタブ：**番号付きの短文**（例：`①エネルギー自給率が低い`）
- リード文：断定調で結論から（例：「自給率はG7最低の15.3%である」）
- 結論帯：行動を促す形（例：「まずは、現状の把握から始めましょう！」「つまり◯◯」）
- 語りかけの「・・・」「！」「？」を積極的に使う
- 数字は必ず単位付き（件数・％・円）で、出典とセット
- 展開は **問題提起 → 根拠データ → 構造の説明 → 解決策 → 行動喚起**

### 2-7. 自己紹介ページ

1. 章タイトル「自己紹介」
2. 上部に実績・会社の写真バナー（幅 31cm ／ B型25.48cm を横に拡大）
3. 小見出しタブ「コンサルタント紹介」（16pt Bold）
4. 部署名（18pt）→ 氏名＋ふりがな（36pt Bold）→ 経歴文（16pt・細字）
5. 連絡先を1行で `Tel:◯◯　　email:◯◯`
6. 右側に顔写真（6.62×9.43cm・**拡大しない**、右端に寄せる）

## 3. 出典フォーマットA：DL資料型（16:9・配布用PDF）

標準フォーマットの**サイズと、ステップ解説・表紙・CTAのデザイン**をここから採用した。

### 3-1. 骨格

```
┌──────────────────────────────────────────────┐
│ 住宅用太陽光・蓄電池業界　Google×AIでカンタン集客   [Funai Soken] │ ← 走るヘッダー
├──────────────────────────────────────────────┤
│  ■ ネイビー見出しボックス（白抜き）                              │
│  リード文（黒・太字・1〜3行）                                    │
│  ［図・表・グラフ・写真］                                        │
│  出典：〜                                                       │
└──────────────────────────────────────────────┘
```

- **走るヘッダー**：全ページ左上に固定。「業種名＋資料タイトル」を毎回同じ文字列で
- 結論帯は持たず、下部は出典のみ
- 章タイトルの代わりに資料タイトルが固定で入る

> **標準フォーマットとの差**：A型は「走るヘッダー＋出典」、標準は「章タイトル＋結論帯」。
> 標準では**結論帯を採用**する。配布も兼ねる資料では、章タイトルの右隣に資料タイトルを
> 小さく併記してもよい（16:9の余白が使える）。

### 3-2. 文体
「〜である」体の論述調。一人で黙読して完結する情報量。

### 3-3. その他の固有要素
- 図解ページの `≪ポイント≫` ボックス（→標準でも採用）
- Google関連図版に `※GeminiはGoogle LLCの登録商標です`
- 出典表記：`出典：発行元「資料名」（URL）（閲覧日：YYYY年M月D日）`
- CTAページ・会社紹介・免責事項5項目

## 6. 本リポジトリでの実装

### 6-1. ファイル

| ファイル | 役割 |
|---|---|
| `themes/funai.css` | **本フォーマットのMarpテーマ**（1280×720px） |
| `templates/船井スタイル_テンプレート.md` | 本フォーマットの空テンプレート |
| `.marprc.yml` | Marp共通設定（`html: true` ＝ 2カラム・進捗バーに必須） |
| `assets/` | 図版の置き場（テンプレート同梱のものは差し替え用のダミー） |
| `themes/sales.css` | 旧・汎用テーマ（既存資料の互換用に残置） |

### 6-2. 要素とMarp記法の対応

| フォーマットの要素 | Marpでの書き方 |
|---|---|
| 章タイトル＋区切り線 | `# 章タイトル`（h1） |
| 小見出しタブ | `## 小見出し`（h2 → ネイビー地の白抜きタブに） |
| リード文 | 直後の段落（自動で18pt相当・983px＝26cm幅で頭打ち） |
| 結論帯 | ページ末尾の `> 引用`（2行なら `<blockquote class="tall">`） |
| 帯の中の黄色強調 | 結論帯の中で `**強調**` |
| 本文中の赤キーワード | 本文中で `**強調**` |
| 表紙 | `<!-- _class: title -->` |
| メッセージ1枚 | `<!-- _class: message -->`（赤字にするなら `message red`） |
| フルカバー転換 | `<!-- _class: cover -->` |
| 目次（該当章を赤） | `<!-- _class: toc -->` ＋ 該当行を `**強調**` |
| 締め | `<!-- _class: end -->` |
| 進捗バー | `<div class="steps">` の5セル。現在セルに `is-now`／最終セルに `is-last` |
| ステップの左カード | `<div class="step-card">`（mark / en / ja / pill） |
| ステップの右ブロック | `<div class="block plain">` `soft` `fill` |
| 2カラム | `<div class="cols">`（左を細くするなら `cols left-narrow`） |
| ≪ポイント≫ボックス | `<div class="point">` |

### 6-3. 単位換算メモ

```
cm × 37.8   = px    （1280px ÷ 33.87cm）
pt × 1.333  = px    （720px ÷ 540pt）
B型の横 × 1.2306 = 標準フォーマットの横
B型の縦 × 1      = 標準フォーマットの縦   ← 変換不要
```
