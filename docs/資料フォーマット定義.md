# 資料フォーマット定義書（船井総研スタイル）

2つの実資料を解析して抽出した、社内標準レイアウト・配色・文章作法のリファレンス。
今後スライドを作成・修正するときは、このドキュメントの規則に従う。

**解析元**

| 略称 | ファイル | 用途 | 枚数 | 比率 |
|---|---|---|---|---|
| **A：DL資料型** | `2026_6_住宅用太陽光_AI_DL.pdf` | ダウンロード配布用の業界レポート | 22枚 | 16:9（960×540pt） |
| **B：勉強会型** | `新ZEH_GX ZEH対策勉強会ver.pptx` | セミナー・勉強会の登壇資料 | 45枚 | 4:3（27.52×19.05cm ＝ 10.83×7.5in） |

## 1. 共通のブランド要素

### 1-1. カラーパレット

| 役割 | HEX | 使いどころ |
|---|---|---|
| ブランドネイビー | `#002060` | 帯・見出しボックス・強調ブロックの背景。最重要色 |
| テーマ濃紺（副） | `#1F497D` | PowerPointテーマの `dk2`。図解の枠線・淡い塗り |
| 白 | `#FFFFFF` | ネイビー地の上の文字色／本文背景 |
| 警告レッド | `#FF0000` | 結論・キーワード1語だけ。**1枚に1〜2箇所まで** |
| 強調イエロー | `#FFFF00` | ネイビー帯の中でさらに強調したい語 |
| 黒 | `#000000` | 通常の本文 |
| 出典グレー | `#8A8A8A` 相当 | 出典・注記 |

> **配色の原則**：ベースは「白地＋ネイविー」。赤と黄は"最後の一撃"にだけ使う。
> 1枚のスライドで赤・黄を3箇所以上使わない。

PowerPointテーマのアクセント色（参考）：
`accent1 #4F81BD` / `accent2 #C0504D` / `accent3 #9BBB59` / `accent4 #8064A2` / `accent5 #4BACC6` / `accent6 #F79646`

### 1-2. フォント

| 用途 | フォント |
|---|---|
| 標準（テーマの major / minor） | **Meiryo UI** |
| 見出し・大書きの強調文 | Meiryo UI Bold（PDF側は明朝系の太字も使用） |
| 英数字の一部 | Arial |
| 補足・引用文 | メイリオ / Hiragino Sans |

原則として**全文Bold**。細字は出典・注記だけ。

### 1-3. ロゴ

- 右上に `Funai Soken` ロゴを常時配置（B型：右上 24.56cm 位置、幅2.72cm）
- 表紙は白抜きロゴ、本編ページは通常版
- 最終ページは会社紹介＋ロゴ＋免責事項

## 2. フォーマットA：DL資料型（16:9・配布用PDF）

### 2-1. 標準ページの骨格

```
┌──────────────────────────────────────────────┐
│ 住宅用太陽光・蓄電池業界　Google×AIでカンタン集客   [Funai Soken] │ ← 走るヘッダー
├──────────────────────────────────────────────┤ ← 細い区切り線
│                                                                │
│  ■ ネイビー見出しボックス（白抜き文字）                          │
│                                                                │
│  リード文（黒・太字・1〜3行）                                    │
│                                                                │
│  ［図・表・グラフ・写真］                                        │
│                                                                │
│  出典：〜（7〜10pt・グレー）                                     │
└──────────────────────────────────────────────┘
```

**要素の定義**

| 要素 | ルール |
|---|---|
| 走るヘッダー | 全ページ左上に固定。「業種名＋資料タイトル」を毎回同じ文字列で。右端にロゴ |
| 見出しボックス | 背景 `#002060`／白抜き太字。幅は文字量に合わせる（左寄せ） |
| リード文 | そのページで言いたいことを **1文** で。黒太字 |
| 出典 | 必ず「出典：発行元「資料名」（URL）（閲覧日：YYYY年M月D日）」の形式 |
| 商標注記 | Google関連図版があるページには `※GeminiはGoogle LLCの登録商標です` を右下に |

### 2-2. ページ種別（この5種類の組み合わせで構成する）

**① 表紙**
- 緑ベタ地に斜め帯のイラスト、左に白抜きロゴ
- タイトル3段構成：`【ターゲット訴求】` → `業界名の` → `メインタイトル`
- 右下に枠付きで `YYYY年M月 発行`

**② データ提示ページ**（例：市場動向）
- 左に数値テーブル、右に棒グラフ＋成長を示す矢印
- 上部にリード文で結論、下部に出典

**③ 全面ネイビーの主張ページ**
- 背景を `#002060` で全面塗り、白抜き大文字（40〜54pt相当）で中央寄せ
- 箇条書きは白い横長ボックス（①②③）を等間隔に3つ並べる
- **結論の1語だけ赤** にする（例：「どこから購入するか」が正しい）
- 前ページの内容を薄く透かして重ねると、話の連続性が出る（実資料で使用）

**④ 図解ページ**
- ピラミッド図／2軸マトリクス／3カラム比較 など
- 図の下に必ず `≪ポイント≫` ボックス（緑枠・薄いピンク地）を置き、要点を「・」で2行

**⑤ ステップ解説ページ**（AIDMA型・本資料の中核パターン）
- 上部：ネイビー全幅帯に共通タイトル（全ステップ共通の文言）
- その下：**進捗バー**（`A 注意 ▶ I 関心 ▶ D 欲求 ▶ M 記憶 ▶ A 行動`）
  - 現在のステップだけネイビー（最終ステップだけ赤）、他はグレーアウト
- 左カラム（約1/3）：ネイビーのカードにアイコン → 大文字（A/I/D/M/A）→ 英語名 → 日本語名 → 白いピル型ラベルで客層名
- 右カラム（約2/3）：3つのブロックを縦積み
  1. `配信対象のお客様の心理` … 白地＋細枠
  2. `出す広告` … 薄いブルーグレー地
  3. `具体例（訴求）` … ネイビー地・白抜き、①②③で列挙
- 最終ステップだけカラーを赤に切り替えてクライマックスを作る

**⑥ まとめページ**
- 5ステップを横一列のカードに圧縮（アイコン／段階名／客層／施策／例）
- 上下にネイビー帯：上はロジックの要約、下は「最大の強み」を黄色強調で

**⑦ CTA・会社紹介ページ**（固定・毎回使い回す）
- 無料経営相談への導線（WEBボタン＋フリーダイヤル `0120-958-270`）
- 最終ページに会社概要・URL・免責事項5項目

### 2-3. Aの文章作法

- ページタイトルは体言止めか「〜とは」
- リード文は **結論から**。「〜である」「〜が必要である」と言い切る
- 数字は必ず単位付き（件数・％・円）で、出典とセット
- 話の展開は **問題提起 → 根拠データ → 構造の説明 → 解決策（自社商材）→ CTA**

## 3. フォーマットB：勉強会型（4:3・登壇用PPTX）

### 3-1. レイアウトマスタ

| レイアウト名 | 用途 |
|---|---|
| `1_タイトル スライド` | 表紙（全面画像＋大タイトル） |
| `タイトル スライド` | 講座タイトル＋登壇者名 |
| `コンテンツ` | 自己紹介など自由レイアウト |
| `1_アジェンダ` | **本編の標準レイアウト（全体の約9割がこれ）** |
| `アジェンダ` | 打合せ資料用の2ブロック型 |

### 3-2. 標準ページ（`1_アジェンダ`）の座標定義

実測値（cm、左上原点）。**この数値をそのまま踏襲すること。**

| 要素 | 位置 (left, top) | サイズ (W×H) | 書式 |
|---|---|---|---|
| 章タイトル（プレースホルダ） | (0.56, 0.19) | 11.0×1.53 ※長い章名は19.4幅 | テーマ既定 |
| 区切り線 | (0.0, 1.72) | 幅27.52 | 直線コネクタ |
| ロゴ | (24.56, 0.19) | 2.72×1.40 | 右上固定 |
| 小見出しタブ | (0.19, 1.85) | 6.16〜13.56×0.81 | 16pt Bold・中央揃え・ネイビー地 |
| リード文テキスト | (0.21, 2.72) | 26.95×1.03〜2.56 | 太字。1行＝1.03、2行＝1.8、3行＝2.56 |
| 本文の図・写真 | (0〜0.6, 3.7〜4.8) | 幅25〜27.5 | ほぼ全幅で配置 |
| 結論帯（フッター上） | (0.0, 16.13) | 27.52×2.2 | 20〜32pt Bold・中央揃え・ネイビー地に白抜き |
| コピーライト | (18.36, 18.47) | 9.0×0.6 | `Copyright Funai Consulting Inc. All Rights Reserved.` |
| ページ番号 | (10.55, 18.31) | — | 中央下 |

> **結論帯（下部バー）が最重要**。ほぼ全ページに置き、そのページの"持ち帰りメッセージ"を1〜2行で書く。
> 帯の高さは 2.0 / 2.2 / 2.4 / 3.0cm を内容量で使い分ける。

### 3-3. 特殊ページのパターン

| パターン | 作り |
|---|---|
| **メッセージ1枚** | 中央にテキストボックス (-0.47, 5.7〜7.7) 幅28.46、**54〜138pt** の特大Bold・中央揃え。赤字で感情に訴える（例：「電気代高騰で家計圧迫」66pt赤） |
| **目次（再掲）** | (0.33, 2.92) 26.63×5.73 に32pt Boldで4項目。**今から話す項目だけ赤**にして、章の変わり目で毎回再掲する |
| **講座構成表** | 3行×3列のブロック。左＝「第◯講座」28pt `#002060`／中＝登壇者区分16pt／右＝内容28pt `#002060` |
| **フルカバー転換** | 既存ページの上に半透明のネイビー矩形 (0,0,27.52×19.05) を重ね、白抜き54〜80ptで問いを投げる（例：「なぜここまで国は強制的に高性能化を推進するのか・・・」） |
| **事例ページ** | 左右2ボックス＋右向き矢印でフロー図化。金額など核心の数字だけ40pt赤（例：「約275万円」） |
| **比較表** | 「項目／内容」2列テーブル。(0.56, 6.96) 26.4×11.17。上部にリード文3行（18pt Bold） |
| **締め** | 「ご清聴ありがとうございました！」54pt Bold |

### 3-4. 自己紹介ページ（`コンテンツ`レイアウト）

固定構成：
1. タイトル「自己紹介」
2. 上部に実績・会社の写真バナー（幅25.48cm）
3. 小見出しタブ「コンサルタント紹介」（16pt Bold）
4. 部署名（18pt）→ 氏名＋ふりがな（36pt Bold）→ 経歴文（16pt・細字）
5. 連絡先を1行で `Tel:◯◯　　email:◯◯`
6. 右側に顔写真（6.62×9.43cm）

### 3-5. Bの構成テンプレート

```
1  表紙（主催者名＋テーマ＋日付）
2  講座タイトル＋登壇者
3  自己紹介
4  本日の流れ（講座構成表）
5  本日お伝えしたい内容（結論を1枚で）
6  「なぜ？」（1語の問いかけ）
7  目次（4章）
8〜 各章
   ├ 章の入口：感情に訴えるメッセージ1枚
   ├ データ・図解ページ（結論帯つき）を数枚
   └ 章の出口：フルカバー転換で次章へ橋渡し
23 目次（再掲・第2章を赤）
33 目次（再掲・第3章を赤）
36 目次（再掲・第4章を赤）
43〜45 まとめ／再掲／ご清聴
```

### 3-6. Bの文章作法

- 小見出しタブは `①エネルギー自給率が低い` のように**番号付きの短文**
- リード文は口語寄せの断定調（「〜のです」「〜しましょう！」）
- 語りかけの「・・・」「！」「？」を積極的に使う（登壇用のため）
- 結論帯は「つまり◯◯」「まずは◯◯から始めましょう！」と行動を促す形

## 4. 2つのフォーマットの使い分け

| | A：DL資料型 | B：勉強会型 |
|---|---|---|
| 読まれ方 | 一人で黙読 | 登壇者が話しながら投影 |
| 1枚の情報量 | 多め（読んで完結する） | 少なめ（話が主役） |
| 文体 | 「〜である」体・論述調 | 「〜です」体・口語調 |
| 比率 | 16:9 | 4:3 |
| ヘッダー | 走るヘッダー（全ページ同一文言） | 章タイトル（章ごとに変わる） |
| フッター | なし（出典のみ） | **結論帯（必須）** |
| 締め | CTA＋会社紹介＋免責 | ご清聴ありがとうございました |

## 5. 制作チェックリスト

- [ ] 全ページに走るヘッダー（A）／章タイトル＋区切り線（B）があるか
- [ ] 右上ロゴが全ページ同じ位置か
- [ ] B型は下部の結論帯が入っているか
- [ ] 赤・黄の使用が1枚2箇所以内に収まっているか
- [ ] 数値・グラフには出典（発行元・資料名・URL・閲覧日）が付いているか
- [ ] Google関連の図版に `※GeminiはGoogle LLCの登録商標です` を入れたか
- [ ] 章の区切りで目次を再掲し、該当章を赤にしているか
- [ ] 最終ページに CTA／会社紹介／免責 を入れたか
- [ ] フォントが Meiryo UI に統一され、本文が太字になっているか

## 6. 本リポジトリでの実装対応

Markdown（Marp）で作る場合の対応づけ：

| 本フォーマットの要素 | Marpでの書き方 |
|---|---|
| ネイビー見出しボックス | `<!-- _class: -->` ＋ CSS で `h2` に `background:#002060; color:#fff` |
| 全面ネイビーの主張ページ | `<!-- _class: impact -->` で `section` 背景をネイビーに |
| 結論帯 | ページ末尾の `> 引用` を CSS で下部固定バー化 |
| 進捗バー | 5セルのテーブル＋現在セルにクラス付与 |
| 出典 | 最下部に `<small>出典：〜</small>` |

`themes/sales.css` の変数を以下に合わせると本フォーマットに近づく：

```css
:root {
  --brand: #002060;
  --brand-dark: #001845;
  --accent: #ff0000;
  --highlight: #ffff00;
}
```
