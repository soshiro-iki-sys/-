# 骨子（確定版）｜工務店アライアンス DL資料

**構成**：3章構成・全16ページ＋お問い合わせページ＝17ページ
**対象読者**：地域密着型かつ営業人員5名程度の太陽光・蓄電池販売店
**扱う範囲**：工務店から新築施主の太陽光・蓄電池導入を発注いただく＝**元請け開拓**

### 大枠の流れ

```
第1章　アライアンスとは？          … 定義・座組・どの手法を使うか
第2章　アライアンスをやるべき理由  … 工務店の課題 → だからこそのアライアンス
第3章　アライアンス成功のポイント  … 受注件数の方程式と5変数の打ち手
まとめ／お問い合わせ
```

## P7 金利上昇のロジック（数値の根拠）

**前提**：4,000万円・35年・元利均等返済

| 金利 | 月々返済 | 同じ月10.4万円で借りられる額 |
|---|---|---|
| 0.5％ | 103,834円 | 4,000万円 |
| 1.0％ | 112,914円 | 3,678万円（▲322万円） |
| 1.5％ | 122,474円 | **3,391万円（▲609万円）** |

太陽光150万円をローンに上乗せした場合の返済増：**月4,593円**（金利1.5％・35年）

> **論旨**：金利上昇 → 施主の借入可能額が縮む → 工務店は棟数減×単価減で粗利が縮む →
> 1顧客あたりの取引額を上げたい → だが自社では太陽光を売れない → **提携の申し出が通りやすい**
>
> **想定される反論**「予算が縮むなら設備こそ削られるのでは？」への回答：
> 太陽光の返済増は月4,593円。電気代削減がこれを上回れば**ローン＋光熱費の総額はむしろ下がる**。
> 金利上昇で施主が「月々いくらか」に敏感になっている今こそ刺さる。
>
> ※電気代の削減額は設置容量・地域・電気料金単価により異なるため、資料では金額を断定していない。
