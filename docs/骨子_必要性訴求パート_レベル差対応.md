# 骨子：必要性訴求パート（レベル差のある受講者向け・60分）

株式会社山岸様／2026年度 営業研修
現行版（26枚）を、**契約率の高いベテランと未経験者が同じ部屋にいる**前提で組み直す案。

---

## 1. レベル差をどう扱うか

> 当初は3つの方針（①要求水準の2段化／②ベテランをコーチに配置転換／③冒頭のレベル可視化）を
> 提案したが、**採用したのは①のみ**。②③は不採用。

### 採用：資料は分けない。要求水準を2段にする

レベル別に資料を分けると進行が分岐して60分では回らない。
**同じページ・同じ順番のまま、「このページで言うこと」を2段に分ける。**

| 段 | 中身 | 誰が使うか |
|---|---|---|
| **基本** | これだけ言えば成立する2〜3行 | 未経験者。ここだけ追えば1時間で形になる |
| **応用** | お客様に合わせて変える／切り返す2行 | 経験者。ここだけ見れば退屈しない |

初心者は基本行だけを目で追い、ベテランは応用行だけを見る。**資料は1つ、読む深さが違う。**
ゴールのスライドで「**基本だけで商談は成立します**」と明言し、初心者が応用に引きずられないようにする。

## 2. 到達目標を2段に分ける

| | **基本**（初めての方・数回の方） | **応用**（契約率を上げたい方） |
|---|---|---|
| 今日のゴール | ① 資料を見ずに、緑帯の結論を言い切れる<br>② 1ページで言う数字を1つに絞れる<br>③ p.9からp.19まで13分で通せる | ① お客様の実額に数字を置き換えられる<br>② ネガが出ても、戻るページを選べる<br>③ テスクロとYES取りを入れられる |
| ロープレの目標 | 「基本」の行だけで p.19 まで到達する | ネガを1つ入れてもらい、切り返して戻る |
| チェックシート合格ライン | 7項目中5つ（上から3つは必須） | 7項目すべて＋ネガの切り返しが出る |

### 2段化の対象と、その中身

| 場所 | 基本 | 応用 |
|---|---|---|
| 各ページスライド | 「このページで言うこと」2〜3行 | 実額への置き換え・切り返し・テスクロ・YES取り 2行 |
| ゴール（P2） | 3つの到達目標 | 3つの到達目標 |
| 伝え方の型（P5） | 「STEP1とSTEP4だけでも通せれば合格」 | − |
| ①章扉（P6） | 「基本の3行だけ言えば①は成立します」 | 「検針票の実額に置き換える／戻るページを選ぶ」 |
| **ネガと切り返し（P16）** | − | **1枚まるごと応用（右上に応用バッジ）** |
| NG集（P23） | 初めての方に多い5つ | **「慣れた人ほど応用から入り、基本が抜けて話が飛ぶ」1行を追加** |
| 通し練習（P24） | 基本の行だけで p.19 まで到達 | ネガを1つ入れてもらう |
| チェックシート（P25） | 7項目中5つ | 7項目すべて＋切り返しが出る |
| ①のまとめ（P17） | 太字3ページを資料なしで | 9ページすべてを実額に置き換えて |

**合計 5＋20＋8＋18＋5＝56分（＋転換4分）**
