## 2. このパートの勝ち筋

**お客様の頭の中を、「導入するかどうか」から「いつ導入するのが賢いか」へ切り替える。**

```
  ✕  導入するか / しないか      ← ここで議論している限り、断る理由はいくらでもある
  ○  今やるか / 10年後にやるか   ← どちらを選んでも「やる」前提になっている
```

前回の経済メリットで「**1ヶ月でいくら減るか**」は出し切っている。
今回はその数字を**時間軸に掛ける**だけで成立する。

### 前回の数字が、そのまま武器になる（★今回いちばん効く設計）

| | 言い方 | 数字 |
|---|---|---|
| **基本** | 誌面どおり「10年間、電気代を払い続けるだけです」 | **10年間で 240万円** |
| **応用** | 「前回お出しした削減額が、10年まるごと手に入りません」 | 12,952円 × 120ヶ月 ＝ **約155万円** |

> **2026年版の誌面は「月20,000円のご家庭 → 10年間で240万円」。**
> 営業マニュアルのルール⑬は「月12,000円なら10年で144万円」（旧版の数字）なので、**誌面に合わせる**。
> お客様の検針票の実額が分かっていれば、その場で計算し直す。
> 「全国平均では」で終わらせない、という前2パートの約束がここでも効く。

## 3. 「待ちたい」の正体は3つ（この分解が今回の肝）

お客様の「まだいい」は1種類ではない。**どれなのかを聞き分けてから潰す。**

| 待ちたい理由 | 潰し方 | 使うページ |
|---|---|---|
| ① **補助金を待ちたい** | 抽選なので当たるとは限らない。待つ間の電気代は年15〜20万円 | （ページなし・トーク） |
| ② **値下がりを待ちたい** | 物価指数は6年で12.7％上昇。原材料の供給構造も変わらない | **p.24** |
| ③ **なんとなく、今じゃない** | 時期が空くと導入しない言い訳を探してしまう。期日を切る | **p.23・p.26** |

→ スマホの例え（合宿資料）が、この3つとそのまま重なる。
　「①今じゃなくていい ②待てば安くなる ③型落ちを買おう」

## 6. 主要スライドの中身

### 3枚目 このパートの勝ち筋（★今回の設計の核）

```
  お客様の頭の中を切り替える

  ✕  「導入するか / しないか」      断る理由はいくらでも出てくる
  ○  「今やるか / 10年後にやるか」   どちらを選んでも“やる”前提
```

| 前回出した数字 | 今回の言い方 |
|---|---|
| 1ヶ月の実質削減額 **12,952円** | 「このメリットが、10年間まるごと手に入りません」 |
| × 120ヶ月 | 「**約155万円**です」 |

- **基本**｜前回の削減額に120を掛けるだけ。新しい数字は要らない
- **応用**｜お客様の診断レポートの実額でその場で計算して見せる

### 5枚目 「機会損失」を自分事にする3手

| 手 | やること | 言い方 |
|---|---|---|
| ① 言葉を置く | 「機会損失」というキーワードを意識的に使う | 「導入を待つのは、この経済効果を先送りにする＝**機会損失**が生じているのと同じなんです」 |
| ② 数字を置換 | 全国平均ではなくお客様の実額で | 「〇〇様は月々約12,952円ですので、**10年で約155万円**の機会損失になりますね」 |
| ③ 質問を投げる | 自分で考えてもらう | 「**もしこの155万円を別のことに使えるとしたら、何に使いたいですか？**」 |

> ③まで行くと、お客様が自分の口で「もったいない」と言う。そこがゴール。

### 7枚目 「待ちたい」の正体は3つ

スマホの例えと重ねる（合宿資料より）。

| 買わない人の言い分 | 太陽光でいうと | 潰し方 |
|---|---|---|
| ① 今じゃなくていいや | なんとなく先送り | **時期が空くと言い訳を探す。期日を切る** |
| ② 待てば安くなる | 値下がり待ち・補助金待ち | **p.24 の物価指数＋原材料の供給構造** |
| ③ 型落ちを買おう | 旧モデルでいい | **数年で性能は変わらない** |

- **基本**｜どれなのかを**まず聞く**。3つは潰し方が違う
- **応用**｜「補助金を待ちたい」は②に見えて、実は**抽選リスク**の話で潰す

### 11枚目 切り返し（逐語）

**「補助金を待ちたい」**
> 「確かに、補助金があれば嬉しいですよね。ただ実は今、『**補助金待ちで損をする**』方が非常に多いんです。待っている間に払い続ける電気代は、おそらく年間で15〜20万円以上。しかも**補助金は抽選式**ですので、必ずしももらえるとは限りません。待っていると製品値上げや申請待ちの渋滞ということも多くて。そう考えると、**最も安く導入できるタイミングは間違いなく『今』**なんです。」

**「また考えて連絡します」**
> 「お気持ちは分かります。ただ、**時期が空くと導入しない言い訳を探してしまいがちで、絶好のタイミングを逃してしまう**かもしれません。○日11時までにご検討いただけますでしょうか。〇日に私からご連絡しますので、そのときにお教えください。**それまでは、このキャンペーン枠を私の責任で確保しておきますね。**」

### 12枚目 p.26 を閉じる前に握る

時期訴求の出口＝金額訴求の入口。**ここで握ってからアプローチブックを閉じる。**

1. 【実演】「費用対効果でみれば、早いうちにセット導入するのがお得です。**ここまではよろしいですか？**」
2. 【実演】「いま月◯◯円お支払いですよね。**その範囲内に収まれば、導入に問題はないですか？**」
3. YESを取ってからアプローチブックを閉じ、見積りへ

> **総額はここでも出さない。**（経済メリットパートと同じ約束）
