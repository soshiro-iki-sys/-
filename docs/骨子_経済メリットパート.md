## 3. 設計の軸：4つ

### 軸① 数字は3つしか残さない

診断レポートには数百の数字がある。**お客様に残すのは3つだけ**と決める。

```
  ①  1ヶ月の実質削減額      （P6）
  ②  25年間の累計削減額     （P7）
  ③  1日あたりの実質負担額   （P8）
```

前回の「1ページで言う数字は1つだけ」のシミュレーション版。

### 軸② レポートの構成が、そのままトークの順番

ページを行き来しない。綴じ順に1回通すだけで話が完結する作りになっている。

```
 P3・P4を並べる → P6の棒グラフ → P6の結論 → P7 → P8
 使う量は同じ、   払う総額は同じ  1ヶ月で   25年で  実質これだけ
 買う量が減る     長さ、中身が割れる これだけ減る これだけ 1日これだけ
```

### 軸③ 「結論 → 内訳」の順で話す

レポートは**左に細かい内訳・右に大きい結論**のレイアウト。
「右を先に言って、左は聞かれたときのため」という設計。

### 軸④ 金額は下から積む（★ご指示2）

合宿資料 p.47「分割して伝える」の型を、このパートの柱にする。

```
  ③  総支払額を伝える           ← 最後。聞かれてから
      ↑
  ②  1月あたりの金額にして表す     （1か月1万円≒電気代支払額より安い／停電保険）
      「奥さんも旦那さんの飲み会2回くらい削ったっていいですよね？」（YES取り）
      「皆さん停電保険って言われて」（第三者話法）
      ↑
  ①  1日あたりの金額にして表す     （1日500円≒コーヒー一杯分ぐらい）
      「旦那様、1日500円くらいコンビニで何か買われてますよね？」（YES取り）
```

**診断レポート P8 のレイアウト（上に販売金額、下に実質負担額・1日あたり）とも一致している。**
→ **「P8 は下から読む」＝「分割して伝える」＝「販売金額は後出し」**が全部同じ話になる。

## 6. 新規スライドの中身

### 16枚目 P6-① 棒の全長は固定、中身が割れる

```
現在      │███████████████████████│   すべて灰 ＝ まだ払う光熱費
FIT期間中  │███│▒▒▒▒▒│▓▓▓▓▓▓▓▓▓│   灰=残る 緑=蓄電池で減 橙=太陽光で減
          │▬▬│                     ← 売電収入だけ別建ての棒
```

- **基本**｜「棒の長さは3本とも同じです」から入る
- **基本**｜「中身が『まだ払う分』と『自分で作った分』に割れているだけです」
- **応用**｜売電だけ棒が分かれている理由（支出減と収入は別物）

> **「安くなる」ではなく「払い先が替わる」**という言い方が、この図の形から出てくる。

### 17枚目 P6-② 節約額の内訳＝セット販売の根拠

| 内訳 | 意味 |
|---|---|
| 電気料金プラン変更 | 提案しなければ 0 |
| **太陽光（自家消費）** | 作った電気を自分で使ったぶん |
| オール電化 | 提案しなければ 0 |
| **蓄電池** | 貯めて使ったぶん |

- **基本**｜太陽光の行と蓄電池の行を**指で2回指す**
- **基本**｜「太陽光だけだとこの行だけ。蓄電池を足すとここまで増えます」
- **応用**｜P4 の「使用のピーク 19〜20時」と結ぶ ＝ **発電しない時間にピークが来るから蓄電池が要る**

> **セット販売の根拠が、商談資料の中に数字で載っている唯一の場所。**

### 21枚目 分割して伝える（★ご指示2の本体）

合宿資料 p.47 の3段ピラミッドを、**そのままの形**で載せる。

| 段 | 言い方 | 添える話法 |
|---|---|---|
| ① 1日あたり | 「1日○○円、コーヒー一杯分くらいです」 | **YES取り**「旦那様、1日500円くらいコンビニで何か買われてますよね？」 |
| ② 1月あたり | 「1か月○○円。いまの電気代より安いです」「**停電保険**だと思っていただければ」 | **YES取り**「奥さんも、旦那さんの飲み会2回くらい削ったっていいですよね？」<br>**第三者話法**「皆さん停電保険って言われて」 |
| ③ 総支払額 | 「総額では○○万円です」 | **最後に伝えるのがベター** |

- **基本**｜**①から言う。③は聞かれてから**
- **応用**｜②で「停電保険」という言い換えを入れる
- **注意**｜**フレーミング効果**＝同じ金額でも枠組みを変えると印象が変わる。嘘をつくのではない

### 26枚目 相見積もり／褒め方

| | やること | 言い方 |
|---|---|---|
| **信頼** | 前提条件を隠さない。数字の出どころを言う | 「この数字は○○様の検針票から計算しています」 |
| **比較** | 他社下げをせず、お客様に判断軸を与える | 「設置後の点検体制で比べてみてください」 |

**金額の褒め → 体験の褒め**（合宿 p.36）

- ✕「○○円もお得ですね」で終わる
- ○「将来的には手出し0円で災害対策もできちゃいますね」
- ○「これで浮いたお金で何ができますか、奥さん？」
- ○「これで旦那さんお小遣いも少し増えますね、って方もいらっしゃいます」

> **「元が取れる／取れない」で判断させると、狭小住宅への提案が困難になる。**
