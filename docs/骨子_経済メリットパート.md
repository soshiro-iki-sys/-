### 経済メリット訴求と金額訴求の線引き

**ここを曖昧にすると、研修も商談も崩れる。**

| | **経済メリット訴求（今回）** | 金額訴求（次） |
|---|---|---|
| 答える問い | **「いくら減るか」** | 「いくら払うか、それは妥当か」 |
| 出す数字 | 削減額・累計削減額・**実質負担額** | 総額の根拠・他社比較・値引き |

| ゴール | **「思ったより減るんですね」** | 「それなら払えます」 |

## 3. 設計の軸：3つ

### 軸① 数字は3つしか残さない

診断レポートには数百の数字がある。**お客様に残す数字は3つだけ**と決める。

```
  ①  1ヶ月の実質削減額        （P6）  「毎月これだけ減ります」
  ②  25年間の累計削減額       （P7）  「25年ではこれだけです」
  ③  1日あたりの実質負担額     （P8）  「払うのは1日これだけです」
```

前回の「1ページで言う数字は1つだけ」の、シミュレーション版。

### 軸② レポートの構成がそのままトークの順番

ページを行き来しない。**綴じ順に1回通すだけで話が完結する**ように作られている。

```
 P3・P4 を並べる  →  P6 の棒グラフ  →  P6 の結論  →  P7  →  P8
  使う量は同じ、     払う総額は同じ長さ、  1ヶ月で      25年で    実質これだけ
  買う量が減る       中身が割れる        これだけ減る   これだけ   1日これだけ
```

### 軸③ 「結論 → 内訳」の順で話す

レポートは**左に細かい内訳・右に大きい結論**のレイアウト。
これは「右を先に言って、左は聞かれたときのため」という設計。

```
   ✕  左から読む     節約額の内訳を順に説明 → 合計 → 実質削減額
   ○  右から読む     実質削減額 →（聞かれたら）内訳はこうです
```

## 6. 新しく作るスライドの中身

### P6-① 棒の全長は固定、中身が割れる（15枚目）

```
現在      │███████████████████████│   すべて灰 ＝ まだ払う光熱費
FIT期間中  │███│▒▒▒▒▒│▓▓▓▓▓▓▓▓▓│   灰=残る 緑=蓄電池で減 橙=太陽光で減
          │▬▬│                     ← 売電収入だけ別建ての棒
```

- **基本**｜「棒の長さは3本とも同じです」から入る
- **基本**｜「中身が『まだ払う分』と『自分で作った分』に割れているだけです」
- **応用**｜売電だけ棒が分かれている理由（支出減と収入は別物）

> **「安くなる」ではなく「払い先が替わる」**という言い方が、この図の形から出てくる。

### P6-② 節約額の内訳4行＝セット販売の根拠（16枚目）

| 内訳 | 意味 |
|---|---|
| 電気料金プラン変更 | 提案しなければ 0 |
| **太陽光（自家消費）** | 作った電気を自分で使ったぶん |
| オール電化 | 提案しなければ 0 |
| **蓄電池** | 貯めて使ったぶん |

- **基本**｜太陽光の行と蓄電池の行を**指で2回指す**
- **基本**｜「太陽光だけだとこの行だけ。蓄電池を足すとここまで増えます」
- **応用**｜P4 の「使用のピーク 19〜20時」と結ぶ ＝ **発電しない時間にピークが来るから蓄電池が要る**

> **セット販売の根拠が、商談資料の中に数字で載っている唯一の場所。**

### P6-③ FIT後に減るのは売電だけ（17枚目）

- **基本**｜「FIT後に減るのは**売電収入だけ**です」
- **基本**｜「自分で使う分の金額は**1円も変わりません**」
- **応用**｜買取単価が落ちる仕組み（24円→8.3円など）まで触れる

> 「10年後はどうなるの？」はほぼ必ず聞かれる。**答えは同じページの右カラムにある。**

### P8-② P6とP8は数字でつながっている（20枚目）

```
   P6                              P8
  ┌──────────────┐          ┌──────────────┐
  │ 1カ月の実質削減額   │ ───────→ │ − 実質光熱費削減額  │
  │     ◆◆,◆◆◆ 円   │          │     ◆◆,◆◆◆ 円   │
  └──────────────┘          └──────────────┘
```

- **基本**｜「さっきのこの金額が、ここに入っています」と**指でつなぐ**
- **応用**｜つながりを言わずに P8 だけ見せると「別の数字」に見える、と理由まで
