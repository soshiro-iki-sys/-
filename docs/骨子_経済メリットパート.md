## 2. 基本方針：伝え方②（★ご指示3）

### 伝え方②を主、①を従にする

| | 中身 | 位置づけ |
|---|---|---|
| **伝え方②**<br>電気代の減収分のみ<br>（合宿 p.18） | **ローンの話をいったん外し、「電気代がいくら減るか」だけを見せる**<br>もともとの電気代 −削減額 ＝ 残る支出／1年・10年・30年の累計 | **これが基本。全員これで話す** |
| 伝え方①<br>ローン返済額を含めたトータル金額<br>（合宿 p.17） | もともとの電気代 ＋ローン分割額 −削減額 ＝ 支出合計<br>返済中は支出が増える → 完済後は激減する絵 | **切り替え用。**長期で考える方／完済後の姿に価値を感じる方 |

### この方針が、話の順番をきれいにする

```
  ［ 伝え方② の世界 ］ローンの話をしない
    p.20・p.21  →  P6（1ヶ月いくら減るか）→  P7（25年でいくら減るか）
                                                    ↓
  ［ 支払いの話に入る ］ここで初めてローンが出てくる
    P8 を下から読む  →  1日あたり  →  1月あたり  →（聞かれたら）総額
```

**「電気代がいくら減るか」を言い切ってから支払いに入る。**
販売金額が後出しになるのも、この順番の自然な結果。

### フレーミングの両面（★今回の肝）

| | 言い方 | なぜ |
|---|---|---|
| **削減額**は | **大きい単位**で言う（25年で455万円） | 得は大きく見せる |
| **支払額**は | **小さい単位**で言う（1日345円） | 負担は身近な単位に落とす |

> どちらも**同じ事実を、別の枠組みで見せているだけ**。嘘はついていない。
> これがフレーミング効果（合宿 p.46・p.47）。

## 3. 設計の軸

### 軸① 数字は3つしか残さない

```
  ①  1ヶ月の実質削減額      （P6）
  ②  25年間の累計削減額     （P7）   ← ここまでが伝え方②
  ③  1日あたりの実質負担額   （P8）   ← ここから支払いの話
```

### 軸② レポートの構成が、そのままトークの順番

ページを行き来しない。綴じ順に1回通すだけで話が完結する作りになっている。

### 軸③ 「結論 → 内訳」の順で話す

レポートは**左に細かい内訳・右に大きい結論**。右を先に言い、左は聞かれたときのため。

### 軸④ 金額は下から積む（合宿 p.47）

```
  ③  総支払額を伝える       ← 最後。聞かれてから
  ②  1月あたりの金額        （電気代支払額より安い／停電保険）
      「奥さんも飲み会2回くらい削ったっていいですよね？」（YES取り）
  ①  1日あたりの金額        （コーヒー一杯分ぐらい）
      「旦那様、1日500円くらいコンビニで買われてますよね？」（YES取り）
```

## 6. 主要スライドの中身

### 4枚目 今日の基本方針（★ご指示3の本体）

```
  ✕  いきなり「月々◯◯円のお支払いで」から入る
         → 支払額だけが記憶に残る

  ○  まず「電気代がいくら減るか」だけを言い切る
         → ローンの話は、そのあと
```

| | 伝え方② ＝ 基本 | 伝え方① ＝ 切り替え |
|---|---|---|
| 見せるもの | 電気代の減収分だけ | ローン返済額を含めたトータル |
| 向いているお客様 | **全員（まずこれ）**／現金一括／月々の支出増に抵抗がある方／数字が多いと混乱される方 | 長期で考えられる方／完済後の姿に価値を感じる方 |
| 切り替える合図 | − | ②で「で、いくら払うの？」と聞かれたとき |

- **基本**｜迷ったら②。ローンの話は自分から持ち出さない
- **応用**｜②で反応が鈍い（得の実感が薄い）ときだけ①に切り替える

### 10枚目 P6-② 節約額の内訳＝セット販売の根拠

| 内訳 | 意味 |
|---|---|
| 電気料金プラン変更 | 提案しなければ 0 |
| **太陽光（自家消費）** | 作った電気を自分で使ったぶん |
| オール電化 | 提案しなければ 0 |
| **蓄電池** | 貯めて使ったぶん |

- **基本**｜太陽光の行と蓄電池の行を**指で2回指す**
- **基本**｜「太陽光だけだとこの行だけ。蓄電池を足すとここまで増えます」
- **応用**｜P4 の「使用のピーク 19〜20時」と結ぶ ＝ **発電しない時間にピークが来るから蓄電池が要る**

> **セット販売の根拠が、商談資料の中に数字で載っている唯一の場所。**

### 13枚目 伝え方②（基本）

ローンを外して、**削減額だけを大きい単位まで積み上げる**。

```
  月で見ると    電気代が ◯◯,◯◯◯円 → ◯,◯◯◯円
  年で見ると    約 ◯◯万円
  25年で見ると  ◆,◆◆◆,◆◆◆ 円      ← P7 の数字をそのまま使う
```

- **基本**｜**ここでローンの話をしない。**「いくら払うか」は次
- **応用**｜25年の数字は P7 を開いて見せる（上昇率0％も同じページにある）

### 15枚目 P8 ＋ 分割して伝える（★ご指示2の本体）

診断レポート P8 のレイアウトと、合宿 p.47 の3段が**同じ構造**であることを重ねて見せる。

| 段 | 言い方 | 添える話法 |
|---|---|---|
| ① 1日あたり | 「1日◯◯円、コーヒー一杯分くらいです」 | **YES取り**「旦那様、1日500円くらいコンビニで買われてますよね？」 |
| ② 1月あたり | 「1か月◯◯円。いまの電気代より安いです」「**停電保険**だと思っていただければ」 | **YES取り**「奥さんも、飲み会2回くらい削ったっていいですよね？」<br>**第三者話法**「皆さん停電保険って言われて」 |
| ③ 総支払額 | 「総額では◯◯◯万円です」 | **最後。聞かれてから** |

- **基本**｜**①から言う。③は自分から出さない**
- **応用**｜②で「停電保険」の言い換えを入れる

### 18枚目 まとめ3つ

1. **まず「いくら減るか」を言い切る。**ローンの話は、そのあと（伝え方②）
2. **削減額は大きい単位、支払額は小さい単位。**総額は最後
3. **金額で勝とうとしない。**✕シミュレーション金額　◎安心感

＋ 金額の褒め → **体験の褒め**
「将来的には手出し0円で災害対策もできちゃいますね」「浮いたお金で何ができますか、奥さん？」
