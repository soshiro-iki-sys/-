# なぜ今、Claude Code なのか

---

# 営業・コンサルの「時間」の正体

## 現状の課題

私たちの一日は、**3種類の作業**に溶けています。

- 📄 **資料づくり** … 提案書・報告書・議事録に毎回 数時間
- 🔍 **調べもの** … 市場・競合・制度のリサーチに半日
- 🔁 **定型作業** … 見積・転記・集計・メールの繰り返し

> 「考える時間」「お客様と向き合う時間」が、作業に押し出されている。

---

# Claude Code とは何か

## ひとことで言うと

### チャットの相手ではなく、**“仕事を代行してくれる同僚”**

- 答えを返すだけでなく、**ファイルを作り・調べ・手を動かす**
- 最新のAI「**Claude**」が頭脳。あなたは**指示する側**に回れる
- 使いこなすほど、**「話すだけで仕事が終わる」**に近づく

---

# チャットAIとの決定的な違い

## お伝えしたいこと

### 「教えてくれる人」から、**やってくれる人**へ

| | 一般的なチャットAI | **Claude Code** |
|---|---|---|
| やること | 答えを**言う** | 答えを**形にする** |
| 成果物 | 画面上の文章 | **ファイル・資料そのもの** |
| 作業 | 自分で転記・整形 | **AIが直接実行** |

---

# 使い方は4パターン

## まずはここから

### 迷ったら、**デスクトップアプリが一番おすすめ**

- 💻 **デスクトップアプリ**（最推奨・いちばん簡単）
- 🖥️ ターミナル（CLI）
- 🌐 ブラウザ
- 🧩 エディタ拡張

> インストールして開くだけ。**難しい設定は不要**です。

# Claude Code で「できること」

---

# できること① 資料・文書をつくる

## こう使う

### 「○○社向けの提案資料を作って」で、**たたき台が完成**

- 提案スライド／報告書／議事録／お礼メール
- **PDF・PowerPoint** まで書き出し
- このプレゼン資料**そのもの**も Claude Code が作成

---

# できること② 調べて・要約する

## こう使う

### リサーチ → 整理 → **レポート化**まで一気通貫

- 長い資料・議事録を**3行に要約**
- 複数の情報を**比較表**にまとめる
- 「要点だけ」「箇条書きで」など**注文どおり**に整形

---

# できること③ データを処理する

## こう使う

### 集計・転記・整形を**まとめて代行**

- アンケート・売上の**集計とグラフ化**
- バラバラの一覧を**フォーマット統一**
- 「先月との差分を出して」など**分析の下ごしらえ**

---

# できること④ 文字起こし・定型作業

## こう使う

### 面倒な繰り返しを、**まるごと肩代わり**

- 会議音声・動画の**文字起こし → 議事録化**
- 毎週の報告書づくり、ファイルの仕分け
- **繰り返し作業ほど効果大**

---

# できること⑤ 過去資産を活かす

## こう使う

### 過去資料を**「型」として再利用**

- 優れた過去提案を参照し、**構成・言い回しを踏襲**
- チームの勝ちパターンを**横展開**
- ゼロから書かず、**実績の上に積む**

# Claude Code 5ステップ攻略法

---

# 5ステップで「同僚」に育てる

## 全体像

| STEP | やること | 到達点 |
|------|---------|--------|
| 1 | 定型業務の**効率化** | AIに**慣れる** |
| 2 | 定型業務の**自立実行** | 決まった作業を**任せる** |
| 3 | 外部連携で**能力拡張** | できる範囲が**広がる** |
| 4 | ワークフローの**最適化** | **チーム**で使える |
| 5 | 意思決定と**ゴール管理** | **話すだけで終わる** |

> 一気にではなく、**できるところから一段ずつ**。

---

# STEP1 定型業務の効率化

## まず慣れる

### フォルダを**「作業部屋」**に設定して、日々の作業から

- 案件ごとのフォルダをAIの**作業場**にする
- まずは資料作成・要約など**身近な作業**を頼む
- 焦らず、**AIの使い方に慣れる**ことが目的

> スタート地点。**ここから始めるのが鉄則**。

---

# STEP2 定型業務の自立実行

## 任せ始める

### 指示を待たず、**決まった時間に自動実行**

- 「毎朝この集計を」「会議後に文字起こしを」を**ルーティン化**
- 文字起こし・資料作成などを**自動で走らせる**
- あなたが寝ている間にも、**仕事が進む**

---

# STEP3 外部連携で能力拡張

## つなげる

### コネクター連携で、**できることが一気に広がる**

- **Gmail / Googleカレンダー / YouTube** などと接続
- メールの送受信、予定調整、動画リサーチまで
- AIが社内外の道具を**直接使えるようになる**

> 「調べて・作る」だけから、**「連絡して・段取りする」**へ。

---

# STEP4 ワークフローの最適化

## 広げる

### 自分専用から、**チームで使える形**へ

- 作った自動化を、**他の人でも回せる**ように整える
- 手順を標準化し、**再現性と安定性**を高める
- 属人化を防ぎ、**チームの仕組み**にする

---

# STEP5 意思決定とゴール管理

## 任せきる

### ゴールと紐づけ、**「話すだけで仕事が終わる」**

- すべての作業を**ゴール管理（例：Addness）**と連携
- AIが**優先順位を理解**した状態で動く
- ここまで来ると、**意思決定に集中**できる

> 5ステップの最終形。AIが**“優秀な同僚”**になる。

---

# 成功の鍵は、たった2つ

## ここが最重要

### ツールを触る前に、**ゴールから逆算する**

- 「何をしたいか（目的）」を先に決め、そこから**逆算**して頼む
- ツールいじりが目的化すると、うまくいかない
- **うまくいかない時は、AIに“改善案”を直接聞く**

> 正解を探すより、**AIと一緒に直していく**のが近道。

# はじめ方は、たった3ステップ

## むずかしい準備はいりません

1. **入れる** … まずは**デスクトップアプリ**をインストール
2. **頼む** … 案件フォルダを作業部屋に。身近な作業を1つお願いする
3. **逆算する** … 「やりたいゴール」から逆算して頼み、**改善はAIに相談**

> まずは **STEP1**。“今日の作業1つ”を任せてみることから。

---

# よくある不安に、先回り

## Q & A

### 「むずかしそう」「情報は大丈夫？」

- **専門知識** … 不要。普段の言葉でOK
- **失敗が怖い** … 重要操作は実行前に確認。下書きから始められる
- **情報の扱い** … 何をしたか記録が残り、人が最終確認

> 不安の正体は「未知」。**一度頼めば**、感覚はすぐ掴めます。
