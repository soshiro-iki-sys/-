# なぜ今、Claude Code なのか

---

# 営業・コンサルの「時間」の正体

## 現状の課題

私たちの一日は、**3種類の作業**に溶けています。

- 📄 **資料づくり** … 提案書・報告書・議事録に毎回 数時間
- 🔍 **調べもの** … 市場・競合・制度のリサーチに半日
- 🔁 **定型作業** … 見積・転記・集計・メールの繰り返し

> 「考える時間」「お客様と向き合う時間」が、作業に押し出されている。

---

# Claude Code とは何か

## ひとことで言うと

### 指示するだけで作業“そのもの”を実行する、**AIの実働部隊**

- 答えを返すだけでなく、**ファイルを作り・調べ・手を動かす**
- 最新のAI「**Claude**」が頭脳。あなたは**指示する側**に回れる
- 開発者向けに生まれたが、**資料・調査・事務**にもそのまま使える

---

# チャットAIとの決定的な違い

## お伝えしたいこと

### 「教えてくれる人」から、**やってくれる人**へ

| | 一般的なチャットAI | **Claude Code** |
|---|---|---|
| やること | 答えを**言う** | 答えを**形にする** |
| 成果物 | 画面上の文章 | **ファイル・資料そのもの** |
| 作業 | 自分で転記・整形 | **AIが直接実行** |

# Claude Code で「できること」

---

# できること① 資料・文書をつくる

## こう使う

### 「○○社向けの提案資料を作って」で、**たたき台が完成**

- 提案スライド／報告書／議事録／お礼メール
- **PDF・PowerPoint** まで書き出し
- このプレゼン資料**そのもの**も Claude Code が作成

---

# できること② 調べて・要約する

## こう使う

### リサーチ → 整理 → **レポート化**まで一気通貫

- 長い資料・議事録を**3行に要約**
- 複数の情報を**比較表**にまとめる
- 「要点だけ」「箇条書きで」など**注文どおり**に整形

---

# できること③ データを処理する

## こう使う

### 集計・転記・整形を**まとめて代行**

- アンケート・売上の**集計とグラフ化**
- バラバラの一覧を**フォーマット統一**
- 「先月との差分を出して」など**分析の下ごしらえ**

---

# できること④ 定型作業を自動化する

## こう使う

### 「いつものやつ、やっておいて」が通じる

- 毎週の報告書づくりを**手順ごと記憶**
- ファイル名の一括変更・仕分け
- **繰り返し作業ほど効果大**

---

# できること⑤ 過去資産を活かす

## こう使う

### 過去資料を**「型」として再利用**

- 優れた過去提案を参照し、**構成・言い回しを踏襲**
- チームの勝ちパターンを**横展開**
- ゼロから書かず、**実績の上に積む**

# Claude Code、5つの強み

---

# 強み① 専門知識はいらない

## ここが効く

### 普段の言葉で**お願いするだけ**

- コマンドも難しい操作も不要
- 「製造業A社向けに」「もっと簡潔に」と**会話で修正**
- **非エンジニアこそ**恩恵が大きい

---

# 強み② 成果物が手元に残る

## ここが効く

### 口頭の助言ではなく、**使えるファイル**が出る

- そのまま提出・編集できる形式で出力
- 「ここだけ直して」も**会話で即対応**
- 作業のやり直し・転記が**激減**

---

# 強み③ チームの“型”を統一できる

## ここが効く

### `CLAUDE.md` に**お作法を書くだけ**

- ブランドカラー・言い回し・構成の型を共有
- **担当者が変わっても品質がブレない**
- 属人的なノウハウが、**チームの資産**に

---

# 強み④ どこでも・任せて放置

## ここが効く

### PC・ブラウザ・**スマホ**から指示できる

- 環境構築なし。**ブラウザを開けば即開始**
- 時間のかかる作業は**任せて別件へ**
- 終わったら**完了を通知**

---

# 強み⑤ 社内の仕組みに“つなげる”

## ここが効く

### 単体で完結せず、**拡張できる**

- 社内ツール・データへ連携（**MCP** という仕組み）
- 繰り返し手順を部品化（**スキル**）
- 「最初に必ず○○する」等の**自動ルール**も設定可能

> 最初は単体で十分。慣れたら**全社の仕組み**に育てられる。

---

# 安心して使える設計

## おさえておきたい

### 暴走しない。**人が主導権を握る**

- 重要・外向きの操作は、**実行前に確認**を取る
- 何をしたかが**記録に残る**（後から確認・レビュー可）
- まず**下書き**を作らせ、人が最終判断

# はじめ方は、たった3ステップ

## むずかしい準備はいりません

1. **開く** … ブラウザで `claude.ai/code` を開く
2. **頼む** … 身近な作業を1つお願いする（例：「この資料を3行で要約して」）
3. **貯める** … うまくいったやり方を `CLAUDE.md` に書き溜める

> 完璧な使い方より、**“今日の作業1つ”**を任せてみることから。

# よくある不安に、先回り

## Q & A

- **専門知識** … 不要。普段の言葉でOK
- **失敗が怖い** … 重要操作は実行前に確認。下書きから始められる

> 不安の正体は「未知」。**一度頼めば**、感覚はすぐ掴めます。
