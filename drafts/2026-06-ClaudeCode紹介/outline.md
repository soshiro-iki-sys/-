# 構成案：Claude Code の良さを徹底解説

> スライドを書く前の骨子。対象＝営業・コンサル（非エンジニア）／ゴール＝「使い始めてもらう」。

## 0. 案件メモ
- 案件名：Claude Code 紹介プレゼン（社内/勉強会向け）
- 相手先：営業・コンサルタント（非エンジニア中心）
- ゴール：聞き終わったその場で「自分も使い始める」気になってもらう
- トーン：専門用語は最小限。「自分の仕事がどう楽になるか」を主役に

## 1. 相手の課題（As-Is）— 営業・コンサルの「時間泥棒」
- 提案資料・報告書の作成に毎回数時間
- 情報収集・リサーチに追われる
- Excel/議事録/メールなど定型作業の繰り返し
- 「考える時間」より「作業の時間」が多い
- ※一番刺さる課題 → 「資料・調べもの・定型作業に時間が溶ける」

## 2. 提案の核（ひとことで言うと）
> Claude Code は「指示するだけで“作業そのもの”を代わりにやってくれる AI の相棒」。
> チャットの賢さ（ChatGPT等）と違い、**実際にファイルを作り・調べ・手を動かす**。

## 3. 提供価値（To-Be）— 5つの良さ
1. **指示するだけ**：会話で頼むだけ。専門知識・コマンド不要
2. **実際に手を動かす**：資料・文書・表を“成果物”として作る（このピッチ自体がその例）
3. **あなたのやり方を覚える**：CLAUDE.md にお作法を書けばチームで品質が揃う
4. **どこでも使える**：PC（ターミナル/アプリ）・ブラウザ・スマホからも
5. **任せて放置できる**：時間のかかる作業を任せ、終わったら通知

## 4. 効果（Before / After）
| 項目 | Before | After |
|------|--------|-------|
| 提案資料1本 | 約3時間 | 約30分 |
| リサーチ＋要約 | 半日 | 数十分 |
| 定型作業 | 手作業の繰り返し | 「いつものやつやって」で完了 |

## 5. 信頼の裏付け（具体例・ユースケース）
- 営業：提案資料・見積・お礼メールのたたき台
- コンサル：リサーチ→要約→レポート化、議事録整理
- 共通：過去資料の再利用、繰り返し作業の自動化
- 実例：この営業資料ワークスペース自体を Claude Code が構築した

## 6. なぜ“今”／他ツールとの違い
- チャット型AI＝答えを「言う」だけ／Claude Code＝答えを形に「する」
- 最新モデル（Claude）搭載・安全性配慮・社内の仕組みにも繋げられる

## 7. 次のアクション（クロージング）＝使い始めてもらう
- ステップ①：ブラウザ（claude.ai/code）で開く
- ステップ②：身近な作業を1つ頼んでみる（「この資料を要約して」等）
- ステップ③：うまくいったお作法を CLAUDE.md に書き溜める
- 「まずは“今日の作業1つ”を頼むだけ」
