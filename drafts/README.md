# drafts/ — 案件ごとの作業フォルダ

ここに **案件（商談）ごとのフォルダ** を切って作業します。

```
drafts/
├── 2026-06-製造業A社/
│   ├── outline.md   ← まず構成案（outline-template.md のコピー）
│   └── index.md     ← スライド本体（standard-pitch.md のコピー）
└── _sample-提案資料/  ← 記入済みのお手本サンプル
    └── index.md
```

## 進め方
1. `drafts/＜日付＞-＜相手先＞/` のフォルダを作る
2. `../templates/outline-template.md` をコピーして構成案を固める
3. `../templates/standard-pitch.md` をコピーしてスライド化
4. 完了した案件は `../archive/` へ移す

> チャットで「○○社向けの資料を作って」と頼めば、私（Claude）がこの手順で進めます。
