## 2. ケアマネジャー・地域包括支援センターの悩みと、遺品整理のシナジー（企画書の業種別ページ）

企画書・提案書・96p版で同じ内容（企画書p65〜66、提案書1-5）。

| 経営課題（ケアマネ・包括の悩み） | 内容 |
|---|---|
| 相談先の不足 | 片付けの専門業者の紹介先がない |
| 高齢者の住環境問題 | 空き家・独居高齢者の家の片付け |
| 家族からの相談増加 | **施設入居・相続などの相談が増加** |
| 業務負担の増加 | 片付け相談の対応に時間を取られる |

| 遺品整理事業参入によるシナジー | 内容 |
|---|---|
| ① 地域課題の解決 | 空き家・放置物件の問題を解決 |
| ② 生前整理への対応 | **施設入居前の整理を支援** |
| ③ 家族支援の強化 | **遠方の家族の負担を軽減** |
| ④ 地域包括ケアとの連携 | 多職種と連携し支援の幅が広がる |

- 業務の流れ：相談対応 → 専門業者の紹介 → 整理・片付け → 関連サービス連携
- まとめ：地域課題の解決／生前整理への対応／家族支援の強化
- 一覧表での要約：「介護（ケアマネ・包括）｜課題：片付けの相談先不足、業務負担の増加｜シナジー：施設入居前の生前整理に対応でき、家族の信頼が上がる｜つながる事業：入居相談・地域連携」（企画書の業種別シナジー一覧）

## 3. 提携先（アライアンス）としての扱い

| 内容 | 出典 |
|---|---|
| 提携先の一覧に「ケアマネジャー・地域包括支援センター」を含む（不動産・士業・葬儀社・解体・リフォーム・ガス会社・役所など） | マニュアル4-1、提案書p45、予測レポート |
| **優先順位はCランク（長期的に開拓）**：「案件化まで時間がかかるが潜在ニーズが大きい／地域との信頼関係構築に役立つ」。A＝不動産・司法書士・行政書士・税理士、B＝葬儀社・解体・リフォーム・保険代理店 | マニュアル4-3 |
| 攻略目標数（人口20万人商圏）：**ケアマネジャー30〜50件／地域包括支援センター5〜10か所**（全体で200〜300件） | マニュアル4-3 |
| 開拓KPI（全業種共通の例）：月50件訪問 → 月10件接触 → 月2件関係構築 → 月1件案件化 | マニュアル4-3 |
| 企画書のアライアンス図にも「ケアマネ・包括支援」。提携の進め方STEP1「地域の不動産会社・士業・葬儀社・**ケアマネ**などを洗い出し、優先順位をつける」 | 企画書（アライアンス提携） |
| 予測レポート：「ケアマネジャー・地域包括支援センター、司法書士、葬儀社などとのアライアンスにより、案件の相互紹介も可能」 | 予測レポート |

### 提携の進め方（全業種共通。ケアマネ・施設にもそのまま使える）

| 項目 | 内容 | 出典 |
|---|---|---|
| 基本スタンス | 最優先は仕事の獲得ではなく「**提携先の信用を守る**」。紹介元が最も恐れるのは「変な業者を紹介して自社の信用を失うこと」 | マニュアル4-2 |
| 言い換え | ✕「仕事をください」→○「お客様のお役に立てます」／✕「一番安くできます」→○「丁寧で誠実な対応をお約束します」 | マニュアル4-2 |
| 初回訪問のゴール | 案件獲得ではなく「**認知獲得**」。資料を置いてもらい、必要なときに思い出してもらう | マニュアル4-4〜4-5 |
| トークの型 | ①挨拶 ②「営業ではなく、御社のお客様のお役に立てるかもしれないと思い」③「遺品整理や生前整理でお困りのお客様がいらっしゃった際に」④資料だけ置かせてほしい ⑤今後のつながり | マニュアル4-4〜4-5 |
| フォロー | 1週間後お礼 → 1か月後再訪 → 2か月後ニュースレター → 3か月後事例共有 → 4か月後相互送客の提案 → 5か月後試験紹介 → 6か月後以降提携化 | マニュアル4-6 |
| 紹介を増やす対応 | 紹介への連絡は30分以内、現調24時間以内、見積り即日〜翌営業日、**紹介元への完了報告**（写真付き） | マニュアル4-8〜4-9 |
| 紹介手数料 | 支払手数料＝紹介による売上・利益×貢献度×手数料率。手数料率の目安：高単価・高粗利5〜15%。契約は試験紹介が出てから | マニュアル4-11〜4-12 |
| 紹介料の目安 | アライアンスの紹介料は**粗利の3〜5%** | DL資料 |

※ 介護施設・ケアマネが紹介料を受け取ってよいかは、法人の方針・制度上の扱いを確認する必要がある（資料には記載なし）

## 6. 資料に書かれていないこと（仮説・要確認）

これまでの資料は「ケアマネ・包括支援センター（紹介元）」と「施設に入居するご家族（お客様）」の目線が中心で、**老人ホーム・介護施設を運営する会社そのものの悩み**はほとんど書かれていない。以下は資料外の仮説なので、使う前にヒアリング・調査で確かめる。

| 区分 | 仮説 | 遺品整理でできること |
|---|---|---|
| 施設の退去時 | 入居者が亡くなった・退去した後、**居室の家財が残り、次の入居者を入れられない**（空室期間＝収入の損失） | 退去後の居室の整理を短期間で行い、空室期間を縮める |
| 施設の退去時 | ご家族が遠方・高齢・不在で、**家財の引き取りが進まない**／身寄りがない方の残置物の扱いに困る | ご家族に代わって仕分け・形見分け・供養・処分を一括で受ける（オンライン見積・立会い不要） |
| 施設の入居前 | 入居が決まっても、**自宅の片付けが進まず入居日が延びる** | 入居前の生前整理・持ち込む家財の選別・搬入まで対応 |
| 施設の職員 | 退去・片付けの相談対応に職員の時間が取られる | 「片付けはこの会社に」という紹介先を持つことで、職員の負担を減らす |
| 入居相談の会社（老人ホーム紹介） | 入居が決まった後の、ご家族の困りごと（実家・空き家）に応えきれていない | 入居後の実家整理・空き家の売却相談までつなぐ（不動産へ） |
| 施設を運営する会社が遺品整理に参入する場合 | 入居者・ご家族との接点を、退去後・相続後の収益につなげられていない | 自社で生前整理・遺品整理を持てば、入居前〜退去後〜実家まで一貫して支援できる（企画書の「退去後の実家整理まで一貫対応」と同じ考え方） |

**確認したいこと**
- 施設の種類（特養・有料老人ホーム・サ高住・グループホーム）ごとの退去時の残置物の扱いと、片付けの期限
- 退去後の空室期間と、その間の収入の損失
- 施設・ケアマネが外部業者を紹介すること、紹介料を受け取ることの可否（法人の方針・制度）
- 介護施設・老人ホーム紹介の会社から遺品整理に参入した事例（資料には見当たらない）
