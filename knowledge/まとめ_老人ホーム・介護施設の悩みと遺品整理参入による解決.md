# 老人ホーム・介護施設を運営する会社の悩みと、遺品整理事業参入による解決

- 対象：有料老人ホーム・サ高住・グループホーム・特養などを運営する会社（介護事業者）
- 根拠の区分：【公的データ】＝統計・公的資料で確認できたもの／【資料】＝これまで学んだ船井総研の資料／【仮説】＝資料・統計で確認できていないもの（ヒアリングで確かめる）

## 1. 介護報酬に頼る収益構造・経営の厳しさ

**悩み**
- 【公的データ】2025年の老人福祉・介護事業の倒産は176件で、2年連続で過去最多。うち有料老人ホームは16件。休廃業・解散は全体で653件（東京商工リサーチ）
- 【仮説】収入の多くが介護報酬と入居費用で、報酬改定や物価・人件費の上昇に左右されやすい。介護保険外の収入源がほしい

**遺品整理参入で変わること**
- 遺品整理・生前整理は介護保険外の自費サービス。【資料】客単価30万円、3年目に年商1億円・営業利益率23.1%のモデル（企画書）
- 報酬改定に左右されない、別の収益の柱になる

## 2. 退去後の居室が空き、次の入居まで時間がかかる

**悩み**
- 【仮説】入居者が亡くなった・退去した後、居室に家財が残り、ご家族の引き取りを待つ間は次の入居者を入れられない。その間の月額費用が入らない（空室の損失）
- 【公的データ】退去時の扱いは契約書・重要事項説明書で定める（老人福祉法に基づき退去事由の明示が義務）。家財の撤去の期限・方法も施設ごとに違う

**遺品整理参入で変わること**
- 自社でご家族に代わって居室の仕分け・形見分け・供養・搬出を短期間で行い、空室期間を縮める
- 試算の例（当日の数字で計算）：月額費用 ○万円 × 縮められる日数 ＝ 1室あたり取り戻せる収入

## 3. 入居が決まっても、自宅の片付けが進まず入居が遅れる

**悩み**
- 【資料】ケアマネ・包括支援センターの悩みに「家族からの**施設入居**・相続などの相談が増加」（企画書）。チラシの相談のきっかけにも「親が施設へ入居した」（一番店マニュアル）
- 【仮説】ご家族が遠方・多忙で自宅の片付けが進まず、入居日が延びる、入居を迷う

**遺品整理参入で変わること**
- 【資料】「入居前の生前整理が必要」「退去後の実家整理まで一貫対応」（企画書の商流図：老人ホーム紹介）
- 入居前の生前整理、施設に持ち込む家財の選別、搬入まで支援し、入居を早める
- 【資料】遠方のご家族にはオンライン見積で、立会いなしで進められる（一番店マニュアル）

## 4. 身寄りのない入居者の、亡くなった後の家財の扱い

**悩み**
- 【公的データ】国は、身元保証人がいないことだけを理由に入所を拒まないよう求めている（消費者委員会の建議、厚労省の通知）。その一方で、亡くなった後の手続きは「死後事務」として、**残置物の処理**・葬儀・関係者への連絡が含まれる（厚労省「高齢者等終身サポート事業者ガイドライン」）
- 【仮説】身寄りのない入居者が亡くなった後、居室の家財の処分を施設が抱え込み、職員の負担と空室の長期化につながっている

**遺品整理参入で変わること**
- 自社に遺品整理の受け皿があれば、後見人・終身サポート事業者・士業と連携して、残置物の処理を適正に進められる
- 【資料】貴重品・権利書の捜索、供養・お焚き上げ、作業前後の写真付き報告（一番店マニュアル）で、関係者への説明責任を果たせる

## 5. 人材不足の中、職員が退去・片付けの対応に時間を取られる

**悩み**
- 【公的データ】介護職員は2026年度に約240万人が必要で、2022年度から約25万人の増加が必要（厚労省、第9期介護保険事業計画に基づく推計）
- 【資料】ケアマネ・包括の悩み「片付け相談の対応に時間を取られる」「片付けの専門業者の紹介先がない」（企画書）
- 【仮説】施設の職員も、退去時のご家族対応・荷物の整理・業者探しに時間を取られている

**遺品整理参入で変わること**
- 片付けを専門の部門・スタッフに任せ、介護職員は介護に集中できる
- 現場作業は介護の資格が要らないため、介護職とは別の採用枠で人を集められる【仮説】

## 6. 入居者の獲得を紹介会社・ケアマネに頼っている

**悩み**
- 【仮説】入居者の獲得を、老人ホーム紹介会社・ケアマネ・病院の地域連携室からの紹介に頼っている。紹介料の負担や、紹介元の確保が課題

**遺品整理参入で変わること**
- 生前整理・実家の片付けの相談は、施設入居を考え始めたご家族と最初に出会える窓口になる（片付けの相談 → 入居相談へ）
- 【資料】ケアマネ・包括との関係が強くなる：「片付けの専門業者の紹介先がない」というケアマネの悩みに、自社が応えられる（企画書のケアマネ・包括のシナジー：家族支援の強化・地域包括ケアとの連携）
- 地域で「入居前から退去後まで任せられる施設」として認知される

## 7. 退去時のご家族とのトラブル・満足度

**悩み**
- 【公的データ】国民生活センターが、有料老人ホームの退去時の修繕費トラブルについて注意を呼びかけている（通常の使用による損耗は原則、入居者の負担にならない）
- 【資料】お客様の不安：費用トラブルが怖い／遠方で立ち会えない／故人の品を雑に扱ってほしくない（一番店マニュアル）

**遺品整理参入で変わること**
- 【資料】明朗会計（定額パック・追加料金なし）、原状回復まで一括、作業前後の写真報告（一番店マニュアル）で、退去時のトラブルを減らす
- 最後まで丁寧に対応することで、ご家族の満足が上がり、口コミ・紹介につながる

## 8. 入居者の実家（空き家）の問題に応えきれない

**悩み**
- 【資料】ケアマネ・包括の悩み「空き家・独居高齢者の家の片付け」（企画書）
- 【仮説】入居後、実家が空き家になり、ご家族から売却・管理の相談を受けても応えられない。実家の売却が入居費用の原資になるケースもある

**遺品整理参入で変わること**
- 【資料】遺品整理は不動産・解体・リフォームへの入口（企画書の商流：出口＝解体・リフォーム・リユース買取・不動産）
- 実家の片付けから、提携する不動産会社への売却・活用の相談までつなぎ、紹介料などの収益も生まれる

## 4つの観点で見たシナジー（個社別ご提案パートの区分）

| 観点 | 介護施設の会社での内容 |
|---|---|
| ① LTVの最大化 | 同じご家族に、入居前の生前整理 → 入居 → 退去後の居室整理 → 実家の整理・売却相談まで一貫して提供できる |
| ② 経営資源 | ご家族との信頼関係、ケアマネ・病院・行政とのつながり、送迎車両などを活かせる |
| ③ 収益・コスト | 介護保険外の自費収入。空室期間の短縮で入居費用の取りこぼしが減る |
| ④ 信頼・ブランド | 「入居前から退去後まで任せられる施設」として、地域で選ばれる |

## 注意点・確認が必要なこと

| 項目 | 内容 |
|---|---|
| 法人の種類 | 社会福祉法人（特養など）は、収益事業に制限がある。株式会社と同じように参入できるかは確認が必要 |
| 入居者への営業 | 入居者・ご家族の弱い立場につけこむ営業と受け取られないよう、案内の仕方・料金の透明性に注意する |
| 個人情報 | 入居者の情報を遺品整理事業で使う場合の同意・取り扱い |
| 紹介料 | 施設・ケアマネが紹介料を受け取ってよいか（法人の方針・制度上の扱い） |
| 許認可 | 買取には古物商、処分は一般廃棄物の許可業者との三社間契約 |
| 仮説の確認 | 2・3・4・6の仮説（空室期間・入居の遅れ・身寄りのない方の家財・紹介依存）は、施設側へのヒアリングで実態を確かめる |
| 事例 | 介護施設の運営会社が遺品整理に参入した事例は、これまでの資料には見当たらない |
