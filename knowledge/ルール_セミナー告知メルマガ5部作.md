# ルール：セミナー告知メルマガ5部作の流れ

- 元にした文章：【遺品整理不動産向け5部作メルマガ】（不動産会社向け「空き家情報を川上で獲得！不動産会社向け遺品整理参入セミナー」の告知、署名：堂野）
- 目的：他の業種（葬儀・解体・介護・便利屋など）向けのセミナー告知でも、同じ型で5部作を作れるようにする

---

## 1. 全体の設計

### 5部作の骨格（読者の疑問の順番に1通ずつ答える）

| 部 | 役割 | 読者の頭の中 | この回で答えること | 次回予告（最後の問い） |
|---|---|---|---|---|
| 1 | **問題提起** | 「何が変わるの？」 | 外部環境の変化で、今のやり方が通用しなくなる。みんなが考える打ち手は競合も同じ。だから「もっと前（川上）」へ | 「では、どうやって“前”のお客様と接点を持つのか？」 |
| 2 | **発想の転換** | 「“前”って誰のこと？」 | 顕在層の取り合いではなく、「まだ決めていない人」と接点を持つ。その人の具体像と、その人がすでに抱えている困りごと | 「本業の相談の“一つ前”にあるビジネスとは？」 |
| 3 | **手段の提示** | 「何で接点を持つの？」 | その入口が遺品整理。お客様の時系列で見せる。「遺品整理で儲けよう」ではなく、目的は本業の入口を持つこと | 「本当に集客できるのか？本業につながるのか？」 |
| 4 | **証拠（事例）** | 「本当にできるの？」 | 実在の会社の数字（事業単体の成果＋本業につながった件数）。読者の会社に置き換えてもらう | 「人がいない会社でも、どうやって作るのか？」 |
| 5 | **障壁の除去＋まとめ** | 「うちでもできる？」 | 作業は外注できる・投資が小さい。最後に「目的は〇〇、遺品整理は手段」をもう一度言い切る | （最終回なので予告なし。セミナーへの申込で締める） |

**ルール1-1**：1通で伝えることは1つだけ。答えは次回に持ち越す（毎回「では、〇〇はどうすればいいのか？」で終える）
**ルール1-2**：前の回の最後の問いに、次の回の冒頭で答える（問いの鎖でつなぐ）
**ルール1-3**：遺品整理という言葉は第3部まで出さない（第1・2部は読者の本業の悩みだけで書く）
**ルール1-4**：一貫したキーワードを1つ決め、全回で繰り返す（不動産版では「川上」）
**ルール1-5**：「目的」と「手段」を分けて言い切る。目的＝読者の本業の成果、手段＝遺品整理（第3部と第5部で2回）

## 2. 各回の書き方

### 第1部：問題提起

| 順番 | 内容 | 不動産版の例 |
|---|---|---|
| ① | 挨拶と署名（会社名・肩書き・名前） | 「遺品整理・空き家整理コンサルタントの堂野です」 |
| ② | 読者への問いかけ（太字1行） | 「2026年10月以降、どのように売却物件を仕入れていきますか？」 |
| ③ | 外部環境の変化（事実・日付・何が変わるか） | 登記受付帳の様式変更で「登記の目的」「不動産所在事項」が削除 |
| ④ | その結果、今のやり方が通用しなくなる | 登記受付帳から相続物件を抽出する営業が難しくなる |
| ⑤ | みんなが考える打ち手を並べる | 一括査定・Web広告・ポータル・DM・自社開拓 |
| ⑥ | 落とし穴：「競合も同じことを考えている」（見出し） | 顕在層の取り合いになる |
| ⑦ | 結論：もっと前へ（キーワードの初出） | 「物件情報が生まれる“川上”へ行く」 |
| ⑧ | 次回予告 | 「どのようにして売却の前のお客様と接点を持つのか？次回お伝えします」 |

### 第2部：発想の転換

| 順番 | 内容 | 不動産版の例 |
|---|---|---|
| ① | 挨拶と署名 | |
| ② | 前回の要約（1〜2行） | 「前回、これから売却物件をどこから仕入れるのか、というお話をしました」 |
| ③ | 今のやり方の共通点（＝顕在層を取っている） | 一括査定もWeb広告も「すでに売りたい人」を獲得する方法 |
| ④ | 発想の転換（見出し） | 「売りたい人を取り合うのではなく、売りたいと思う前の人と接点を持てないか？」 |
| ⑤ | 「前の人」の具体像を3つ（お客様の言葉で） | 「実家を相続したけれど、まだ売るか決めていない」「親が施設に入った」「兄弟で話せていない」 |
| ⑥ | その人がすでに抱えている問題 | 「この家をこれからどうしよう？」 |
| ⑦ | ヒントは「本業の相談より前の困りごと」 | 売却を考える“前”に何に困るのか |
| ⑧ | 次回予告 | 「売却相談の一つ前にあるビジネス」 |

### 第3部：手段の提示

| 順番 | 内容 | 不動産版の例 |
|---|---|---|
| ① | 挨拶と署名 | |
| ② | 前回の要約 | 「売りたいと思う前のお客様と接点を持つ」 |
| ③ | お客様の場面を1つ描く（物の名前を並べて具体的に） | 家具・家電・衣類・食器・生活用品・思い出の品 → 「この家の中をどうしよう…」 |
| ④ | 手段の名前を出す（見出し） | 「遺品整理・実家じまい」 |
| ⑤ | 先回りの否定：「〇〇で儲けましょう、という話ではない」 | 「不動産会社も遺品整理で儲けましょう、という話ではありません」 |
| ⑥ | お客様の時系列（矢印の図） | 相続・施設入居 → 実家が空く → 遺品整理 → 片付く → この家をどうしよう？ → 売却・買取・解体・活用 |
| ⑦ | 本業の接点が1段前に来ることを示す | 「売りたい」の一つ前の「まず片付けたい」から接点 |
| ⑧ | 言い換え（見出し）と、目的と手段の言い切り | 「物件情報を買うのではなく、入口を自社で持つ」「目的は川上で獲得すること。遺品整理は手段」 |
| ⑨ | 読者の疑問を先取り → 次回予告 | 「本当に集客できるのか？」→「月40〜50件集客している会社の事例」 |

### 第4部：証拠（事例）

| 順番 | 内容 | 不動産版の例 |
|---|---|---|
| ① | 挨拶と署名 | |
| ② | これまでの要約と、読者の疑問を代弁（3つ） | 「考え方は分かった」「でも集客できるのか？」「本業につながるのか？」 |
| ③ | 事例の会社（社名は伏せてもよい） | S社様 |
| ④ | 事業単体の成果（売上・利益） | 2年で売上8,000万円・営業利益3,000万円 |
| ⑤ | 「注目してほしいのはここだけではない」で、本業につながる数字へ | 販促費月50〜60万円で、実家じまい案件を月40〜50件 |
| ⑥ | 本業への転換率と年間件数（見出し） | 契約の約10〜20%が不動産仲介・解体へ、年間約50件 |
| ⑦ | 読者の会社に置き換えてもらう問い | 「年間約50件が今のルートとは別に入ってきたら？」 |
| ⑧ | 今のやり方との対比をもう一度 | 一括査定＝売ると決めた人／遺品整理＝どうしようの段階 |
| ⑨ | モデルに名前をつける | 「川上獲得型」の物件仕入れ |
| ⑩ | 次の不安を代弁 → 次回予告 | 「人がいない」「採用が必要では」「設備投資は？」→「人がいない会社でもどう作るか」 |

### 第5部：障壁の除去＋まとめ

| 順番 | 内容 | 不動産版の例 |
|---|---|---|
| ① | 挨拶と署名、4回分の要約 | |
| ② | 不安を代弁（3つ） | 「人がいない」「採用の余裕がない」「大きな投資はできない」 |
| ③ | 結論を見出しで | 「現場作業まで自社で行う必要はありません」 |
| ④ | 外注の流れ（矢印の図） | 自社で集客 → 問い合わせ対応 → 現調・営業 → 実作業は提携業者 → 不動産相談 → 査定 → 仲介・買取 |
| ⑤ | 「持っていただきたいのは作業機能ではなく、最初の接点」 | |
| ⑥ | 投資が小さいことを箇条書き | ショールーム・倉庫・大規模設備が不要、専門HP中心、専門人材の採用を前提としない、実作業は外部と連携 |
| ⑦ | 「新しい会社を作るのではなく、入口を1つ足す」 | |
| ⑧ | 区切り線のあとで最終メッセージ：「〇〇をやりたいかどうかは、今は重要ではない」 | 「遺品整理をやりたいかどうか」ではなく「空き家情報をどこから取るのか」 |
| ⑨ | 目的と手段をもう一度言い切る | 目的＝空き家・相続不動産情報を川上で獲得、遺品整理＝手段 |
| ⑩ | 事例の数字を再掲してセミナーへ | 月50〜60万円で月40〜50件、年間約50件が不動産・解体へ |

## 3. 毎回の共通ルール

### 本文

| ルール | 内容 |
|---|---|
| 書き出し | 毎回同じ挨拶と署名（会社名・肩書き・名前）。第2部以降は「前回、〇〇というお話をしました」で始める |
| 1文の長さ | 1〜2行で改行。1段落は1〜3文。スマホで読む前提 |
| 強調 | 核心の1文は太字、または見出し（###）にする。1通に見出しは2〜4個 |
| お客様の言葉 | 悩みや場面は「」でお客様のセリフとして書く（「実家を相続したけれど…」） |
| 図 | 流れは矢印（↓）の縦並びで見せる（第3部・第5部） |
| 問いかけ | 読者に考えさせる問いを入れる（「御社の事業に置き換えてみてください」） |
| 先回り | 読者が思いそうな疑問・反論を「〜と思われるかもしれません」で代弁し、次回で答える |
| 売り込まない | 本文では申込を求めない。「儲けましょう」「〇〇会社になりましょう」とは言わない |
| 締め | 第1〜4部は次回予告で終える。第5部はまとめで終える |

### セミナー告知ブロック（本文の後、区切り線のあと）

| 順番 | 内容 | ルール |
|---|---|---|
| ① | 区切り線 | 「――――――――」で本文と分ける |
| ② | 見出し | その回の本文のテーマに合わせて言い換える（第1部「空き家情報を川上で獲得する方法を」→第3部「遺品整理を入口に〜」→第4・5部「川上獲得型の物件仕入れモデルを」） |
| ③ | セミナー名 | 毎回同じ（太字） |
| ④ | その回の論点に沿った一文 | 本文で話したことと、セミナーで分かることをつなぐ |
| ⑤ | おすすめの読者（悩みのリスト3〜4つ） | 本業の言葉で書く（「売却物件をもっと仕入れたい」「一括査定サイト以外の仕入れチャネルをつくりたい」など）。毎回ほぼ同じでよい |
| ⑥ | 第3部以降は「〇〇をやりたい会社だけのセミナーではない」 | 遺品整理に関心がない読者も対象だと伝える |
| ⑦ | 第4・5部は事例の数字を再掲 | |
| ⑧ | 申込リンク | 「▼セミナーの詳細・お申し込みはこちら」＋セミナー名のリンク |

### 数字・事実

| ルール | 内容 |
|---|---|
| 外部環境の変化 | 日付と、何が変わるかを正確に書く（例：2026年10月1日、登記受付帳の「登記の目的」「不動産所在事項」が削除） |
| 事例の数字 | 第4部で初めて出し、第5部とセミナー告知で再掲する。事業単体の数字と、本業につながる数字の両方を出す |
| 数字の扱い | 出典のある数字だけを使う。事例は掲載許可を確認する |

## 4. 他の業種に使うときの置き換え表

| 要素 | 不動産版 | 置き換える内容 |
|---|---|---|
| 読者の本業の成果（目的） | 売却物件の仕入れ（空き家・相続不動産情報） | 例：葬儀＝葬儀後のアフター売上、解体＝元請けの解体案件、介護＝入居・退去の支援 |
| 外部環境の変化（第1部） | 登記受付帳の様式変更 | その業種で今のやり方が通用しなくなる事実（日付つき） |
| みんなが考える打ち手（第1部） | 一括査定・Web広告・ポータル・DM | その業種の一般的な集客・営業の打ち手 |
| 「前の人」（第2部） | 売りたいと思う前の人 | 本業の相談をする前の段階のお客様 |
| キーワード（全回） | 川上 | 1語で言えるもの |
| 時系列（第3部） | 相続 → 実家が空く → 遺品整理 → 売却 | お客様が本業にたどり着くまでの流れの中で、遺品整理が手前にあることを示す |
| 事例（第4部） | S社様：月40〜50件、年間約50件が不動産・解体へ | その業種に近い事例の、事業単体の数字と本業への転換の数字 |
| 不安（第5部） | 人がいない・投資できない | その業種の経営者が思いそうな不安 |

## 5. 単発のメルマガ（1通版）にまとめる場合

不動産業績アップメルマガ（11月16日配信分）の構成。5部作を1通に圧縮するときの型。

| 欄 | 入れる内容（5部作のどこから取るか） |
|---|---|
| 件名 | 【対象】＋外部環境の変化（第1部）＋「〇〇する方法とは？」 |
| 挨拶文 | 外部環境の変化（第1部）→ お悩み3つ（「〜…」）→ 顕在層の取り合い（第2部）→ 川上へ・入口として遺品整理（第3部） |
| 見出し1・本文1 | 時系列の矢印（第3部）＋事例の数字（第4部） |
| 見出し2・本文2 | セミナーの講座構成と、読者の本業にとっての意味 |
| 装飾文言 | こんな経営者様におすすめ（3つ）＋最後の一文 |
| 紹介文 | 開催概要（日時・会場・受講料）＋申込リンク＋締めの一文 |

## 6. 確認しておきたい点（元の文章について）

- 5部作の申込リンク（seminar/146268）と、11月16日配信分のリンク（seminar/147234）が違う。セミナー名も「不動産会社向け遺品整理参入セミナー」と「【全業種向け】遺品整理ビジネス新規参入セミナー2027」で異なる。どちらに誘導するかを揃える
- 第4部の事例（S社様：2年で売上8,000万円・営業利益3,000万円）は、これまでの資料の蒼炎様の数字と一致。掲載の許可を確認する
- 「月40〜50件の実家じまい案件」「契約の約10〜20%が不動産仲介・解体へ、年間約50件」の出典（S社様の実績）を確認しておく
