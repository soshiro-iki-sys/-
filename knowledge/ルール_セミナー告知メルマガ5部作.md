# ルール：セミナー告知メルマガ5部作の流れ

- 元にした文章：【遺品整理不動産向け5部作メルマガ】（不動産会社向け「空き家情報を川上で獲得！不動産会社向け遺品整理参入セミナー」の告知、署名：堂野）
- 目的：他の業種（葬儀・解体・介護・便利屋など）向けのセミナー告知でも、同じ型で5部作を作れるようにする

---

## 1. 全体の設計

### 5部作の骨格（感情の流れ：恐怖 → 期待 → 納得 → 具体 → 安心）

| 部 | 役割 | 読者の気持ち | この回で書くこと | 次回予告（最後の問い） |
|---|---|---|---|---|
| 1 | **問題提起（恐怖）** | 「このままだとまずい」 | 外部環境の変化で、今のやり方が通用しなくなる。みんなが考える打ち手は競合も同じで、取り合いになる | 「では、これからどうすればいいのか？」 |
| 2 | **明るい未来（こうなったら良くない？）** | 「そうなれたらいい」 | 恐怖の裏返しの理想の状態を描く。競合と取り合う前に、お客様と出会えている状態（川上） | 「その未来を叶える方法とは？」 |
| 3 | **その未来を叶えるのが遺品整理（なぜ遺品整理なの？）** | 「なるほど、だから遺品整理か」 | お客様の時系列で、遺品整理が本業の“一つ前”にあることを見せる。目的は本業、遺品整理は手段 | 「本当に遺品整理でお客様を集められるのか？」 |
| 4 | **どうやったらできるの？（どのように遺品整理で集客するの？）** | 「具体的にはどうやるの？」 | 遺品整理の集客の仕組みと、実際の数字（販促費 → 案件数 → 本業につながる件数）。事例で証明する | 「でも、うちには人がいない。現場はどうするの？」 |
| 5 | **うちでもできるの？（現場も含めてどう参入する？）** | 「うちでもできそう」 | 参入の形（集客〜営業は自社、作業は外注）、投資の小ささ、立ち上げの進め方。最後に目的と手段をもう一度言い切る | （最終回。セミナーへの申込で締める） |

**ルール1-1**：1通で伝えることは1つだけ。答えは次回に持ち越す（毎回、読者が次に思う問いで終える）
**ルール1-2**：前の回の最後の問いに、次の回の冒頭で答える（問いの鎖でつなぐ）
**ルール1-3**：第2部の「明るい未来」は、第1部の「恐怖」の裏返しで書く（恐怖：取り合いになる → 未来：取り合う前に出会えている）
**ルール1-4**：遺品整理という言葉は第3部まで出さない。第1・2部は読者の本業の言葉だけで書く
**ルール1-5**：一貫したキーワードを1つ決め、全回で繰り返す（不動産版では「川上」）
**ルール1-6**：「目的」と「手段」を分けて言い切る。目的＝読者の本業の成果、手段＝遺品整理（第3部と第5部で2回）
**ルール1-7**：第4部は「集客の方法」と「数字の証明」をセットにする。第5部は「現場」と「投資」の不安に答える

### 元の5部作との対応

| 部 | 新しい役割 | 元の5部作で書かれていたこと |
|---|---|---|
| 1 | 問題提起（恐怖） | 登記受付帳の様式変更 → 一括査定・Web広告は競合も同じ → 取り合い |
| 2 | 明るい未来 | 「売りたいと思う前の人」と接点を持てている状態。「この家をどうしよう？」の段階で出会える |
| 3 | なぜ遺品整理なの？ | 相続 → 実家が空く → 遺品整理 → どうしよう → 売却。遺品整理は川上の入口 |
| 4 | どうやって集客するの？ | S社様：販促費月50〜60万円で月40〜50件、年間約50件が不動産・解体へ |
| 5 | うちでもできるの？ | 集客〜営業は自社、作業は提携業者。ショールーム・倉庫・大規模設備が不要 |

※ 元の第4部は「事例の紹介」が中心で、集客の方法（Web・チラシ・提携など）にはほとんど触れていない。新しい型では、第4部で集客の方法を具体的に書き、その証明として事例の数字を置く

## 2. 各回の書き方

### 第1部：問題提起（恐怖）

| 順番 | 内容 | 不動産版の例 |
|---|---|---|
| ① | 挨拶と署名（会社名・肩書き・名前） | 「遺品整理・空き家整理コンサルタントの堂野です」 |
| ② | 読者への問いかけ（太字1行） | 「2026年10月以降、どのように売却物件を仕入れていきますか？」 |
| ③ | 外部環境の変化（事実・日付・何が変わるか） | 登記受付帳の様式変更で「登記の目的」「不動産所在事項」が削除 |
| ④ | その結果、今のやり方が通用しなくなる | 登記受付帳から相続物件を抽出する営業が難しくなる |
| ⑤ | みんなが考える打ち手を並べる | 一括査定・Web広告・ポータル・DM・自社開拓 |
| ⑥ | 恐怖の核心：「競合も同じことを考えている」（見出し） | 「売りたい人」を集めた時点で、取り合いが始まっている |
| ⑦ | このままだとどうなるか（放っておいた場合） | 仕入れが細る、価格競争になる |
| ⑧ | 次回予告 | 「では、これからどうすればいいのか？」 |

### 第2部：明るい未来（こうなったら良くない？）

| 順番 | 内容 | 不動産版の例 |
|---|---|---|
| ① | 挨拶と署名、前回の要約（1〜2行） | 「前回、これから売却物件をどこから仕入れるのか、というお話をしました」 |
| ② | 恐怖の裏返しの問いかけ（見出し） | 「売りたい人を取り合うのではなく、売りたいと思う前の人と出会えていたら？」 |
| ③ | 理想の状態を具体的に描く | 競合が知る前に、相続・空き家の所有者から相談が来ている |
| ④ | その「前の人」の具体像を3つ（お客様の言葉で） | 「実家を相続したけれど、まだ売るか決めていない」「親が施設に入った」「兄弟で話せていない」 |
| ⑤ | その人たちがすでに抱えている問題 | 「この家をこれからどうしよう？」 |
| ⑥ | 未来が叶ったときの本業の変化 | 査定を依頼される前から関係ができ、取り合いにならない |
| ⑦ | キーワードで言い切る（見出し） | 「物件情報が生まれる“川上”で出会う」 |
| ⑧ | 次回予告 | 「その未来を叶える、売却相談の一つ前にあるビジネスとは？」 |

### 第3部：その未来を叶えるのが遺品整理（なぜ遺品整理なの？）

| 順番 | 内容 | 不動産版の例 |
|---|---|---|
| ① | 挨拶と署名、前回の要約 | 「売りたいと思う前のお客様と出会う」 |
| ② | お客様の場面を1つ描く（物の名前を並べて具体的に） | 家具・家電・衣類・食器・生活用品・思い出の品 → 「この家の中をどうしよう…」 |
| ③ | 手段の名前を出す（見出し） | 「遺品整理・実家じまい」 |
| ④ | 先回りの否定 | 「不動産会社も遺品整理で儲けましょう、という話ではありません」 |
| ⑤ | お客様の時系列（矢印の図）で「なぜ遺品整理か」を示す | 相続・施設入居 → 実家が空く → 遺品整理 → 片付く → この家をどうしよう？ → 売却・買取・解体・活用 |
| ⑥ | 本業の接点が1段前に来ることを示す | 「売りたい」の一つ前の「まず片付けたい」から接点 |
| ⑦ | 目的と手段の言い切り（見出し） | 「目的は空き家情報を川上で獲得すること。遺品整理は手段」 |
| ⑧ | 次回予告 | 「では、遺品整理でどうやってお客様を集めるのか？」 |

### 第4部：どうやったらできるの？（どのように遺品整理で集客するの？）

| 順番 | 内容 | 不動産版の例・入れる要素 |
|---|---|---|
| ① | 挨拶と署名、読者の疑問を代弁 | 「考え方は分かった。でも本当に集客できるのか？」 |
| ② | 集客の方法（3本柱）を具体的に | Web（専門HP・SEO・MEO・リスティング）／チラシ（保存版）／提携（司法書士・税理士・葬儀社・ケアマネ） |
| ③ | なぜ遺品整理は集客しやすいのか | 「遺品整理 地域名」で探す人は最初から家一棟の相談。不動産の一括査定ほど取り合いになっていない（一番店が不在） |
| ④ | 証明としての事例（売上・利益） | S社様：2年で売上8,000万円・営業利益3,000万円 |
| ⑤ | 集客の数字（見出し） | 販促費月50〜60万円で、実家じまい案件を月40〜50件 |
| ⑥ | 本業につながる数字 | 契約の約10〜20%が不動産仲介・解体へ、年間約50件 |
| ⑦ | 読者の会社に置き換えてもらう問い | 「年間約50件が、今のルートとは別に入ってきたら？」 |
| ⑧ | 次の不安を代弁 → 次回予告 | 「人がいない」「現場作業は？」「投資は？」→「うちでもできるのか？」 |

### 第5部：うちでもできるの？（現場も含めてどう参入する？）

| 順番 | 内容 | 不動産版の例 |
|---|---|---|
| ① | 挨拶と署名、4回分の要約 | |
| ② | 不安を代弁（3つ） | 「人がいない」「採用の余裕がない」「大きな投資はできない」 |
| ③ | 結論を見出しで | 「現場作業まで自社で行う必要はありません」 |
| ④ | 参入の形（矢印の図） | 自社で集客 → 問い合わせ対応 → 現調・営業 → 実作業は提携業者 → 不動産相談 → 査定 → 仲介・買取 |
| ⑤ | 「持っていただきたいのは作業機能ではなく、最初の接点」 | |
| ⑥ | 投資が小さいことを箇条書き | ショールーム・倉庫・大規模設備が不要、専門HP中心、専門人材の採用を前提としない、実作業は外部と連携 |
| ⑦ | 立ち上げの進め方（あれば） | 例：6か月で提携先の開拓 → 専門HP → 集客・営業開始 |
| ⑧ | 「新しい会社を作るのではなく、入口を1つ足す」 | |
| ⑨ | 区切り線のあとで最終メッセージ | 「遺品整理をやりたいかどうか」ではなく「空き家情報をどこから取るのか」 |
| ⑩ | 目的と手段をもう一度言い切り、事例の数字を再掲してセミナーへ | |

## 3. 毎回の共通ルール

### 本文

| ルール | 内容 |
|---|---|
| 書き出し | 毎回同じ挨拶と署名（会社名・肩書き・名前）。第2部以降は「前回、〇〇というお話をしました」で始める |
| 1文の長さ | 1〜2行で改行。1段落は1〜3文。スマホで読む前提 |
| 強調 | 核心の1文は太字、または見出し（###）にする。1通に見出しは2〜4個 |
| お客様の言葉 | 悩みや場面は「」でお客様のセリフとして書く（「実家を相続したけれど…」） |
| 図 | 流れは矢印（↓）の縦並びで見せる（第3部・第5部） |
| 問いかけ | 読者に考えさせる問いを入れる（「御社の事業に置き換えてみてください」） |
| 先回り | 読者が思いそうな疑問・反論を「〜と思われるかもしれません」で代弁し、次回で答える |
| 売り込まない | 本文では申込を求めない。「儲けましょう」「〇〇会社になりましょう」とは言わない |
| 締め | 第1〜4部は次回予告で終える。第5部はまとめで終える |

### セミナー告知ブロック（本文の後、区切り線のあと）

| 順番 | 内容 | ルール |
|---|---|---|
| ① | 区切り線 | 「――――――――」で本文と分ける |
| ② | 見出し | その回の本文のテーマに合わせて言い換える（第1部「空き家情報を川上で獲得する方法を」→第3部「遺品整理を入口に〜」→第4・5部「川上獲得型の物件仕入れモデルを」） |
| ③ | セミナー名 | 毎回同じ（太字） |
| ④ | その回の論点に沿った一文 | 本文で話したことと、セミナーで分かることをつなぐ |
| ⑤ | おすすめの読者（悩みのリスト3〜4つ） | 本業の言葉で書く（「売却物件をもっと仕入れたい」「一括査定サイト以外の仕入れチャネルをつくりたい」など）。毎回ほぼ同じでよい |
| ⑥ | 第3部以降は「〇〇をやりたい会社だけのセミナーではない」 | 遺品整理に関心がない読者も対象だと伝える |
| ⑦ | 第4・5部は事例の数字を再掲 | |
| ⑧ | 申込リンク | 「▼セミナーの詳細・お申し込みはこちら」＋セミナー名のリンク |

### 数字・事実

| ルール | 内容 |
|---|---|
| 外部環境の変化 | 日付と、何が変わるかを正確に書く（例：2026年10月1日、登記受付帳の「登記の目的」「不動産所在事項」が削除） |
| 事例の数字 | 第4部で初めて出し、第5部とセミナー告知で再掲する。事業単体の数字と、本業につながる数字の両方を出す |
| 数字の扱い | 出典のある数字だけを使う。事例は掲載許可を確認する |

## 4. 他の業種に使うときの置き換え表

| うちでもできる？（第5部） | 人がいない・投資できない → 作業は外注、投資は小さい | その業種の経営者が思いそうな不安と、参入の形 |

## 5. 単発のメルマガ（1通版）にまとめる場合

不動産業績アップメルマガ（11月16日配信分）の構成。5部作を1通に圧縮するときの型。

| 欄 | 入れる内容（5部作のどこから取るか） |
|---|---|
| 件名 | 【対象】＋外部環境の変化（第1部）＋「〇〇する方法とは？」 |
| 挨拶文 | 外部環境の変化（第1部）→ お悩み3つ（「〜…」）→ 顕在層の取り合い（第2部）→ 川上へ・入口として遺品整理（第3部） |
| 見出し1・本文1 | 時系列の矢印（第3部）＋事例の数字（第4部） |
| 見出し2・本文2 | セミナーの講座構成と、読者の本業にとっての意味 |
| 装飾文言 | こんな経営者様におすすめ（3つ）＋最後の一文 |
| 紹介文 | 開催概要（日時・会場・受講料）＋申込リンク＋締めの一文 |

## 6. 確認しておきたい点（元の文章について）

- 5部作の申込リンク（seminar/146268）と、11月16日配信分のリンク（seminar/147234）が違う。セミナー名も「不動産会社向け遺品整理参入セミナー」と「【全業種向け】遺品整理ビジネス新規参入セミナー2027」で異なる。どちらに誘導するかを揃える
- 第4部の事例（S社様：2年で売上8,000万円・営業利益3,000万円）は、これまでの資料の蒼炎様の数字と一致。掲載の許可を確認する
- 「月40〜50件の実家じまい案件」「契約の約10〜20%が不動産仲介・解体へ、年間約50件」の出典（S社様の実績）を確認しておく
