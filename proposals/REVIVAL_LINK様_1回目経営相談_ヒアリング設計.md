# REVIVAL LINK株式会社様　1回目経営相談　ヒアリング項目と話の流れ

## この商談の位置づけ

- **ゴール：** 個社別ご提案パート（ひな形15枚）を埋めるための情報を集め、**2回目の経営相談（ご提案）のアポを取る**
- **時間：** 60分（オンライン想定）
- **姿勢：** 売り込まない。「資料・セミナーのお礼と、貴社に当てはめたときの疑問の整理」という体裁（経営相談マニュアルの初回の考え方）。数字や社内事情を初回から深く追及しすぎない
- **使う資料：** 企画書（前半）から必要なページだけ。個社別パートのひな形は**見せない**（手元で埋めるためのメモとして使う）

## 各パートのヒアリング項目

### 1. オープニング（3分）

- お礼：資料ダウンロード（またはセミナー）へのお礼
- 本日の目的：「資料だけでは、貴社にどう当てはまるかイメージしづらい部分もあると思います。本日は貴社の状況を伺い、疑問を整理する時間にさせてください」
- 進め方：前半は貴社のことを伺い、途中で遺品整理事業の概要を少しだけご説明し、最後に質問を伺う

### 2. きっかけを伺う（5分）　→ ひな形3（目的）の材料

| 優先・聞くこと | 質問例 | ひな形のどこに使うか |
|---|---|---|
| ◎ 関心を持ったきっかけ | 「今回、遺品整理の資料をご覧いただいた一番のきっかけは何でしたか？」 | 3：目的 |
| ○ 気になった内容 | 「資料の中で特に気になった部分や数字はありましたか？（空き家の仕入れ、残置物、収益モデルなど）」 | 3・6 |
| ◎ 検討の段階 | 「今は情報収集の段階ですか、それとも具体的に始める方向で検討されていますか？」 | 14（時期） |
| △ これまでの検討 | 「遺品整理や片付けの事業について、これまで社内で話が出たことはありますか？」 | 3 |

### 4. 遺品整理事業の概要をお伝えする（7分）

伝えるのは判断材料だけ。詳しい事業計画やご支援内容は2回目に回す。

1. 市場性：3つの波（死亡数・空き家・相続登記の義務化）、2027年は地域一番店が不在の成長期
2. 許可：一般廃棄物の許可がなくても、三社間契約で始められる
（事業モデル・商流は2回目に回す。聞かれたら「3年1億円のモデルがあるので、次回貴社の数字に置き換えてお持ちします」と答える）

→ 説明の後に「ここまでで、貴社の事業に当てはめたときに気になる点はありますか？」と聞き、5へつなぐ

### 5. 課題と目的を伺う（18分）　→ ひな形3（目的）、4（課題）、6（シナジー）

**課題（ひな形4）**

| 優先・聞くこと | 質問例 |
|---|---|
| ◎ 空き家事業の課題 | 「空き家の買取・再生で、今いちばん困っていることは何ですか？（仕入れ・競合・スピード・コストなど）」 |

**目的（ひな形3）**

| 優先・聞くこと | 質問例 |
|---|---|
| ◎ 一番の目的 | 「もし遺品整理を始めるとしたら、一番の目的は何になりそうですか？（空き家の仕入れを増やす／残置物のコストを下げる／新しい収益の柱にする など）」 |
| ◎ 位置づけ | 「遺品整理は、本業の入口として考えたいですか？それとも単体でも利益を出す事業として育てたいですか？」 |
| ○ 成功のイメージ | 「3年後、遺品整理がどうなっていれば“やってよかった”と言えますか？」 |

**シナジーの確認（ひな形6・7）**：時間があれば1〜2問だけ。伺った内容をもとに、4つの観点（LTVの最大化／経営資源／収益・コスト／信頼・ブランド）のどれが強そうかを、その場で確かめる
- 「片付けで出会ったお客様から、売却や買取の相談が出てきたら、貴社で受けられそうですか？」
- 「ポスティングで遺品整理のチラシを配ることはできそうですか？」
- 「民泊・シェアハウスのスタッフや清掃の体制を、片付けにも使えそうですか？」

### 6. 進め方の前提を伺う（5分）　→ ひな形7・8（スキーム）、14（数値計画）

◎の2問だけは必ず聞き、残りは「始めるうえで一番気になることは何ですか？」の1問で一番のネックを特定する。

| 優先・要因 | 質問例 | ひな形 |
|---|---|---|
| ◎ 時期 | 「始めるとしたら、いつ頃を考えられますか？」 | 14：スケジュール |
| ◎ キーマン | 「社内で担当される方のお心当たりはありますか？（兼任でもよい）」 | 14：体制 |
| ○ プラン | 「現場の作業は、自社でやりたいですか？外注でもよいですか？」 | 8：外注スキーム |
| △ お金 | 「新しい事業にかける投資の考え方（上限や回収の目安）はありますか？」 | 14 |
| ○ 会社 | 「本業（空き家買取）のブランドと分けたいか、一緒に打ち出したいか、お考えはありますか？」 | 13：事業コンセプト（屋号） |
| △ 競合 | 「エリア内で、気になっている片付け・遺品整理の会社はありますか？」 | 10〜12：競合調査 |

### 7. まとめと次回のご提案（7分）

1. 伺った内容を、目的 → 課題 → シナジーの順に1分で復唱する（認識のずれを防ぐ）
2. 次回の約束：
   > 「本日はありがとうございました。資料だけでは、貴社にどう当てはまるか分かりにくかったと思います。次回、本日伺った内容をもとに、**貴社のエリアの競合調査と、貴社専用の事業の進め方・数値計画**をまとめてお持ちします。情報収集の一環として、見ていただくだけでも構いません。」
3. 日程をその場で決める（2〜3週間後）
4. 次回までにお願いしたいこと（可能な範囲で）：残置物整理の年間件数と外注費、対応エリア、民泊・シェアハウスの物件数
