# REVIVAL LINK株式会社様　1回目経営相談　ヒアリング項目と話の流れ

## この商談の位置づけ

- **ゴール：** 個社別ご提案パート（ひな形15枚）を埋めるための情報を集め、**2回目の経営相談（ご提案）のアポを取る**
- **時間：** 60〜90分（オンライン想定）
- **姿勢：** 売り込まない。「資料・セミナーのお礼と、貴社に当てはめたときの疑問の整理」という体裁（経営相談マニュアルの初回の考え方）。数字や社内事情を初回から深く追及しすぎない
- **使う資料：** 企画書（前半）から必要なページだけ。個社別パートのひな形は**見せない**（手元で埋めるためのメモとして使う）

### 事前に分かっていること（公式サイトより）

| 項目 | 内容 |
|---|---|
| 会社 | 世田谷区尾山台、代表取締役 山内将義、2012年創業、資本金2,300万円、宅建業 東京都知事（1） |
| 事業 | ①空き家買取・再生活用 ②インバウンド民泊・シェアハウス運営 ③不動産売買・収益物件サポート ④通信サービス ⑤ポスティング・販促支援 |
| 遺品整理との接点 | 空き家買取で「残置物の整理や権利関係の複雑な案件も柔軟に対応」、相続不動産を扱い士業と連携 |
| 分からないこと | 売上構成、人員、対応エリア、残置物整理を自社でやっているか外注か、年間の買取件数、古物商許可の有無、遺品整理に関心を持ったきっかけ |

→ 事前準備：世田谷区（＋周辺区）の人口・世帯数・高齢化率を調べておく（ひな形9枚目）。競合調査は商談後に行う（エリアを聞いてから）

## 各パートのヒアリング項目

### 1. オープニング（5分）

- お礼：資料ダウンロード（またはセミナー）へのお礼
- 本日の目的：「資料だけでは、貴社にどう当てはまるかイメージしづらい部分もあると思います。本日は貴社の状況を伺い、疑問を整理する時間にさせてください」
- 進め方：前半は貴社のことを伺い、途中で遺品整理事業の概要を少しだけご説明し、最後に質問を伺う

### 2. きっかけを伺う（10分）　→ ひな形3（目的）の材料

| 聞くこと | 質問例 | ひな形のどこに使うか |
|---|---|---|
| 関心を持ったきっかけ | 「今回、遺品整理の資料をご覧いただいた一番のきっかけは何でしたか？」 | 3：目的 |
| 気になった内容 | 「資料の中で特に気になった部分や数字はありましたか？（空き家の仕入れ、残置物、収益モデルなど）」 | 3・6 |
| 検討の段階 | 「今は情報収集の段階ですか、それとも具体的に始める方向で検討されていますか？」 | 14（時期） |
| これまでの検討 | 「遺品整理や片付けの事業について、これまで社内で話が出たことはありますか？」 | 3 |

### 3. 貴社の現状を伺う（20分）　→ ひな形2（現状）、5（つながり図）

サイトで分かっていることを先に伝え、「この理解で合っていますか？」と確認する形で進める（相手が答えやすい）。

| 聞くこと | 質問例 | ひな形 |
|---|---|---|
| 事業構成 | 「5つの事業をされていますが、今の売上の柱はどの事業ですか？だいたいの割合を教えていただけますか？」 | 2：事業構成 |
| 空き家買取の規模 | 「空き家の買取・再生は、年間でどのくらいの件数を扱われていますか？」 | 2・14 |
| 仕入れルート | 「空き家や相続物件の情報は、主にどこから入ってきますか？（紹介・ポータル・登記情報・自社の集客など）」 | 4（課題）・6 |
| 対応エリア | 「主にどのエリアで事業をされていますか？世田谷区が中心ですか？」 | 9（商圏）・競合調査 |
| 民泊・シェアハウス | 「民泊・シェアハウスは何棟くらい運営されていますか？物件はご自身で買い取ったものですか？」 | 5・6 |
| ポスティング事業 | 「ポスティングは自社スタッフで配布されていますか？どのくらいの範囲・部数を配れますか？」 | 6（集客）・7 |
| 士業との連携 | 「税理士・司法書士・弁護士の先生とは、どのような形で連携されていますか？」 | 6・7 |
| 体制 | 「社員の方は何名くらいですか？現場に出られる方、営業の方はそれぞれ何名ですか？」 | 2・8・14 |
| 車両・倉庫 | 「トラックや倉庫はお持ちですか？」 | 2・8 |
| 許認可 | 「古物商の許可はお持ちですか？」 | 2・8 |
| 強み（称賛から） | 「空き家の買取から再生・運営まで一社でできる会社は多くないと思います。お客様から選ばれている理由は何だと思われますか？」 | 2：強み |
| 今後の目標 | 「3年後、5年後に、会社全体としてどのくらいの規模を目指されていますか？」 | 3：実現できたときの状態 |

### 4. 遺品整理事業の概要をお伝えする（15分）

伝えるのは判断材料だけ。詳しい事業計画やご支援内容は2回目に回す。

1. 市場性：3つの波（死亡数・空き家・相続登記の義務化）、2027年は地域一番店が不在の成長期
2. 事業モデル：商圏20万人・客単価30万円で3年1億円のモデル（※モデル数値と明示）
3. 商流：遺品整理は、売却・解体・リフォームの「前」でお客様と出会える
4. 許可：一般廃棄物の許可がなくても、三社間契約で始められる

→ 説明の後に「ここまでで、貴社の事業に当てはめたときに気になる点はありますか？」と聞き、5へつなぐ

### 5. 課題と目的を伺う（20分）　→ ひな形3（目的）、4（課題）、6（シナジー）

**課題（ひな形4）**

| 聞くこと | 質問例 |
|---|---|
| 空き家事業の課題 | 「空き家の買取・再生で、今いちばん困っていることは何ですか？（仕入れ・競合・スピード・コストなど）」 |
| 仕入れの変化 | 「相続物件の情報の取り方で、最近変わってきたことはありますか？」（※2026年10月の不動産登記受付帳の様式変更に触れる） |
| 残置物整理の現状 | 「買い取った物件の残置物は、今は自社で片付けていますか？外注ですか？」 |
| 残置物の件数・費用 | 「年間何件くらい、1件あたりいくらくらいかかっていますか？」（※答えにくそうなら「だいたいで」） |
| 残置物の困りごと | 「外注先の日程や費用、対応の質で困ったことはありますか？」 |
| 民泊・シェアハウスの課題 | 「家具・家電の調達や、清掃・内装の手配で手間がかかっていることはありますか？」 |

**目的（ひな形3）**

| 聞くこと | 質問例 |
|---|---|
| 一番の目的 | 「もし遺品整理を始めるとしたら、一番の目的は何になりそうですか？（空き家の仕入れを増やす／残置物のコストを下げる／新しい収益の柱にする など）」 |
| 位置づけ | 「遺品整理は、本業の入口として考えたいですか？それとも単体でも利益を出す事業として育てたいですか？」 |
| 成功のイメージ | 「3年後、遺品整理がどうなっていれば“やってよかった”と言えますか？」 |

**シナジーの確認（ひな形6・7）**：伺った内容をもとに、4つの観点（LTVの最大化／経営資源／収益・コスト／信頼・ブランド）のどれが強そうかを、その場で確かめる
- 「片付けで出会ったお客様から、売却や買取の相談が出てきたら、貴社で受けられそうですか？」
- 「ポスティングで遺品整理のチラシを配ることはできそうですか？」
- 「民泊・シェアハウスのスタッフや清掃の体制を、片付けにも使えそうですか？」

### 6. 進め方の前提を伺う（10分）　→ ひな形7・8（スキーム）、14（数値計画）

7つの阻害要因のうち、どれが一番のネックかを特定する（全部を聞かなくてよい）。

| 要因 | 質問例 | ひな形 |
|---|---|---|
| 時期 | 「始めるとしたら、いつ頃を考えられますか？」 | 14：スケジュール |
| キーマン | 「社内で担当される方のお心当たりはありますか？（兼任でもよい）」 | 14：体制 |
| プラン | 「現場の作業は、自社でやりたいですか？外注でもよいですか？」 | 8：外注スキーム |
| お金 | 「新しい事業にかける投資の考え方（上限や回収の目安）はありますか？」 | 14 |
| 会社 | 「本業（空き家買取）のブランドと分けたいか、一緒に打ち出したいか、お考えはありますか？」 | 13：事業コンセプト（屋号） |
| 競合 | 「エリア内で、気になっている片付け・遺品整理の会社はありますか？」 | 10〜12：競合調査 |

### 7. まとめと次回のご提案（10分）

1. 伺った内容を、目的 → 課題 → シナジーの順に1分で復唱する（認識のずれを防ぐ）
2. 次回の約束：
   > 「本日はありがとうございました。資料だけでは、貴社にどう当てはまるか分かりにくかったと思います。次回、本日伺った内容をもとに、**貴社のエリアの競合調査と、貴社専用の事業の進め方・数値計画**をまとめてお持ちします。情報収集の一環として、見ていただくだけでも構いません。」
3. 日程をその場で決める（2〜3週間後）
4. 次回までにお願いしたいこと（可能な範囲で）：残置物整理の年間件数と外注費、対応エリア、民泊・シェアハウスの物件数
