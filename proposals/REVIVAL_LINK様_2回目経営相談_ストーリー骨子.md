## 第1章：事業参入の目的と全体像（2スライド）

### P.1｜本提案の趣旨：遺品整理事業に参入する「真の目的」

**メッセージ**
遺品整理は単なる片付け業ではなく、「不動産・民泊物件を市場流通前の最上流（売主直）で自動仕入れする装置」である。

**レイアウト**
左右2分割の対比図。中央に「➔」の大きな矢印。下部に結論の帯。左は灰色系（従来）、右は紺・赤系（本モデル）で色を分ける。

**掲載内容**

| | 【左側：従来の商流】 | 【右側：本モデルの商流】 |
|---|---|---|
| 入口 | 業者回り・出物待ち | 遺族からの「実家の片付け相談（Web）」 |
| 流れの図 | 売主 → 仲介業者 → 買取業者（業者回り）→ 貴社 | 遺族 → Web問い合わせ → 貴社（片付け）→ 物件の相談 |
| 物件と出会うタイミング | 売却が決まった後（市場流通後） | 売却を決める前（市場流通前・最上流） |
| 結果 | 競合多数・中途半端な仕入れ・価格競争 | 競合ゼロで空き家・不動産・残置物を直接捕捉 |

- 【結論】（下部の帯）：「片付けで即日利益」＋「売主直の優良物件をノーリスク選別」

**トークのポイント**
- 前回、社長からいただいた2つのお言葉を起点にする
  - 「不用品回収は売買が決まった後。遺品整理はその手前で取れる」が腹落ちした
  - 一番良い仕入れは、遺品整理業者からの紹介だった（2,300万円で仕入れ、約1か月で3,500万円で売却）
- 「その“紹介”を、自社で毎月つくれる状態にするのが今回のご提案です」とつなぐ

### P.4｜解決策①【財務・エリア】：在庫リスクゼロで即日キャッシュ化＆都内近郊の反響獲得

**メッセージ**
現金を寝かせず日銭を作り、足を使った飛び込みから「Web反響仕入れ」へシフト。

**レイアウト**
左右2ブロック。左＝財務（キャッシュの流れ図）、右＝エリア（集客の流れ図）。上部に「Before → After」の小さな比較を置く。

**掲載内容**

| | 先出しキャッシュゼロ（財務） | 都内オフィスの利点を活用（エリア） |
|---|---|---|
| 内容 | 片付け完了時に代金回収 | Web・MEOにより集客 |
| ポイント | 粗利約18万円/件。在庫リスクなし | 「都内在住で実家（都内・近郊・北関東）の処分に困っている売主」を直接集客 |
| 図 | 受注 → 作業 → 完了時に入金（現金が寝ない） | 都内の売主 → Web検索・マップ → 貴社（都内オフィス） |

- Before → After
  - 財務：物件を買って在庫を持つ → 片付けで先に現金が入る
  - エリア：足を使った業者回り（北関東） → Web反響で売主から相談が来る（都内・近郊）

**トークのポイント**
- 実家が北関東でも、相続した子どもは都内に住んでいるケースが多い。都内でWeb集客すれば、北関東の物件にも出会える
- 片付けは物件を買わないので、融資や現金を使わずに始められる

### P.5｜解決策②【組織体制】：属人化を排除する「組織営業（0次接客・即時見積）」

**メッセージ**
営業マンの力量や独立に左右されず、誰でも成約率80%を叩き出す型を導入。

**レイアウト**
左から右への営業フロー図（問い合わせ → 0次接客 → 現地調査・即時見積 → 即決クロージング）。各段階の下に「使う仕組み」を記載。

**掲載内容**

| 段階 | 仕組み | 内容 |
|---|---|---|
| 問い合わせ直後 | 0次接客（電話） | 5分以内の初回コールでヒアリング・写真送付誘導 |
| 現場調査 | 即時見積Excelシート | 平米・間取り・荷物量を入れるだけで、その場で見積提示 |
| クロージング | 即決クロージング | その場で金額が出るので、即決につながる |

- 下部の帯：営業マンの力量・独立に左右されない → 誰でも成約率80%

**トークのポイント**
- 前回の「営業1人で月1件、育っても独立した方が得になる」という課題への回答
- 型があるので、担当者が替わっても同じ品質で営業できる

### P.6｜解決策③【民泊連携】：主力事業「民泊（年商1億）」との強力な相乗効果

**メッセージ**
他社には絶対に真似できない「空き家×民泊転用×家具リユース」の独自モデル。

**レイアウト**

**掲載内容**

| 観点 | 内容 |
|---|---|
| 物件仕入れ | 売却に困る空き家・古民家を安価に買取・サブリースし、インバウンド民泊へ転用 |
