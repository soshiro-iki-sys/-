## 第1部：問題提起（恐怖）

**件名案**：介護事業の倒産、2年連続で過去最多。介護報酬“だけ”に頼る経営は、これからも続けられますか？

| 順番 | 書くこと |
|---|---|
| ① | 挨拶と署名 |
| ② | 問いかけ（太字）：「介護報酬が下がったとき、次の一手はありますか？」 |
| ③ | 事実：2025年の老人福祉・介護事業の倒産は176件で、2年連続で過去最多。休廃業・解散は653件（東京商工リサーチ） |
| ④ | 事実：介護職員は2026年度に約240万人が必要で、2022年度から約25万人の増員が必要（厚労省） |
| ⑤ | みんなが考える打ち手を並べる：加算の取得、稼働率アップ、新規施設の開設、紹介会社への依存 |
| ⑥ | 恐怖の核心（見出し）：「どれも“介護保険の中”の打ち手。報酬改定と人材不足の影響を同じように受ける」 |
| ⑦ | このままだとどうなるか：報酬・物価・人件費の変化がそのまま経営を直撃する |
| ⑧ | 次回予告：「では、介護保険に頼らない柱を、どうつくるのか？」 |

**セミナー告知ブロックの見出し**：「介護保険の“外”に柱をつくる方法を、セミナーで解説します」
**おすすめの読者**：介護報酬に頼らない収益源がほしい／空室・入居率に悩んでいる／ご家族への支援を強化したい

## 第2部：明るい未来（こうなったら良くない？）

**件名案**：入居の“前”から、退去の“後”まで。ご家族に頼られ続ける施設になれたら？

| 順番 | 書くこと |
|---|---|
| ① | 挨拶と署名、前回の要約（介護保険の中の打ち手だけでは限界） |
| ② | 恐怖の裏返しの問いかけ（見出し）：「もし、介護保険の“外”に、もう1本の柱があったら？」 |
| ③ | 理想の状態を描く：報酬改定があっても、自費の収入が経営を支えている |
| ④ | ご家族の具体像を3つ（お客様の言葉で）：「入居は決まったけど、実家の片付けが終わらない」「母が亡くなって、部屋の荷物を引き取りに行けない」「父が施設に入って、実家が空き家になった」 |
| ⑤ | その人たちは、すでに施設の目の前にいる（入居者のご家族） |
| ⑥ | 未来が叶ったときの変化：入居がスムーズに進む、居室がすぐ次の方に使える、ご家族から感謝され紹介が増える |
| ⑦ | キーワードで言い切る（見出し）：「入居の前と退去の後。介護保険の“外”で、ご家族を支える」 |
| ⑧ | 次回予告：「その未来を叶える、介護と地続きのビジネスとは？」 |

## 第3部：その未来を叶えるのが遺品整理（なぜ遺品整理なの？）

**件名案**：ご家族が施設に相談できずに困っていること。それが、介護保険の“外”の入口です

| 順番 | 書くこと |
|---|---|
| ① | 挨拶と署名、前回の要約 |
| ② | 場面を描く：入居者が亡くなった後の居室。衣類、家具、写真、手紙……ご家族は遠方で、すぐには来られない |
| ③ | 手段の名前を出す（見出し）：「遺品整理・生前整理」 |
| ④ | 先回りの否定：「介護施設が片付け屋さんになりましょう、という話ではありません」 |
| ⑤ | ご家族の時系列（矢印の図）：施設入居の決定 → 自宅の片付け（生前整理）→ 入居 → 退去・ご逝去 → 居室の整理（遺品整理）→ 実家の整理 → 売却・解体（提携先へ） |
| ⑥ | なぜ遺品整理か（3つ） ・入居者とご家族の困りごとの真ん中にある ・介護保険の外の自費サービス（客単価30万円の事例も） ・入居の前と退去の後の、どちらにも関われる |
| ⑦ | 目的と手段の言い切り（見出し）：「目的は介護保険の外の柱と、入居率を守ること。遺品整理は手段」 |
| ⑧ | 次回予告：「施設の会社が、本当に遺品整理でお客様を集められるのか？」 |

## 第4部：どうやったらできるの？（どのように遺品整理で集客するの？）

**件名案**：広告より先に、もう接点はあります。介護事業者だからできる遺品整理の集め方

| 順番 | 書くこと |
|---|---|
| ① | 挨拶と署名、読者の疑問を代弁（「考え方は分かった。でも集客できるのか？」） |
| ② | 介護事業者の強み（見出し）：「お客様は、すでに施設の中にいる」 |
| ③ | 集客の方法（4つ） ・入居者・ご家族への案内（入居時・退去時のご案内に生前整理・遺品整理を載せる） ・ケアマネ・地域包括支援センター（「片付けの紹介先がない」という悩みに応える） ・病院の地域連携室・入居相談の会社 ・Web（専門HP・MEO）で地域のご家族から直接 |
| ④ | なぜ集客しやすいか：施設の看板そのものが信頼になる。ご家族はすでに施設を信頼している |
| ⑤ | 証明としての数字：遺品整理専門の会社の事例（2年で売上8,000万円・営業利益3,000万円、販促費月50〜60万円で月40〜50件）【要確認：介護事業者の参入事例があれば差し替え】 |
| ⑥ | 自社に置き換える問い：「年間の退去・ご逝去は何件ですか？そのうち何件が、居室や実家の片付けで困っていますか？」 |
| ⑦ | 次の不安を代弁 → 次回予告：「介護職員に片付けまでさせられない」「人が足りない」→「うちでもできるのか？」 |

## 第5部：うちでもできるの？（現場も含めてどう参入する？）

**件名案**：介護職員に片付けはさせません。施設の会社が遺品整理を始める“現実的な”方法

| 順番 | 書くこと |
|---|---|
| ① | 挨拶と署名、4回分の要約 |
| ② | 不安を代弁（3つ）：「介護職員に片付けはさせられない」「人が足りない」「新しい投資はできない」 |
| ③ | 結論を見出しで：「現場作業は、提携する専門業者に任せられます」 |
| ④ | 参入の形（矢印の図）：施設・Webで相談受付 → 自社で現地調査・見積 → 作業は提携業者 → 完了報告 → 実家の売却・解体は提携先へ |
| ⑤ | 介護職員は介護に集中できる（片付けの相談対応を専門の担当に任せる） |
| ⑥ | 投資が小さいこと：大きな設備は不要、専門HP中心、作業は外部と連携、担当者1名から |
| ⑦ | 立ち上げの進め方（例：6か月で提携業者の開拓 → 料金設計 → 専門HP → 案内開始） |
| ⑧ | 「新しい事業所をつくるのではなく、ご家族を支えるサービスを1つ足す」 |
| ⑨ | 最終メッセージ：「遺品整理をやりたいかどうかではなく、介護保険の外にどんな柱を持つか」 |
| ⑩ | 目的と手段をもう一度言い切り、セミナーへ |

## 書く前に確認すること

| 項目 | 内容 |
|---|---|
| セミナー | 介護事業者向けのセミナーがあるか、名前・日程・URL |
| 事例 | 介護事業者が遺品整理に参入した事例（資料には見当たらない）。なければ第4部は遺品整理専門の事例＋「接点の数」の問いで構成 |
| 仮説の言い方 | 「空室期間」「入居の遅れ」「身寄りのない方の家財」は仮説。断定せず「〜ということはありませんか？」と問いかけで書く |
| 法人の種類 | 社会福祉法人は収益事業に制限がある。読者が株式会社中心か確認し、必要なら注記 |
| 入居者への案内 | 弱い立場のご家族への営業と受け取られないよう、「ご家族の負担を減らす支援」として書く |
| 事実の数字 | 倒産件数（2025年・暦年）と介護職員の必要数（2026年度）は出典を明記 |
