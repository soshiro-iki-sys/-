# 個社別ご提案パート 汎用フォーマット 骨子（v1）

## 位置づけ

- 企画書（前半：遺品整理事業の一般論）の後ろに差し込む、**会社ごとに中身を埋める後半パート**
- 商談前は情報が少ないので、**「仮説」と「確認したいこと」で組み、ヒアリングと調査で埋めていく**作り
- 出発点は「何をやるか」ではなく **「なぜこの会社が遺品整理をやるのか（目的）」**。目的が決まれば、シナジー・商圏・事業設計がそこから決まる
- どの業種・規模の会社にも使えるよう、業種で変わる部分は選択式・空欄にする

### 使い方（3段階）

| 段階 | いつ | 埋めるもの | 見せ方 |
|---|---|---|---|
| ① 仮説版 | 初回の経営相談の前 | 公開情報（HP・会社概要）と業種別シナジーから立てた仮説、競合の机上調査 | 「仮説」「要確認」と明記して見せ、商談で答え合わせする |
| ② ヒアリング後 | 初回の経営相談の後 | 参入目的、現状の数字、体制、課題 | 仮説を事実に置き換える |
| ③ ご提案版 | 2回目の経営相談 | 競合調査の結果、事業コンセプト、数値計画 | 最終の提案書として見せる |

各スライドの右上に、状態を示すラベルを付ける：**【仮説】【要ヒアリング】【調査中】【確定】**

## 構成（約15枚）

### A. 目的を定める（3枚）

| # | タイトル | 中身 | ①仮説版で埋めるもの | 埋めるための情報源 |
|---|---|---|---|---|
| A1 | 中扉：○○株式会社様へのご提案 | | 社名 | |
| A2 | 貴社の現状 | 事業構成（売上の柱）、強み、商圏、体制を1枚に整理 | HP・会社概要から分かる範囲。数字は空欄 | HP、会社概要、帝国データ等、ヒアリング |
| A3 | 遺品整理事業に取り組む目的 | 6つの目的の型から、貴社に当てはまるものを選ぶ（複数可）。**一番の目的を1つに絞る** | 業種から考えられる目的に仮の印をつける | ヒアリング（DL・セミナーのきっかけ、経営課題、遺品整理の位置づけ） |

**目的の6つの型（A3で使う選択肢）**

| 型 | 目的 | 当てはまりやすい業種 | 成功の判断基準 |
|---|---|---|---|
| ① 本業の入口 | 本業の案件（仕入れ・受注）を、市場に出る前に獲得する | 不動産、解体、リフォーム | 遺品整理から生まれた本業の件数・粗利 |
| ② 外注の内製化 | 今外注している片付け・残置物撤去を自社の粗利に変える | 不動産、解体、買取再販 | 削減できた外注費 |
| ③ 既存資源の活用 | 空いている人員・車両・時間を売上に変える | 引越し、運送、便利業、産廃 | 稼働率、閑散期の売上 |
| ④ 既存顧客へのアフター | 既存のお客様・会員に提供できるサービスを増やす | 葬儀、墓石、リフォーム、介護 | 既存顧客からの受注件数、継続率 |
| ⑤ 新しい収益の柱 | 本業とは別に、伸びる市場で事業を一つ育てる | どの業種でも | 遺品整理単体の売上・利益（3年1億円モデル） |
| ⑥ 本業の差別化 | ワンストップ対応で、本業の競合と差をつける | 不動産、葬儀、リフォーム | 本業の成約率・単価 |

→ 一番の目的によって、後ろのページで重視するもの（シナジー／単体の収益性／集客の仕方）が変わる

### B. 仮説を立てる（3枚）

| # | タイトル | 中身 | ①仮説版で埋めるもの |
|---|---|---|---|
| B1 | 貴社と遺品整理のシナジー（仮説） | 「お客様・商流」「経営資源（人・車両・ノウハウ）」「集客チャネル」「本業への出口」の4つの観点で、つながりを仮説として並べる。各項目に強さ（◎○△）と【要確認】を付ける | 企画書の業種別シナジーをもとに仮説を書く |
| B2 | 仮説を確かめるための確認事項 | B1の各仮説について「何が分かれば正しいと言えるか」を表にする（例：年間の残置物撤去の件数、外注費、閑散期の稼働、既存顧客数） | 確認事項のリスト |
| B3 | 想定される課題・リスク | 人員、許可、ブランド（本業との関係）、投資余力など、立ち上げで障害になりそうなこと | 業種から想定されるもの |

**B1 シナジー仮説の書き方（表の型）**

| 観点 | 仮説 | 強さ | 確かめ方 | 状態 |
|---|---|---|---|---|
| お客様・商流 | 例：既存のお客様の中に、相続・実家の片付けの相談が月○件ある | ◎○△ | 過去1年の相談件数を確認 | 【要ヒアリング】 |
| 経営資源 | 例：トラック・作業員が閑散期に空いている | | 月別の稼働率 | |
| 集客チャネル | 例：自社のHP・チラシ・顧客名簿で集客できる | | 名簿の件数、HPの反響数 | |
| 本業への出口 | 例：片付け後に売却・解体・リフォームにつながる | | 過去の紹介・受注件数 | |

### C. 市場と競合を調べる（3枚）

| # | タイトル | 中身 | ①仮説版で埋めるもの | 情報源 |
|---|---|---|---|---|
| C1 | 貴社商圏の市場規模 | 商圏人口 × MS4,200円で市場規模を試算。高齢化率・空き家数・世帯数 | 本社所在地の市区町村で試算 | 住民基本台帳（自治体）、総務省「住宅・土地統計調査」 |
| C2 | 商圏の競合状況 | 競合調査シート（下記）の要約。競合の数、専門店の有無、価格帯、打ち出し | 机上調査（Google検索・Googleマップ） | 下記の調査手順 |
| C3 | 貴社が勝てるポジション | 競合と比べて空いているところ（専門店がいない／価格が不明瞭な業者ばかり／不動産・供養までできる会社がない など）と、貴社の強みが重なるところ | C2から仮説 | C2の結果 |

**競合調査シート（C2の中身・別紙のExcelでも可）**

| 項目 | 調べる内容 |
|---|---|
| 調べる範囲 | 商圏の市区町村で「遺品整理 ○○市」「不用品回収 ○○市」「生前整理 ○○市」をGoogle検索・Googleマップで検索し、上位10社 |
| 業態 | 遺品整理専門店／不用品回収・便利屋／買取業者／大手チェーン／葬儀・不動産などの兼業 |
| 打ち出し | 屋号・キャッチコピー・専門性（遺品整理を主に打ち出しているか） |
| 料金 | パック料金の有無、1K・2LDKなど間取り別の価格 |
| 信頼材料 | Google口コミの件数・評価、施工事例、スタッフ紹介、許可・資格 |
| 集客 | SEO（検索順位）、MEO（地図の順位）、リスティング広告の出稿有無 |
| サービスの幅 | 買取・供養・特殊清掃・解体・不動産売却まで対応しているか |
| まとめ | 地域一番店はいるか／空いているポジションはどこか |

### D. 事業の方向性を決める（4枚）

| # | タイトル | 中身 | いつ埋めるか |
|---|---|---|---|
| D1 | 貴社版の事業コンセプト | 売り先・売り物・売り方、屋号の考え方（本業と分けるか） | ③ご提案版 |
| D2 | 貴社版の事業モデル | 一番の目的に合わせた型を選ぶ：A「単体で稼ぐ型」（3年1億円モデル）／B「本業の入口型」（遺品整理は集客の入口、利益は本業で）／C「内製化型」（自社案件の片付けから始める）| ③ご提案版 |
| D3 | 貴社版の数値計画 | 選んだ型に合わせた3年計画。本業への波及（本業込みの利益）を分けて見せる | ③ご提案版 |
| D4 | 立上げの進め方 | 6か月のスケジュールと、最初の3か月でやること | ③ご提案版 |

### E. まとめ（1枚）

| # | タイトル | 中身 |
|---|---|---|
| E1 | 次に確かめること／決めること | 仮説版・ヒアリング後の段階では、残っている【要ヒアリング】【調査中】の項目と、次回までに双方で準備すること。ご提案版では省略してよい |

→ この後に「船井総研がご提供できること」（企画書のまま）

## このフォーマットで変わること（REVIVAL LINK様の提案書との違い）

- 「シナジーがある」と言い切らず、**仮説として出し、確かめ方とセットで見せる**
- 目的を最初に決めるので、会社ごとに提案の軸がぶれない
- 競合調査を、提案の中の決まったページ（C2・C3）として組み込む
- 事業モデルを1つに決め打ちせず、目的に合わせて3つの型から選ぶ

## 確認したい点

1. **目的の6つの型**は、この分け方でよいですか？（増やす・まとめる・名前を変える など）
2. **状態ラベル（【仮説】【要ヒアリング】など）**を、お客様に見せるスライドにそのまま出してよいですか？出したくない場合は、発表者ノートだけに書きます
3. **競合調査シート**は、スライド1枚の要約＋別紙Excelの形でよいですか？Excelのひな形も作れます
4. この骨子でよければ、まずは空欄のフォーマット（pptx）を作り、そのうえでREVIVAL LINK様を例に①仮説版を埋めてみます
