# 堺市の便利屋様　経営相談ストーリー（悩み起点版）

ゴール：松＝支援獲得／竹＝HPディレクション／梅＝研究会誘導

## このストーリーの考え方

- 「遺品整理を勧める話」ではなく、**社長の目標と、そこに届かない理由（4つの悩み）を一緒に整理する話**にする
- 4つの悩み（商品・集客・営業・現場）は別々に見えて、根っこは同じ「**1件が小さく、件数で稼ぐしかない構造**」。この構造を本人の数字で見えるようにする
- 遺品整理・専門店ブランドは、**本人が口にした悩みへの答え**として出す。悩みが出ていない領域の話はしない
- 出てきた悩みの数と深さで、松・竹・梅を決める

**ストーリーの一文**
「○年後に○万円」という目標に対して、今のやり方だとギャップが埋まらない（1）。理由は、1件が小さく（商品）、高単価の相談が来ず（集客）、比べられて負け（営業）、人と車がもったいない使い方になっている（現場）から（2）。この4つは全部、1件の単価が低いことから来ている。だから、余っている人と車を高単価の遺品整理に回すのが一番早い（3）。ただし便利屋の看板のままでは、集客でも営業でも専門店に負けるので、専門店ブランドを持つ（4）。

## 1. 目標とギャップ（10分）

| 聞くこと | 質問 |
|---|---|
| 目標 | 「いつまでに、売上・利益をどのくらいにしたいですか？」「その目標を立てた理由は何ですか？（法人化・人を増やす・家族・独立）」 |
| 現状 | 「今の年間の売上と、手元に残る利益はどのくらいですか？」 |
| ギャップ | 「目標まで、あといくら足りませんか？」 |
| 今の見通し | 「今のやり方を続けて、その目標に届きそうですか？」 |

**ここで作る数字（その場で書き出す）**

| | 金額 |
|---|---|
| 目標（○年後） | （記入） |
| 現状 | （記入） |
| ギャップ | （記入） |
| 今の単価で埋めると | ギャップ ÷ 今の平均単価 ＝ 月に**あと○件** |

> 「今の単価のままだと、月にあと○件増やす必要があります。今の人と車で、そこまで増やせそうですか？」

## 2. 4つの悩みを聞く（25分）

各領域で「状況 → 困りごと → 放っておくと」の順に聞く。出てきた言葉と数字はそのままメモし、4・5で使う。

### 商品：小単価・労働集約・利益率

| 段階 | 質問 | 引き出したい悩み |
|---|---|---|
| 状況 | 「どんな仕事が多いですか？1件の単価は平均いくらですか？」 | 1件1〜2万円の小口が中心 |
| 状況 | 「遺品整理や家一棟の片付けは、月に何件、いくらで受けていますか？」 | 大きな仕事も便利屋の価格で受けている |
| 困りごと | 「件数のわりに、手元に残らないと感じることはありますか？」 | 忙しいのに利益が残らない |
| 放っておくと | 「単価が今のままだと、利益を増やすには件数を増やすしかないですよね。それは続けられそうですか？」 | 労働時間・体力の限界 |

**寄り添いの一言**：「何でも引き受けるからこそ地域で頼られている。でもその分、1件が小さくなりやすいんですよね。」

### 集客：案件数の伸び悩み・高単価案件が来ない・埋没

| 段階 | 質問 | 引き出したい悩み |
|---|---|---|
| 状況 | 「問い合わせは月に何件、どこから来ますか？（本部・比較サイト・電話・紹介）」 | 本部・比較サイト頼み |
| 状況 | 「その中で、10万円を超える相談は月に何件ありますか？」 | 高単価の相談が少ない |
| 困りごと | 「『遺品整理 堺市』で検索すると、貴社は出てきますか？」 | 専門店に埋もれている |
| 放っておくと | 「高単価の相談が増えないまま件数だけ増やすと、どうなりそうですか？」 | 忙しさだけが増える |

**寄り添いの一言**：「小口の相談は来るのに、大きな相談ほど他社に行ってしまう。もったいないですよね。」

### 営業：成約率・相見積もりで負ける

| 段階 | 質問 | 引き出したい悩み |
|---|---|---|
| 状況 | 「見積りを出したうち、何割くらい受注になりますか？」 | 成約率 |
| 状況 | 「遺品整理や大きな片付けの見積りで、他社と比べられることはありますか？」 | 相見積もり |
| 困りごと | 「負けたとき、理由は何だと思いますか？値段ですか、それ以外ですか？」 | 専門店の安心感に負けている |
| 困りごと | 「見積りは、人によって金額が変わることはありますか？」 | 見積りが感覚頼み |
| 放っておくと | 「大きな見積りで負けが続くと、年間でいくら逃していますか？」 | 逃している金額 |

**寄り添いの一言**：「値段では負けていないのに取れない、というのが一番悔しいですよね。」

### 現場：トラックの経費と稼働・人員の不足や余り

| 段階 | 質問 | 引き出したい悩み |
|---|---|---|
| 状況 | 「トラックは何台、月の稼働はどのくらいですか？」 | 車両の稼働の偏り |
| 状況 | 「作業員は何名、忙しい日と暇な日の差はありますか？」 | 人の余り・不足 |
| 困りごと | 「1日1〜2件の小口で、トラックと人を出していて、割に合わないと感じることは？」 | 経費に見合わない稼働 |
| 放っておくと | 「人を増やすと、固定費に見合う仕事を毎日埋められそうですか？」 | 増員できない |

**寄り添いの一言**：「人と車を持っているのは強み。でも小口の仕事だと、その強みを活かしきれていないかもしれません。」

## 3. 悩みの根っこを一緒に見る（10分）

出てきた悩みを1枚に並べ、すべて「1件が小さい」につながっていることを示す。

```
            1件の単価が小さい
     ┌──────────┼──────────┬──────────┐
  商品           集客          営業          現場
件数で稼ぐしか   大きな相談が   専門店に       小口で人と車を
ない・利益が     来ない         比べられて     出している
残らない                        負ける
```

> 「4つとも、根っこは同じでした。1件の単価が小さいから、件数で稼ぐしかなくて、人と車も小口に使ってしまう。だから目標に届かない。逆に言えば、**1件の単価を上げられれば、4つが一度に良くなります**。」

---

## 4. 解決策：遺品整理に特化（15分）

出てきた悩みごとに「遺品整理だと何が変わるか」を示す（出ていない悩みは飛ばす）。

| 悩み | 遺品整理で変わること | 示す数字 |
|---|---|---|
| 商品：小単価・利益が残らない | 家一棟で15〜30万円。小口の10〜20件分を1件で | 同じ物量でも専門店は15〜20万円。他店舗の事例は6万円で約3分の1 |
| 集客：高単価の相談が来ない | 「遺品整理 堺市」で探す人は、最初から家一棟の相談 | 堺市の市場規模（人口×4,200円）【人口は要確認】 |
| 営業：比べられて負ける | 専門店としての安心感（遺品整理士・供養・買取・事例）で選ばれる | 成約率の目安 50〜70%（Web反響） |
| 現場：人と車がもったいない | 余っている人と車を、1日で15〜30万円の仕事に回せる | 1件で作業員2〜4名×1〜2日 |

**ギャップに当てはめる**
> 「最初に出したギャップ○万円。今の単価なら月あと○件でしたが、遺品整理なら月**○件**で届きます。」（ギャップ ÷ 遺品整理の単価）

### FCに加盟している場合

- いきなり「独立」「卒業」とは言わない。規約（競業避止・独自ブランド）を本人に確認してからにする
- 伝え方：「本部の仕事は今まで通り続けながら、利益率の高い遺品整理だけは自社の看板で取る。その先に、自社の柱が育ったら、FCとの付き合い方を選べるようになります」
- ロイヤリティ・手数料を聞けていれば、「遺品整理を自社で取ると、手数料がかからない分、利益が○万円変わります」と示す

## 5. なぜ専門店ブランドか（10分）

2で出た「集客」「営業」の悩みにつなげて話す。

| 悩み | 便利屋の看板のままだと | 専門店ブランドなら |
|---|---|---|
| 集客：埋もれる | サイトの中で遺品整理は1メニュー。「遺品整理」との関連が薄く、検索（SEO・AI検索）や広告で専門店に負けやすい | サイト全体が遺品整理の情報になり、専門性・実績が伝わる。高単価の相談の入口になる |
| 営業：比べられて負ける | 「何でも屋さん」に見え、大切な遺品を任せる相手として比べると負ける | 専門店としての安心感。トークと見積りを標準化でき、成約率が安定する |
| 商品：単価が上がらない | 便利屋の料金表・1点回収と並び、15〜20万円で見せにくい | 定額パック（間取り別）で、家一棟の価格を正面から見せられる |

> 「遺品整理をやること自体は、今のサイトでもできます。ただ、大きな相談を取って、比べられても勝つには、専門店の看板が必要です。」

※ 検索・AI検索での評価は、専門性のあるサイトの方が有利になりやすい傾向として伝える（順位を約束しない）
※ 「便利屋のサイトの中で強化するのではだめか」と聞かれたら、反論処理（松竹梅ストーリーの資料）の段階提案で返す

## 6. 進め方と選択肢（10分）

2で出た悩みの数と深さで、提案を決める。

| 出てきた悩み | 必要な支援 | ゴール |
|---|---|---|
| 商品・集客・営業・現場のうち3つ以上が深い | 商品設計（定額パック）＋専門HP＋見積・営業の型＋集客・月次の改善 | 松 |
| 集客（埋もれる・高単価が来ない）が中心 | 専門HP（自社の看板） | 竹 |
| 悩みはあるが、時期・資金・規約で今は動けない | 全国の事例・数字を知る場 | 梅 |

**6か月の進め方（松の場合）**
1. 1〜2か月目：商品設計（定額パック）、処分業者・提携先の確認、競合調査
2. 3〜4か月目：専門HP制作、見積シート・営業トークの導入
3. 5〜6か月目：広告・MEOの運用開始、営業同行、紹介ルートの開拓

## 7. クロージング（10分）

| 手順 | トーク |
|---|---|
| まとめ（本人の言葉で） | 「目標は○年後に○万円。今は、1件が小さく、大きな相談が来ず、比べられて負け、人と車を小口に使っている。それを遺品整理の専門店で一度に変える、ということでしたね。」 |
| テストクロージング | 「このやり方なら、目標に届きそうですか？」「気になる点は、あと何かありますか？」 |
| 松 | 「看板だけでなく、価格・見積・営業の型と毎月の改善までご一緒すると、一番早く目標に近づけます。○月開始でいかがでしょうか。」 |
| 竹（松が重い場合） | 「まずは専門店の看板（HP）だけ先に作る方法もあります。大きな相談の入口ができます。」 |
| 梅（今は動けない場合） | 「すぐに始めなくても、全国で遺品整理に取り組んでいる会社の事例と数字を知っておくと、判断の材料になります。研究会にお越しください。」 |

## 確認が必要なこと

| 項目 | 内容 |
|---|---|
| 相手の立場 | お助けマスターの加盟店か。FCの規約（独自HP・別ブランド・競業避止） |
| 数字 | 堺市の人口（市場規模の計算用）、他店舗の事例「6万円」は1件だけの参考 |
| 研究会・HPディレクション | 研究会の費用、HPディレクション単体での受注可否と費用 |
