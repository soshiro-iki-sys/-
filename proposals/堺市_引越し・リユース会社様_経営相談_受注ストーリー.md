# 堺市の引越し・不用品リユース会社様　経営相談ストーリー（ゴール：受注）

## 前提

| 項目 | 内容 |
|---|---|
| 相手 | 堺市で引越し事業・不用品リユース事業を営む会社（社長） |
| 状態 | 「遺品整理を起点とする新事業モデル」に関心がある（DL資料・セミナー等がきっかけと想定。きっかけは冒頭で確認） |
| 時間 | 90分を想定（60分の場合は5〜7の説明を短くする） |
| ゴール | その場でご支援のお申込み（または開始月の決定）。決裁者が同席していない場合は「決裁者同席の次回日程」を決める |

## このストーリーの考え方

- 関心はすでにある相手なので、「遺品整理は儲かるか」を説明するより、**「貴社がやれば、他社より早く・高い利益で立ち上がる」理由**を、相手の口から出た事実で組み立てる
- 引越し＋不用品リユースの会社は、遺品整理に必要なもの（トラック・作業員・搬出の技術・古物商・リユースの販路）を**ほぼすべて持っている**。足りないのは「遺品整理として選ばれる集客・営業・見積の型」だけ → そこが船井総研の支援内容とぴったり重なる
- 一番の壁は「今の不用品回収の延長でできる」という思い込み。**不用品回収と遺品整理は、お客様も単価も選ばれ方も違う**ことを、相手自身の数字で気づいてもらう
- 冒頭で「最後にご支援の形とお見積りもお伝えし、ご判断いただきたい」と伝えておく（クロージングを不意打ちにしない）

**ストーリーの一文**：引越しとリユースで持っている人・車・販路は、遺品整理にそのまま使える（強み）。ただ不用品回収の延長では単価が上がらず、閑散期も埋まらない（課題）。遺品整理を「専門店」として立ち上げれば、閑散期を高単価の仕事で埋め、リユースの仕入れも増える（理想）。足りないのは集客・営業・見積の型だけで、それを船井総研が6か月で入れる（解決）。

## 6. 貴社がやる理由（モデル）（15分）

### 6-1. 不用品回収と遺品整理の違い（気づいてもらう）

| | 不用品回収 | 遺品整理 |
|---|---|---|
| お客様 | 物を減らしたい人（引越し・模様替え） | 実家を片付けたいご遺族・ご家族 |
| 1件の単価 | 小さい（3の数字を使う） | 30万〜40万円（家一棟） |
| 選ばれ方 | 価格 | 信頼・丁寧さ・供養・買取の透明さ |
| その後 | 終わり | 売却・解体・リフォーム・相続の相談につながる |

> 「同じ『片付け』でも、お客様も単価も選ばれ方も違います。不用品回収の延長で遺品整理を受けると、価格で比べられてしまう。だから**遺品整理の専門店として、別の看板で立ち上げる**のがポイントです。」

### 6-2. 貴社ならではのシナジー（4つの観点）

| 観点 | 貴社での内容 |
|---|---|
| ① LTVの最大化 | 引越しのお客様（施設入居・住み替え・実家じまい）から遺品整理・生前整理へ。逆に遺品整理のご家族から引越し・配送の依頼も |
| ② 経営資源 | トラック・作業員・梱包・搬出の技術をそのまま使える。**閑散期の空き稼働を遺品整理で埋める** |
| ③ 収益・コスト | 作業を外注せず自社でできるので粗利が高い。買い取った物はリユースの販路で売れる → 買取で費用を相殺し、価格でも勝てる |
| ④ 信頼・ブランド | 「引越し会社がやる、遺品整理の専門店」。搬出の丁寧さ・建物への配慮は引越しで培った強み |

### 6-3. 数値計画（企画書の3年モデル）

| | 1年目 | 2年目 | 3年目 |
|---|---|---|---|
| 売上 | 3,600万円 | 5,400万円 | 1億円 |
| 営業利益率 | 2.9% | 16.7% | 23.1% |

- 企画書のモデルは作業員アルバイトを経費に入れている。**貴社は既存の作業員・車両を使えるため、閑散期の稼働で回せる分は、さらに利益が残りやすい**（3で聞いた空き稼働の数字で示す）
- 初期投資はHP制作費が中心。古物商をお持ちなら取得費用は不要
- 【要確認】企画書の1年目の営業利益（106万円）は、表の経費を合計すると586万円になり合わない。数字を出す前に社内で確認しておく

## 8. 不安の解消（10分）

相手から出た不安にだけ答える（全部は話さない）。

| よく出る不安 | 答え方 |
|---|---|
| 「今の不用品回収と何が違うのか」 | 6-1の表。お客様・単価・選ばれ方が違う。だから別の看板で立ち上げる |
| 「人が足りない」 | 最初は担当者1名（営業・見積）から。作業は既存の作業員と閑散期の稼働で回す |
| 「一般廃棄物の許可がない」 | 許可業者との三社間契約で、法令に沿って始められる（3で現状の処分方法を確認しておく） |
| 「堺市は競合が多いのでは」 | 「遺品整理 堺市」で上位の会社を事前に調べておき、専門店として打ち出している会社が少ないことを示す【要事前調査】 |
| 「繁忙期に遺品整理まで手が回るか」 | 引越しの繁忙期（2〜4月）は遺品整理の広告を抑え、閑散期に厚くする運用ができる |
| 「費用に見合うか」 | 遺品整理1件の粗利と、初期投資・月額費用を並べて、何件で回収できるかを示す（9で） |
| 「前にも新規事業で失敗した」 | 何がうまくいかなかったかを聞き、マニュアル・ツール・月次支援で型を入れることで防げる点を示す |

### 立ち上げ6か月

| 期間 | やること |

| 1〜2か月目 | 商圏の競合調査、商品・料金設計（定額パック）、処分業者・提携先の確認 |

| 5〜6か月目 | Web広告（リスティング・MEO）のテスト運用、営業同行・改善、紹介ルート（不動産会社・ケアマネ等）の開拓 |

## 10. クロージング（10分）

| 手順 | トーク・内容 |
|---|---|
| まとめ（相手の言葉で） | 「本日伺ったのは、閑散期の稼働を埋めたい、単価の高い仕事がほしい、ということでした。遺品整理なら、今の人・車・リユースの販路をそのまま使って、それが実現できます。」 |
| テストクロージング | 「ここまでお聞きになって、貴社でやるイメージは湧きましたか？」「気になっている点は、あと何かありますか？」 |
| 残った不安に答える | 8の表で答える。答えられないものは「次回までに調べてお持ちします」と期限を決める |
| お申込みの打診 | 「では、ぜひご一緒させてください。開始は○月からでいかがでしょうか。閑散期に間に合わせるなら、○月開始で6か月後に集客を始められます。」 |
| 決めること | ①お申込み（支援内容のプラン）②開始月 ③担当者の候補 ④初回の打ち合わせ日 |
| 申込書 | その場で申込書を出す。社内で確認が必要な場合は、確認する相手と回答期限を決める |

**開始月の決め方**：引越しの繁忙期（2〜4月）を避けて立ち上げ、閑散期から集客を始められる逆算で提案する（例：秋に開始 → 翌年の閑散期から本格稼働）

### その場で決まらない場合

| 状況 | 対応 |
|---|---|
| 決裁者が不在 | 決裁者同席の次回日程をその場で決める。本日の資料と数値計画をお渡しする |
| 費用で迷っている | プラン（ツールを月次とセットにして100万円）や開始月の調整を提案する。回収の目安をもう一度示す |
| 時期が合わない | 開始月だけ先に決め、それまでに競合調査をお持ちすることを約束する |
| 関心が薄れた | 何が引っかかったかを聞く。無理に押さず、情報提供の接点を残す |
