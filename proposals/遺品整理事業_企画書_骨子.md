# 遺品整理事業 企画書 骨子（v3）

作成：2026-11-02
ベース：船井流一番店マニュアル（事業コンセプト・集客・営業・現場）、B2B経営相談マニュアル、提案書（76p）、企画書（96p）

## v2からの変更点
- 資料を2部に分けるのをやめ、**1冊の企画書**にした
- 1冊を前から順に使い、**前半を事前経営相談（1回目）、後半を事後経営相談（2回目）**で使う並びにした
- 支援内容と費用は引き続き**一番最後**。シナジーは**全業種向け**

---

## 0. 全体設計

### タイトル案
**「遺品整理事業 参入のご提案 ―“片付け”を入口に、地域の相続・空き家案件の最初の相談先になる―」**
表紙は「株式会社○○ 様」宛て。日付・担当コンサルタント名

### 1冊を2回の経営相談で使い分ける

```
 1章 はじめに ─┐
 2章 貴社のお話 │ 事前経営相談（1回目）
 3章 遺品整理の事業概要 │  ＝ヒアリング＋事業の理解＋簡単な質問への回答
 4章 よくあるご質問 ─┘   （ここで止めて2回目のアポをとる）
 ───────── セミナー（または資料DL後の検討期間）─────────
 5章 疑問の解消 ─┐
 6章 貴社で進めるには │ 事後経営相談（2回目）
 7章 成功事例 │  ＝疑問の解消＋進め方＋根拠＋提案（クロージング）
 8章 船井総研のご支援とお見積り ─┘
 付録（必要に応じて開く）
```

| | 事前経営相談（1回目） | 事後経営相談（2回目） |
|---|---|---|
| 使う章 | 1〜4章（約25枚） | 2章の振り返り＋5〜8章（約30枚） |
| 役割 | **聞く・理解してもらう** | **疑問を解消し、進め方を示し、決めてもらう** |
| やること | ヒアリング／遺品整理の事業概要の説明／セミナーで聞きたいこと・DL資料で気になったことへの簡単な回答（セミナーの理解が深まるように企画書を見せながら） | セミナーでの疑問の解消／貴社で進める場合の進め方／成功事例の共有（進め方の根拠）／コンサルティングのご提案 |
| 売り込み | しない。5章以降は開かない | 最後の8章で提案する |
| ゴール | 2回目のアポを確定する | 支援プランを決めていただく |

**運用のポイント**
- 1回目は4章で終える。目次（1-2）で「後半は次回、貴社に当てはめてご説明します」と見せておき、2回目へ自然につなぐ
- 2章「貴社のお話」は**1回目は質問だけのヒアリングシート**、**2回目は伺った内容を書き込んだ版**に差し替えて振り返りに使う
- セミナー経由は「セミナーの理解を深める事前ガイダンス」、DL経由は「資料の改善・サービス向上のためのヒアリング」という名目で1回目を設定する（B2Bマニュアルの流入経路別フロー）
- 各ページの下に赤字の結論を1行入れる（1ページ1メッセージ）

## 2章 貴社のお話を伺う（3枚）【1回目：ヒアリング／2回目：振り返り】
B2Bマニュアルの4大カテゴリに沿う。1回目は質問のみ（答えは手元でメモ）。2回目は書き込んだ版で「前回伺ったこと」として確認する。**他社名・外注先名は資料に書かない**
| No | タイトル | 聞くこと |
|---|---|---|
| 2-1 | ご相談のきっかけ | セミナー申込／資料DLのきっかけ、気になったフレーズや数値、社内の検討段階（情報収集／比較検討／早期立上げ）、セミナーで特に聞きたいこと |
| 2-2 | 貴社の現状と目標 | 売上規模と構成、人員（兼任できる人がいるか）、許認可（宅建・古物商・一般廃棄物）、車両・倉庫、3年後・5年後の目標。**実績をほめてから目標を聞く** |
| 2-3 | 本業の課題と遺品整理への期待 | 本業の課題（業種別の例を選択肢として並べる）、残置物・片付けの相談が月何件あるか・今どう対応しているか、遺品整理を会社の中でどう位置づけたいか |

|---|---|---|
| 3-1 | 中扉 | |

| 3-5 | 業界の現状 | 不用品回収中心の業者が多い／グリーフケアに差／品質のばらつき。【結論】専門店が少ない今がチャンス |
| 3-6 | 今が参入のタイミング | ライフサイクル図（成長期・地域一番店が不在）。【結論】一番店をとれるのは今 |

| 3-8 | 3年間の数値計画（概要） | 売上3,600万→5,400万→1億円、営業利益率は3年目に20%超、初期投資と回収時期。**概要のみ。内訳は5章で説明** |

| 3-10 | 7つの収益機会 | 遺品整理→買取→供養→特殊清掃→解体→不動産→リフォームの階段図。30万円の案件が490万円になる例。【結論】遺品整理は「入口商品」 |
| 3-11 | 許可がなくても始められる | 三社間契約の要点。一廃許可・古物商は「あれば利益が増える」位置づけ。【結論】法令に沿った方法でスモールスタートできる |
| 3-12 | 事業を動かす4つの柱 | 集客／営業／現場／提携の4つをカードで紹介。【結論】4つを仕組みにすれば、未経験でも立ち上げられる |
| 3-13 | 全業種共通：遺品整理がもたらすシナジー | どの業種にも共通する4つの効果：①商流の川上がとれる ②既存のお客様・資産が活きる ③外注していた作業が利益に変わる ④地域の信頼が上がり紹介が増える。【結論】遺品整理は、どの業種にとっても「本業の入口」になる |
| 3-14 | 業種別シナジー一覧 | 8業種を同じ型の表で（本業の課題／遺品整理で得られること／つながる本業の仕事）。中身は下の「業種別シナジー一覧」参照 |
| 3-15 | 章のまとめ | 需要・儲け・始めやすさ・本業への効果を1行ずつ |

## 5章 疑問の解消（5枚）【2回目】
2回目の冒頭は2章（書き込み版）で前回の内容を確認してから入る。セミナー・1回目でいただいた疑問に、7つの阻害要因の順で答える。**相手の疑問に合わせてページを選ぶ**
| No | タイトル | 内容・【結論】 |
|---|---|---|
| 5-1 | いただいたご質問一覧 | セミナーアンケート・1回目の質問を7つの阻害要因（お金・時期・競合・プラン・キーマン・会社・自分）に分類した表 |
| 5-2 | お金：本当に儲かるのか | 3年間の収支（全経費の内訳を表示し合計と一致させる）、初期投資と回収。【結論】社員1名から、3年目に営業利益率20%超 |
| 5-3 | プラン・キーマン：現場と人は回るのか | 3ヶ年の人員体制（正社員は営業・管理、作業は外部スタッフ）、見積の仕組み（段ボール換算・立米単価）、処分費を下げる仕組み（国内買取→海外輸出→まとめ売り→廃棄）。【結論】トラック・倉庫・専門の目利きがなくても始められる |
| 5-4 | 会社：法令とブランドは大丈夫か | 三社間契約の詳細（前提条件と自治体確認を明記）、古物台帳・契約書・損害賠償保険。【結論】本業のブランドを守れる運営体制を最初から整える |
| 5-5 | 競合・時期：後発でも勝てるか | 地域の競合状況、専門店化と提携で勝つ。【結論】専門店がいない今が参入時期 |

## 業種別シナジー一覧（3-14の中身）

| 業種 | 本業の課題 | 遺品整理で得られること | つながる本業の仕事 |
|---|---|---|---|
| 不動産 | 仕入れ競争・広告費の高騰、売却前の片付けで案件が長期化 | 売却を考える前の所有者と出会える。残置物撤去の外注費が自社の利益に | 売買仲介・買取再販・賃貸管理 |
| 解体 | 価格競争で利益率低下、紹介依存、職人の稼働の波 | 解体前の案件を元請けでとれる。家財撤去の利益も自社に | 解体工事・土地活用 |
| 住宅・リフォーム | 新築市場の縮小、大型案件不足、OB客との接点不足 | 相続した実家のリノベ相談の入口になる | リフォーム・リノベーション |
| 葬儀 | 家族葬化で単価下落、葬儀後の収益がない | 葬儀後の「困りごと」を自社で受けられ、会員の満足度が上がる | 法要・供養・墓じまい・相続相談 |
| 介護（ケアマネ・包括） | 片付けの相談先が不足、業務負担の増加 | 施設入居前の生前整理に対応でき、家族の信頼が上がる | 入居相談・地域連携 |
| 便利業 | 小口案件ばかりで利益率が低い、ブランド力が弱い | 高単価商品を持てる。専門店として信頼される | 不用品回収・ハウスクリーニング |
| リサイクル | 良質な仕入れが不安定、一般客との接点が少ない | 良質なリユース品を直接仕入れられる | 資源回収・リユース販売 |
| 買取 | 高価値品の仕入れが不安定、買取できない物が多い | 家一軒分から高価値品を仕入れられ、「全部お願いできる」が強みに | 出張買取・店舗販売 |

## 既存2資料からの改善点（反映済み）

| # | 既存資料の問題 | 骨子での対応 |
