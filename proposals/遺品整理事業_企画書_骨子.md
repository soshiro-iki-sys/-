## 0. 全体設計

### 2回の経営相談の役割分担

| | 事前経営相談（1回目） | 事後経営相談（2回目） |
|---|---|---|
| タイミング | セミナー前（セミナー経由）／資料DL後（DL経由） | セミナー後（セミナー経由）／1回目の1〜2週間後（DL経由） |
| 相手の状態 | 関心はあるが、遺品整理の事業像がまだぼんやりしている | 事業像は理解した。「うちでもできるか」「どう進めるか」を知りたい |
| 役割 | **聞く・理解してもらう** | **疑問を解消し、進め方を示し、決めてもらう** |
| やること | ①ヒアリング ②遺品整理の事業概要の説明 ③セミナーで聞きたいこと・DL資料で気になったことへの簡単な回答（セミナーの理解が深まるように資料を見せながら） | ①セミナーでの疑問の解消 ②貴社で進める場合の進め方 ③成功事例の共有（進め方の根拠） ④コンサルティングのご提案（クロージング） |
| 売り込み | **しない**（支援内容・費用は見せない） | する（最後に支援内容と費用を提示） |
| ゴール | 2回目のアポイントを確定する | 支援プランを決めていただく |
| 時間の目安 | 60分 | 90分 |
| 使う資料 | **第1部**（約25枚） | **第2部**（約30枚） |

### 資料の作り方
- **1つのマスター資料を「第1部」「第2部」に分けて作る**。第1部は1回目で使い、2回目の冒頭で要点だけ振り返る
- 第1部の終わりに**「次回お持ちするもの」**ページを置き、2回目のアポを自然に取る
- 第2部の冒頭に**「前回伺ったこと」**ページを置き、1回目の内容を引き継ぐ
- **支援内容と費用は第2部の最後**。それまでは「貴社がどう進めるか」に集中し、売り込みに見えないようにする
- 各ページの下に赤字の結論を1行入れる（1ページ1メッセージ）

### 流入経路ごとの使い方

| | セミナー経由 | 資料DL経由 |
|---|---|---|
| 1回目の名目 | 「セミナーの理解を深めるための事前ガイダンス」 | 「資料の改善・サービス向上のためのヒアリング」 |
| 1回目の重点 | セミナーで聞きたいことを先に聞き、セミナーのどこで答えが出るかを示す | DL資料で気になった箇所への回答。「自社に当てはめた具体策はまだ見えていない」と気づいていただく |
| 1回目の締め | 「セミナー後に、貴社に当てはめた進め方をご説明します」 | 「次回、貴社の強みを踏まえた事業化イメージをお持ちします」 |
| 2回目の名目 | 「セミナー内容の深掘り＋貴社専用の進め方のご提示」 | 「貴社専用の事業化イメージのご提示」 |
| 2回目の第1章 | セミナーでいただいた疑問への回答 | 前回の質問への回答＋セミナー内容の要約 |

## 業種別シナジーの全業種版（2-2 No.15 の中身）

| 業種 | 本業の課題 | 遺品整理で得られること | つながる本業の仕事 |
|---|---|---|---|
| 不動産 | 仕入れ競争・広告費の高騰、売却前の片付けで案件が長期化 | 売却を考える前の所有者と出会える。残置物撤去の外注費が自社の利益に | 売買仲介・買取再販・賃貸管理 |
| 解体 | 価格競争で利益率低下、紹介依存、職人の稼働の波 | 解体前の案件を元請けでとれる。家財撤去の利益も自社に | 解体工事・土地活用 |
| 住宅・リフォーム | 新築市場の縮小、大型案件不足、OB客との接点不足 | 相続した実家のリノベ相談の入口になる | リフォーム・リノベーション |
| 葬儀 | 家族葬化で単価下落、葬儀後の収益がない | 葬儀後の「困りごと」を自社で受けられ、会員の満足度が上がる | 法要・供養・墓じまい・相続相談 |
| 介護（ケアマネ・包括） | 片付けの相談先が不足、業務負担の増加 | 施設入居前の生前整理に対応でき、家族の信頼が上がる | 入居相談・地域連携 |
| 便利業 | 小口案件ばかりで利益率が低い、ブランド力が弱い | 高単価商品を持てる。専門店として信頼される | 不用品回収・ハウスクリーニング |
| リサイクル | 良質な仕入れが不安定、一般客との接点が少ない | 良質なリユース品を直接仕入れられる | 資源回収・リユース販売 |
| 買取 | 高価値品の仕入れが不安定、買取できない物が多い | 家一軒分から高価値品を仕入れられ、「全部お願いできる」が強みに | 出張買取・店舗販売 |

**全業種共通の4つの効果**：①商流の川上がとれる ②既存のお客様・資産が活きる ③外注していた作業が利益に変わる ④地域の信頼が上がり紹介が増える

## 既存2資料からの改善点（v1から継続して反映）

| # | 既存資料の問題 | 骨子での対応 |
|---|---|---|
| 1 | 1回目と2回目の区別がなく、1冊で全部説明している | **第1部（聞く・理解）と第2部（解消・進め方・決める）に分割** |
| 2 | 支援内容・費用が途中から出てきて売り込み色が強い | **第2部の最後だけで提示**。第1部では見せない |
| 3 | 実在クライアントのヒアリングメモがそのまま残っている | 第1部は質問のみ（答えは手元でメモ）、第2部で「前回伺ったこと」として整理して確認 |
| 4 | 業種別ページが全業種並び、自社と関係ないページが多い | 本編は「全業種共通の効果」＋「8業種の一覧表」。業種別の詳細は付録 |
| 5 | 事例が支援内容の直前に置かれ、根拠として使われていない | 「貴社での進め方」の直後に置き、**進め方との対応**を示す |
| 6 | 章番号の飛び・重複 | 第1部・第2部それぞれで通し番号 |
| 7 | 営業KPIの一人当たり件数の誤り（5／7.5／14件） | 10／7.5／約9.3件に修正 |
| 8 | 料金表が3種類混在、立米単価とチラシ料金が合わない | 料金表を1つに統一し、箱数・立米を併記 |
| 9 | 1年目の営業利益が内訳と合わない（記載106万円、内訳合計586万円） | 全経費の内訳を表示し合計と一致させる（要確認） |
| 10 | 準備期間を考慮していない1年目売上 | 1年目は月ごとの立ち上がりで表示 |
| 11 | 回収計画に支援費用が入っていない | 投資総額と回収の見通しを1枚で表示 |
| 12 | 「100%合法」の断定、法改正の出典なし | 前提条件と自治体確認を明記、出典を明記 |
| 13 | 仲介手数料を「両手6%」で概算 | 法定上限で計算 |
| 14 | 不動産相談件数の計算ずれ（120件×5〜10%を5〜10件） | 6〜12件に修正（付録） |
| 15 | 広告費の数字が3種類 | 時期別の広告予算として1枚に整理 |
| 16 | 現場品質の説明がない | 「現場品質の仕組み」を追加 |
| 17 | 誤字・未完成ページ・業種違いの画像 | 全ページ見直し、1ページ1メッセージ |
