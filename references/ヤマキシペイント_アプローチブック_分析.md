### 説得の流れ
**問題（家は劣化する・放置すると高くつく）→ 不安（業者選びで失敗する）→ 判断基準（6つの指標）→ 当社はそれを満たす（サービス・塗料・実績）→ 安心の流れ（工程）**

市民講座の「教育 → 判断基準 → 行動」とほぼ同じ骨組みを、**営業が1対1で読み合わせる冊子**にしたもの。

## 2. ページ別の内容

### B. なぜ塗装工事をしなければならないのか？（p2–7）
| p | 内容 |
|---|---|
| 2 | 劣化が進むと家の内部まで傷み、地震に弱くなり、雨漏りする。「新築から何年で塗装」という決まりや車検のような制度はないので、定期的なメンテナンスが必要。昔から「10年」「14〜15年」と言われるが、正しくは**家の状況によって塗り替え時期は変わる**。2,000万〜3,000万円かけて建てた家の資産価値を守る。塗装の目的は「耐久性を伸ばす」「美観を新築のようにする」の2つ |
| 3 | 放置すると雨水が入り、家の中が腐り、塗装どころか家の改修が必要になる（壁内の腐食・目地の割れ・サイディングの欠けの写真）。「外壁や屋根の劣化を放置することはやめましょう！」 |
| 4 | 「特性」の青いバッジ：①経年劣化でクラック・毛細管現象で水が入りやすい（モルタルの亀裂）②割れやすい・サイディングは反りが出やすい（「反り」「割れ」の赤ラベル） |
| 5 | 特性：サイディングの目地は経年劣化で割れ・ひび・痩せが起こる（目地の写真4枚） |
| 6 | 雨漏りを放置すると躯体が腐る。家のイラストに、窓まわりのシーリング・モルタルの割れ・コーキングの割れ・雨樋のつまり・チョーキング・カラーベストの割れ・屋根と外壁の接続部。「このような症状がある時は早期に解決が必要です」 |
| 7 | 傷みすぎると塗っても塗料がすぐはがれる（外壁材がはがれる／カビや藻で腐敗／水を吸って変形／チョーキングで密着しない）。**その場合は塗装をお断りし、サイディング工事（上貼り）になり、費用は塗装の約2〜3倍**。例：当社の外壁パック比較（下の表）。「外壁や屋根の劣化を放置すると結局高くつきます！」 |

**p7 の価格パック（この冊子で唯一の価格情報）**
| パック | 商品 | 価格（税込） | 条件 | 耐久年数 |
|---|---|---|---|---|
| プレミアムシリコン（ラジカル）塗装パック「低価格と耐久性を求める方に人気」 | エスケー化研「エスケープレミアムシリコン」 | **54.8万円**（税抜498,182円） | 外壁100㎡・足場代込・10年保証・高圧洗浄 | 15〜17年 |
| 外壁サイディングパック「超高耐久！塗装ができない傷んだ外壁にも対応！」 | KMEW「はる一番」 | **148万円〜**（税抜1,345,454円〜） | 外壁100㎡・足場代込・10年保証・高圧洗浄 | 20〜30年 |

→ 148 ÷ 54.8 ≒ **2.7倍**。1年あたりにすると、塗装は約3.4万円（54.8万円 ÷ 16年）、サイディングは約5.9万円（148万円 ÷ 25年）。「早めに塗装したほうが安い」という主張は、この数字でも裏付けられる。
→ 外壁100㎡で54.8万円（足場込み）は、市民講座の「30坪で100〜150万円」よりかなり安い。市民講座の金額は屋根なども含むと考えられ、**含む範囲を明記しないと金額の比較ができない**ことがここでもわかる。

### C. 塗装会社選びに失敗すると…（p8–11）
| p | 内容 |
|---|---|
| 8 | 「とにかく安いところでいいのでは？」→「決してそんなことはありません。安いには安いなりの理由とリスクがある」。お客様の悩みの統計（住宅リフォーム推進協議会 H30）：適正価格がわからない／施工がしっかり行われるか／どの業者を選べばよいか／何を比べればよいか。**市民講座 p16 と同じグラフ・同じ文章** |
| 9 | 激安店の足場（踏板がない単管足場）vs 自社（踏板付きの足場）。「労働基準監督署に通報されたら足場を解体しないといけない」。建設業の労働災害の円グラフ（墜落・転落34％など、16,268人）。「足場の設置を正しく行わないと、不慮の事故につながる!?」 |
| 10 | 「外壁塗装の質は職人の意識と技術による。安すぎる金額は手抜きを誘発する。当社は適正な金額を職人に払うことで品質を担保」。比較3組：シーリング（ムラ vs 打ち替え）／下塗り（下地が透ける vs ムラなし）／希釈率（守らない vs 秤で調合） |
| 11 | 「会社選びに失敗して困るのはお客様」。比較2組：手抜き塗装で数年後にはがれた vs 乾燥時間をとって上塗り／乾燥時間が短くはがれた vs 3回塗りできれい。「施工不良が発生しないように、適切な会社選びをしましょう！」 |

### D. 安心して任せられる塗装会社の選び方（p12–15）
p12 で6つの指標を緑の箱で示し、「価格も大事だが、価格だけで選ぶと塗装工事は必ず失敗する」。p13–15 で1つずつ解説。

| 指標 | 解説 | 当社の主張 |
|---|---|---|
| 現場調査の質 | 調査でやること：①劣化の診断 ②施工方法の選定 ③塗料の選定。図面だけで見積はできない | **現場調査に約1時間30分かける** |
| ショールームがある | 会社の所在地がはっきりしているので、手抜きや見積以上の請求がない。「絶対に外してはいけないポイント」 | |
| 完工チェック | 最後の確認を丁寧にする業者を選ぶ。プロでもミスはありうる | 完工チェックを徹底 |
| 会社の歴史 | 地域密着でも、創業数年の会社もある。家と会社の距離が近いほどアフターが早い | **創業120年以上** |
| 連帯工事保証 | 口約束ではなく保証書を確認。元請けだけでなく、**実際に工事をした施工業者も責任を負い、施工業者が対応できないときは元請けも連帯して責任を負う**「連帯工事保証」を出す会社を選ぶ | |
| 実績 | ホームページで実績を必ず確認。「保証10年でも、その会社が10年後にあるとは限らない」。確認すべきは：**売上（50億円以上なら安心）／創業年数（50年以上なら安心）／利益を公開しているか** | |

### E. 当社のサービス（p16–17）
- p16 **近隣挨拶はおまかせ**：お客様に代わって、教育を受けた担当者が会社・工期・工程・ご迷惑をかける可能性を説明する。近隣トラブルを防ぐ。
- p17 **職人マナー8か条**（赤い見出しの8つの箱）
  1. 施工管理も責任担当（下請けに丸投げしない）
  2. 安心養生
  3. 本日の作業報告（施工日記）
  4. お茶菓子不要（心付けも遠慮）

  6. 整理整頓・清掃
  7. 工事の過程を逐一撮影（工事後に「ご報告書」で提出）
  8. 工期厳守

## 4. 中身の読み解き

### 他の資料との共通点（業界の「型」）
- **劣化の特性ページ**（クラック・毛細管現象／反り・割れ／目地の割れ・痩せ、青い「特性」バッジ）は**市民講座の p24–26 とほぼ同じ文と写真**。
- **お客様の悩みの統計**（住宅リフォーム推進協議会 H30）も**市民講座の p16 と同じグラフ**。
- 冒頭の壁内の腐食・目地・サイディングの写真も市民講座 p21 と同じ。
→ 塗装業界向けに共有されているひな型（同じ素材集）から作られていると考えられる。**統計が平成30年のまま古い点も同じ**なので、ひな型の側を一度更新すれば、すべての資料に反映できる。

### この冊子ならではの強み
1. **「放置すると高くつく」を自社の価格で示している**（54.8万円 vs 148万円〜）。抽象的な「早めに」より説得力がある。
2. **会社選びの基準を、自社が有利な指標にしている**：創業120年以上・ショールーム・連帯工事保証・売上50億円以上など、新しい会社や小さな会社が満たしにくい基準を「安心の基準」として示している。
3. **生活の不安を先回りして消す**：近隣挨拶の代行、お茶菓子不要、禁煙、毎日の作業報告。お客様が工事中に気をつかう場面を具体的に挙げている。
4. **現場調査の約束につなげやすい**：「図面だけで見積はできない」「調査に1時間30分」と書いてあり、次の行動（現場調査）が自然に決まる。

## 5. 問題点・直したほうがよい箇所

### 重大（信頼や法律に関わるもの）
| 場所 | 内容 |
|---|---|
| p10・p11 | **「自社の場合」として載せている写真の一部が、他社のサイトやGoogleの画像検索の結果から持ってきた画像**。画像に残っている説明文（代替テキスト）に「〇〇の画像検索結果」「関連画像」、他社のサイトのURL（個人のホームページやブログ）が入っている。「自社の場合」と書いて他社の写真を使うのは、**お客様に誤解を与える表示**になり、**著作権**の問題もある。必ず自社の現場写真に差し替える |
| p9 | 足場の写真も画像検索の結果。円グラフ（建設業の労働災害）には出典がない |
| 全ページのフッター | 「**富山市**地域の屋根・外壁を…」。施工実績は石川県（野々市市・小松市）。**別の地域・別の会社のひな型の文言が残っている**可能性が高い。対応エリアに合わせて直す |
| p1・p25 | 表紙と裏表紙に**会社名のロゴしかない**。冊子のタイトル、住所、電話番号、ショールームの場所、ホームページがどこにも書かれていない。置いていく冊子なのに連絡先がない |

## 6. 改善した構成の案（A4冊子のまま）
1. 表紙（タイトル「失敗しない外壁・屋根塗装のための安心ブック」など＋会社名＋連絡先）
2. ごあいさつと会社概要（創業120年・ショールーム・対応エリア・許可・資格・保険）
3–7. なぜ塗装が必要か（今の内容。統計と劣化の写真は自社の現場のものに）
8. 放置すると高くつく（パックの価格比較＋1年あたりの費用）
9–11. 業者選びで失敗しないために（自社の現場写真だけで「良い施工・悪い施工」を説明）
12–15. 安心できる会社の選び方（6つの指標＋**当社の場合**を各指標の横に明記）
16–17. 近隣挨拶・職人マナー
18–19. 塗料の選び方（表の誤りを直す）
20–21. 施工実績（お客様の声を添えて）
22–24. 塗装工事の流れ（塗装用のスケジュール、アスベスト調査を追加）
25. 保証とアフターサービス（連帯工事保証の中身）
26. 裏表紙：無料現場調査のご案内（電話・QRコード・ショールームの地図）

## 7. 他の資料にも使える型
- **「放置すると高くつく」ページの型**：塗装パック vs 張替えパックを、同じ条件（面積・足場・保証・洗浄）で並べ、価格と耐久年数を比べる
- **「VS」比較の型**：左に悪い例、右に自社、下に一言の説明（**写真は必ず自社のもの**）
- **選び方の指標の型**：指標を6つの箱で一覧 → 1つずつ「なぜ大事か」→「当社では〜」
- **マナー8か条の型**：番号付きの赤い見出し＋短い説明＋アイコン（禁煙・お茶菓子不要）
- **12ステップのスケジュールの型**：キャラクター付きの番号カードと日付の記入欄で、お客様と一緒に予定を書き込める
