### D. 足場工事：法改正対応について（p20）
- 労働安全衛生規則の改正で、2024年4月から幅1m以上の場所では「一側足場」ではなく「本足場」が原則義務になった。
- 厚生労働省の資料（第152回安全衛生分科会の資料）をそのまま貼っている：①一側足場を使える範囲の明確化 ②足場の点検者の指名の義務化 ③点検の記録に点検者の名前を追加。

### I. 差別化（p31–33）
- p31 **ワンストップサービス**：相談 → 現地調査 → 提案書 → 見積り作成 → 商談 → 色合わせ → 材料発注 → 施工管理 → 完工まで、**同じ担当者がずっと対応**。大手や小規模の他社は工程ごとに担当が替わる（担当A→B→C→A→D）ので、お客様の希望がずれやすい（「決して否定ではございませんが一般的な傾向です」と添えている）
- p32 **地域密着店の強み**：同じ石川県でも地域・気候・風・劣化の速さが違うので、独自の下地補修工法で数年後に差が出る。下塗り材も補修材も1種類ではない。「一流メーカー塗料 約100種以上！」「組合せ無限大!!!」「お客様の最適がここにある!!!!」（ギザギザの吹き出し）
- p33 **まとめ（比較表）**
  - 外壁王：相談から完工まで担当できる担当者制度／地域に特化した職人の気づきと補修力／施工管理システムでずっと記録を残す／**こだわりや強みを消さないので、価格は多少高い**
  - 大手：全国統一のマニュアルに沿う施工力、オリジナル塗料で特別感、スケールメリットで安い／小規模店：低コストで安い
  - 「どの会社であっても外壁修繕＝資産を守ることに変わりはない。お客様が一番納得し、安心できる会社で施工するのが一番です」

- p34 **外壁会社の差が出る箇所＝下地処理**：マスチック工法・シーリング工法・セメント工法・ポリエステルパテ工法の写真。「塗膜を長持ちさせる下作業の施工力がいちばん大事」。「※ただし、同じデザインにはならないことをご理解いただいています」（補修した部分は元の柄が消える、という注意）。左官補修の動画のQRコード

## 4. 中身の読み解き（専門的な見方）

### この家の状態（写真から読み取れること）
- **外壁**：窯業系サイディングの表面の層がはがれて、灰色の素地が出ている（p10・p11・p15）。北陸のように雨と雪が多く、冬に凍ったりとけたりをくり返す地域でよく起きる**凍害**の典型的な症状。塗膜の劣化というより、**サイディング板そのものが水を吸って傷んでいる**状態。
  → だから「はじめに」で「水を含ませずに通気をとることが大事」と書き、p23–24 の「7工程」（素地を固める下地材 → 左官で形を戻す → 防水の厚みをつける）で、**ただ塗るだけでは直らない**ことを説明している。筋の通った組み立て。
- **コーキング**：目地の痩せ・すき間。打ち替えが必要な状態。
- **付帯部**：屋根の上にある壁の天端（笠木・破風）の塗膜が大きくはがれている。雨樋の支持金具に錆。
- **屋根**：金属の縦葺き屋根（雪止め付き）で、色あせと塗膜の劣化。錆が広がる前の段階。→ 板金用の錆止め（SKマイルドボーセイ）＋屋根の遮熱塗料のプランにつながる。

### 営業の工夫として学べる点
1. **ほめてから指摘する**（p8「大切に住まわれていることが伝わります」）
2. **部位の名前の図**（p9）で、見積書を読めるようにしてから明細を見せる
3. **チェック表**（p7）で、相見積もりの相手を自社の基準で比べさせる

5. **他社を否定しない言い方**を添える（p31「決して否定ではございません」、p33「どの会社でも資産を守ることに変わりはない」）

### 中身として足りないもの
| 足りないもの | 理由 |
|---|---|
| **外壁のプラン名** | 板金部・屋根・アルミサイディングのプランはあるが、**外壁の塗装に使う塗料の名前がどこにもない**（p3の保証書の見本にエスケー プレミアムシリコンがあるだけ）。外壁は塗装なのか、アルミサイディングの重ね張りなのか、面ごとに分けるのかをはっきりさせる |
| 現状写真の説明 | p10–19 は写真だけで、**何が起きていて、放っておくとどうなるか**の説明がない。1枚ごとに「症状 → 原因 → 対処」を一言入れる（例：「表面の層がはがれている＝凍害。塗るだけでは直らないため、7工程の下地補修が必要」） |
| 写真と見積の対応 | p9 の部位の名前の図と、現状写真・見積明細の項目が結びついていない。写真に部位の名前（破風・笠木・水切りなど）を書き込むと、見積書が読みやすくなる |
| 工期・工程表 | チェック表で「工期が明確か」を聞いているのに、提案書の中に工期の見込みがない |
| この工事の保証内容 | 保証書は見本だけ。この家の工事で何年保証になるのかを書く |
| アスベストの事前調査 | 2023年10月から、改修工事の前の有資格者による事前調査が義務。提案書に一言入れる |
| 色の提案 | ワンストップの流れに「色合わせ」があるが、提案書の中にカラーシミュレーションがない |
| ページの順番 | 会社の話（理由①〜⑥）が7ページ続いてから、やっとお客様の家の話になる。**お客様の家の診断を先に**、会社の信頼はその後、のほうが「自分のための提案」に感じてもらいやすい |

## 7. 他の資料にも使える型（テンプレートとして抜き出せるもの）
- **「選ばれる理由」の型**：理由の見出し → 一文の主張（オレンジ）→ 補足（黒）→ 証拠の画像（許可票・資格証・保険・写真）
- **「現状」ページの型**：黄色のラベル「現状（部位）」＋写真2枚＋赤枠
- **チェック表の型**：区分（会社・営業マン・見積もり・施工）× 自社／B社／C社 × 合計
- **工程の型**：写真を矢印でつなぎ、「ここまでが当社独自」「ここからやっと3回塗り」と区切る
- **比較まとめの型**：左に自社の特徴、右に他社の特徴、最後に「どの会社でも大切なのは〜。一番納得できる会社で」と中立の言葉で締める
