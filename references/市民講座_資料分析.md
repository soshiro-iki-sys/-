# 「安心・安全な塗装工事をするための市民講座」資料 分析ノート

元資料：PowerPoint 書き出しPDF（71ページ／780×540pt＝**4:3**／作成者 Jelly You）
主催：一般社団法人 全国外壁屋根協議会（JWRC）× サポート企業：（株）住まいるペイント
用途：一般市民向けの**無料セミナー（市民の窓口講座）＝集客型の営業セミナー**。最後は無料相談会につなげる設計。

本講座の中身の深掘り（専門知識の裏付け・情報の更新・想定問答）は [本講座_深掘り学習.md](./本講座_深掘り学習.md) を参照。

このノートは、同じ型の資料（別地域・別加盟店向けの市民講座、塗装・リフォーム系のセミナー資料など）を作るときの設計図として使う。

### 説得の流れ（なぜこの順番なのか）
1. **権威**：社団法人・認定制度・表彰（ASTEC ゴールド加盟店／施工実績No.1）で「中立で信頼できる講座」という印象を作る
2. **共感**：公的統計（住宅リフォーム推進協議会・住宅リフォーム紛争処理センター）で「みんな同じ悩みを持っている」と示す
3. **危機感**：劣化写真を大量に見せて「自分の家も危ないかも」と思わせる
4. **教育**：正しい工程（足場→洗浄→養生→下地→シーリング→3回塗り→付帯部→検査）を見せ、見分ける目を持たせる
5. **落とし穴**：坪数見積のトリック、悪い見積書の例 → 「安い業者は危ない」
6. **基準の提示**：良い会社の14条件 → 主催の加盟店がすべて満たす形にしている
7. **行動喚起**：「まず一度は外壁・屋根の“健康診断”を」→ 無料相談会・現地診断へ

## 3. デザインシステム

### 3-1. パートA「市民の窓口講座」テンプレ（暗め・写真背景）
- **背景**：ぼかした青空と都市の写真（ターコイズ〜ティール系のグラデーション）
- **装飾**：右上から左下へ走る**半透明の斜めストライプ**（ピンク→ラベンダー→オレンジのグラデーション）。中扉には**ピンク→オレンジのグラデーション三角形**
- **コンテンツ面**：上下に暗いティールの帯、中央に半透明の白いパネル（すりガラス風）
- **ロゴ**：右下に常に「市民の窓口講座」ロゴ（濃紺 `#1D2088` の枠＋白地に黒字、下に「講 座」の帯）
- **中扉の書式**：白い太字タイトル（ドロップシャドウ）＋小さな赤い▼＋細いフォントで字間を大きく空けた「P r o g r a m 1」
- **タイムライン**：白い横線、白縁の赤い丸、赤い▲、青いバー（`#5B9BD5` 系）で時間を表示
- **見出しフォント**：HG創英角ゴシックUB 系（字間を広めに）。本文は Meiryo／Yu Gothic

**中扉（01〜05）**：白背景、中央に黒い家のアイコン＋大きな「01」＋細い下線、その下に黒の極太で章タイトル。装飾はほとんどない。

**写真の見せ方の決まり**
- 劣化部分は**赤い楕円**で囲む（破線＝インパクト重視、実線＝ピンポイント）
- 6枚の写真を3×2のグリッドで並べ、それぞれに「●〇〇の劣化」というキャプション
- 工程の写真は青いヘッダー付きのカード（`#2E75B6` 系、「① 現状」など）を灰色の **»** でつなぐ
- Before／After は赤いラベル＋赤い曲がり矢印
- 写真に赤いラベル（白文字）を直接重ねる（「反り」「割れ」）

**図解のパターン**
- 「特性」の青い丸バッジ＋箇条書き（キーワードだけ青文字）

## 4. 文章・言い回しの特徴
- 呼びかけ口調：「〜しましょう」「〜してください」「〜が大切です！」と感嘆符が多い
- 疑問形の見出しで興味を引く：「なぜ、セミナーを開催するのか？」「ベストな塗り替えの時期とは？」「良い会社ってどんな会社ですか？」
- 〜波線〜 で小見出しを挟む：「〜業者選びのポイント〜」「〜結論〜」「〜さいごに〜」
- ◆・●・□・①〜⑭ などの記号を使い分ける（◆＝悩み・ポイント、●＝写真キャプション、□＝チェックリスト、丸数字＝条件や手順）
- 数字で具体化：築8〜10年、30坪で100〜150万円、10年＋10年 vs 25年、150.2㎡ vs 150.6㎡
- 出典を明記（URL付き）して客観性を出す
- お客様の不安を「」で代弁する：「一番価格が安い業者に頼みたい・・・。」
