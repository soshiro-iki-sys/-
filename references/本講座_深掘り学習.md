# 本講座（p12–62）深掘り学習ノート

対象：「失敗しない外壁塗装 屋根工事をするための市民講座」（JWRC × 住まいるペイント）の本講座パート
前提ノート：[市民講座_資料分析.md](./市民講座_資料分析.md)（全体の構成・デザイン・ページ一覧）

このノートでは、本講座の各章について次の5点を整理する。
1. **狙い**：その章で受講者の気持ちをどう動かすか
2. **伝えるべき要点**：講師が必ず口にすべきこと
3. **専門知識の裏付け**：スライドに書かれていない「なぜそうなのか」
4. **事実確認・情報の更新**：2026年時点で古い・不正確・誤解を招く箇所
5. **改善案**：差し替え・追加したいスライド

調べた日：2026年10月2日。出典はノートの最後にまとめた。

## 0. 本講座の骨組み（一言で言うと）

> **「塗装の失敗は、悪徳業者よりも“普通の業者の知識不足と診断ミス”で起きる。だから、診断・見積・契約の中身で業者を選びましょう」**

| 章 | 受講者の気持ちの変化 | 決めの一言（スライドから） |
|---|---|---|
| 1. 開催経緯と目的 | 「自分だけじゃない、みんな不安なんだ」 | 外壁・屋根のメンテナンスにおける業者選びは必須！ |
| 2. 基礎知識 | 「うちの家も劣化しているかも」「工事ってこんなに手順があるのか」 | チョーキングが防水切れの目安／塗り替え目安 築8〜10年 |
| 3. 失敗しない3つのポイント | 「普通の業者でも失敗するのか」「見積は坪数じゃないのか」 | 資格者がいて施工実績の多い会社に依頼する |
| 4. 業者選び | 「価格だけで選んではいけない」「見積書・契約書を見ればわかる」 | 「良い業者」を選定し、工事を行うことが大切です！ |
| 5. 質疑応答 | 「この人に相談してみよう」 | （→ まとめ講座・無料相談会へ） |

**注意**：タイトルに「3つのポイント」とあるが、スライド上の小見出しは (1)塗装工事を成功させるための道のり と (2)劣化度合いによって何年持たせたいかを決める の**2つしかない**。3つ目は「結論：資格者がいて施工実績の多い会社に依頼する」（p53）と読めるが、はっきりしない。講師が口頭で3つを言えるようにするか、スライドに (3) を立てる必要がある（案は第3章の改善案を参照）。

## 第1章 本勉強会の開催経緯と目的（p14–18）

### 狙い
講師がいきなり売り込むのではなく、「公的な統計」と「地域の声」を根拠に**中立の立場から**話す、という構えを作る。

### 伝えるべき要点
- 自己紹介（p15）は本文が空欄。**話す内容を決めておく**：塗装歴（平成7年開業）、屋根から転落した経験（安全への思いにつながる）、建築会社での営業・監督の経験、保有資格。
- p16：リフォーム前の不安の上位は「適正価格がわからない」「施工が適正に行われるか」「業者選び・手続きが面倒」「業者の特徴を比較しにくい」。

- p18：地域から届いている4つの悩み → この講座で順番に答える、と予告する。

## 第2章 絶対に知っておきたい外壁・屋根の基礎知識（p19–42）

### 2-(1) 外壁・屋根は劣化する（p20–28）

#### 狙い
写真を次々に見せて「うちも同じかもしれない」と思わせる。そのうえで、**自分で確かめられる見分け方**（チョーキング、ひび割れ、目地）を持ち帰ってもらう。

#### 専門知識の裏付け（講師が説明できるようにしておくこと）
| テーマ | スライドの表現 | 裏付けとなる仕組み |
|---|---|---|
| 塗膜の構造（p20） | 樹脂・顔料・添加剤 | 塗料は「樹脂（膜を作り、守る）」「顔料（色）」「添加剤（性能の調整）」でできている。**耐用年数を決めるのは樹脂の種類**（アクリル・ウレタン・シリコン・フッ素・無機）。ここが p52 の塗料性能比較表への伏線になる |
| チョーキング（p20） | 防水切れの目安 | 紫外線で樹脂が分解し、顔料が粉になって表面に出てくる現象。手でこすると白い粉が付く。**塗膜の守る力が落ち始めたサイン**であり、すぐに雨漏りするわけではない。「すぐ工事しないと危ない」とあおらない言い方にする |
| クラック（p24） | 毛細管現象で水が入りやすい | 細いすき間ほど水が吸い込まれる。幅0.3mm以上・深さ4mm以上は「構造クラック」とされ、塗装の前に補修（Uカット＋シーリングなど）が必要、と言われることが多い。p46 のクラックスケールの写真とつなげる |
| 反り・割れ（p25） | サイディングは反りが出やすい | 窯業系サイディングはセメント質なので、塗膜が切れて水を吸うと、乾くときに反ったり割れたりする。**反りが大きいと塗装では直せず、張替えになる** → 第3章 (2) の「張替え・上張り」の話の伏線 |
| 目地（p26–27） | 可塑剤が入っている／紫外線に弱く硬化する | シーリング材にはやわらかさを保つ「可塑剤」が入っている。年月がたつと可塑剤が抜けて（ブリード）硬くなり、建物の動き（膨張・収縮）についていけずに割れる・痩せる。塗装の上に可塑剤がしみ出て黒く汚れることもあるため、**ノンブリードタイプ**のシーリング材を使うかどうかも業者を見分けるポイント |
| 塗り替え時期（p28） | 初回 8〜10年／2回目以降 11〜15年 | 新築時の塗料はグレードが低いことが多いので初回は早め、2回目以降は選んだ塗料の耐用年数に左右される、という説明にすると筋が通る |

#### 事実確認・注意点
- p22・p23・p65–68 の劣化写真には、**北海道寄りの事例**（凍害・スガ漏れ）が混ざっている（まとめ講座側）。練馬区・杉並区・中野区の受講者向けには、**東京の気候で起きやすいもの（チョーキング、カビ・コケ、目地の痩せ、金属部の錆）を中心**に見せる。
- p24 の家のイラストに「17」というページ番号が残っている。
- p26 の「経年劣化\nで」の改行を直す。

### 2-(2) 塗装工事の流れ（p29–42）

#### 狙い
正しい工程をすべて見せることで、**「この工程を省く業者は危ない」と判断できる目**を受講者に持たせる。

#### 工程ごとの「手抜きされやすいポイント」（講師が口頭で補う）
| 工程 | スライド | 手抜きされやすいポイント・確認方法 |
|---|---|---|
| 足場（p29） | しっかりした足場と飛散防止ネット | **2024年4月から、幅1m以上の場所では原則「本足場」（支柱が2列の足場）が義務**になった（労働安全衛生規則の改正）。安い見積の中に、法令に合わない一側足場（支柱1列）が入っていないか |
| 高圧洗浄（p30） | 頑固な汚れを洗浄 | 洗浄のあと**十分に乾かしたか**（目安は1日以上）。乾く前に塗ると、はがれの原因になる |
| 養生（p31） | 近隣・車・窓を守る | 仕上がりと近隣トラブルに直結する |
| 下地処理（p32） | 補修・釘打ち・ケレン | **塗装後の「はがれ」の多くは下地処理不足が原因**。工事中の写真を出してもらう約束をする（p60 ②「施工中写真」） |
| シーリング打ち替え（p33–34） | ① 現状 → ② 撤去 → ③ プライマー → ④ 充填 → ⑤ ヘラならし → ⑥ 仕上げ | 古いシーリングを**全部撤去したか**、**プライマーを塗ったか**（塗らないと早くはがれる） |
| シーリング増し打ち（p35–36） | サッシまわり等 | 増し打ちは、古いシーリングの上に足すので厚みが取りにくい。サッシまわりは撤去するとサッシや防水シートを傷めるおそれがあるため、増し打ちを選ぶことがある |
| 下塗り（p37） | 密着性を高める | 外壁材や劣化の状態に合った下塗り材を選んでいるか（シーラー・フィラー・微弾性フィラーなど）。見積書に**製品名**が書いてあるか |
| 中塗り・上塗り（p38–39） | 3回塗りで艶と耐久性 | **塗料メーカーが決めた塗布量（㎡あたり何kg）と、塗り重ねの間隔**を守っているか。中塗りと上塗りで色を少し変えてもらうと、2回塗ったことが確認できる |
| 付帯部（p40） | 軒天・雨樋・帯板など | 見積書に付帯部が**部位ごとに書かれているか**（「付帯部一式」は要注意） |
| 仕上がり確認（p41） | 社内検査 → 施主立ち会いの検査 | 保証書の発行と、点検の時期（1年・3年・5年など）をここで確認する |

#### 要注意：p36 の「2面接着／3面接着」の図の置き場所
- **2面接着**（底にバックアップ材やボンドブレーカーを入れて、シーリングを両側の2面だけにくっつける）は、**動きの大きい目地（ワーキングジョイント）＝サイディングの目地**のための考え方。つまり**打ち替え工法**の話。
- ところが資料では、この図が**増し打ち工法（サッシまわり）**のページに載っている。サッシまわりのように動きの小さい目地（ノンワーキングジョイント）は、3面接着でも問題ないことが多い。
- このままだと「増し打ちは2面接着だから良い」と誤解される。→ **図を打ち替え工法のページ（p33–34の後）に移す**のが正しい。

#### p42 お化粧のたとえ
専門用語を身近にする良いスライド。受講者に女性が多い場合は特に効く。「下地処理を省いた化粧は崩れる＝下地処理を省いた塗装ははがれる」と一言でまとめる。

#### 追加したいスライド（法令の変化）
- **アスベストの事前調査**：大気汚染防止法の改正で、改修工事（外壁塗装の下地処理や高圧洗浄も含む）の前にアスベストの事前調査が義務になった。**2023年10月からは「建築物石綿含有建材調査者」などの有資格者による調査が必要**。一定の規模以上の工事は自治体への報告も必要。古い家の仕上塗材や屋根材にはアスベストを含むものがあるため、「事前調査の話をしてくれる業者か」は業者を見分ける新しいポイントになる。

## 第3章 意外な落とし穴？！失敗しない工事3つのポイント（p43–53）

### 3-(1) 塗装工事を成功させるための道のり（p44–48）

#### p44 11ステップの工程カード
- 「いつまでに終えたいか → 逆算してスケジュールを組む」がこのスライドの核。受講者に**実際に日付を書き込んでもらうワークシート**として配布すると、講座の後の相談につながる。
- 番号「2」が重複している（現場調査・診断／ご要望お伺い）。3 に直す。
- 今の時代に合わせて追加したい工程：**アスベスト事前調査**（ステップ2の現場調査と一緒に行う）。

#### p45 ピラミッド（本講座でいちばん大事な考え方）
- 頂点：悪徳業者・手抜き工事（数は少ないが目立つ）
- 中段：施工前の診断ミス
- 底辺：施工業者の知識不足、勝手な解釈・思い込み（**いちばん多い**）
- 伝え方：「悪徳業者を避けるだけでは足りません。**ふつうの業者でも、診断を間違えれば失敗します**」。ここから「診断力のある業者を選ぶ」→「外壁診断士」「現場調査のチェックリスト」へ自然につなげる。

#### p46 現場調査のチェックリスト
写真に写っているのは、チョーキングの確認（指に付いた白い粉）、クラックスケール（ひび割れの幅を測る定規）、含水率計（外壁が水を含んでいる量を測る機械）、写真付きの診断書。**「この道具を使っていますか？」と業者に聞けばよい**、と具体的に伝える。

#### p47–48 坪数の落とし穴
- p47：35坪と40坪で値段が違っても、外壁の面積は同じ（凹凸の形が違うだけ）。
- p48：35坪＝外壁150.2㎡、42坪＝外壁150.6㎡。**床面積が7坪（約23㎡）違っても、外壁の面積はほぼ同じ**。
- 裏付け：よく使われる簡単な計算は「延床面積 × 係数（1.2前後）＝外壁面積」。この式だと 35坪（約115.7㎡）→約139㎡、42坪（約138.8㎡）→約167㎡ となり、**約28㎡もの差が出てしまう**。p48 の実例は、「坪数に係数をかけるだけの見積は不正確」ということをそのまま示している。
- 外壁の面積を左右するのは、**窓の大きさと数、バルコニーの有無、軒の高さ（家の高さ）、家の形の凹凸**。
- 受講者が持ち帰るべき行動：「見積書の外壁面積（㎡）が、**図面か実際の測定**で出された数字かを聞く」。

### 3-(2) 劣化度合いによって何年持たせたいかを決める（p49–52）

#### 狙い
「安い塗装をくり返す」か「一度にしっかり直す」かを、**ライフプラン（あと何年住むか）**で決めてもらう。

#### 伝え方の注意
- p49 の「10年＋10年 vs 張替え・上張り25年」は、数字の比べ方として雑。**1年あたりの費用 ＝ 工事費 ÷ 持つ年数** という式を見せて、自社の実際の金額で計算した例を出すほうが説得力がある。
- 「あと10年で建て替える・住み替える」家に高い無機塗料や張替えを勧めるのは逆効果。**持たせたい年数が短いなら、安い工法でよい**とはっきり言うと、中立の講座としての信頼が上がる。

#### p52 塗料性能比較表（プレースホルダー）を埋める案
一般的によく示される目安。**メーカー・製品・立地によって変わる**ため、最終的には自社で扱う製品のカタログ値に差し替える。

| 塗料の種類（樹脂） | 耐用年数の目安 | ㎡単価の目安 | 特徴 |
|---|---|---|---|
| アクリル | 5〜7年 | 1,400〜1,600円 | 安いが長持ちしない。今の外壁塗装ではほとんど使われない |
| ウレタン | 8〜10年 | 1,700〜2,200円 | やわらかく付帯部向き |
| シリコン | 10〜15年 | 2,300〜3,000円 | 価格と耐久性のバランスがよく、いちばん多く使われる |
| ラジカル制御型 | 12〜15年 | 2,500〜3,000円 | チョーキングの原因になる劣化を抑える |
| フッ素 | 15〜20年 | 3,800〜4,800円 | 耐久性が高い |
| 無機（無機成分を含むもの） | 20〜25年 | 4,500〜5,500円 | もっとも長持ち。価格も高い |

- 加盟店が扱うアステックペイントの「超低汚染リファイン1000MF-IR」（無機成分配合フッ素樹脂・遮熱・低汚染）は、メーカーの促進耐候性試験で**約20〜24年相当**とされている。紹介するなら「試験での相当年数であり、保証年数とは別」と添える。
- 「耐用年数＝保証年数」ではないことを必ず伝える（よくある誤解）。

### 結論（p53）
「施工仕様を把握し最良の施工をするためには、資格者がいて施工実績の多い会社に依頼する」

#### 「3つのポイント」をはっきりさせる案
| ポイント | 中身 | 対応するスライド |
|---|---|---|
| ① 逆算したスケジュールと、正しい診断 | 現場調査のチェックリスト、面積の実測 | p44–48 |
| ② 何年持たせたいかで工法と塗料を選ぶ | ライフプラン、塗料性能比較表 | p49–52 |
| ③ 資格者と実績のある会社に頼む | 結論 | p53 |

## 第4章 業者選びのポイント（p54–61）

### 狙い
「価格だけで選ばない」→「何を見ればよいか（診断・面積・契約書・見積書・保証）」→「良い会社の条件」の順に、**判断のものさし**を渡す。

### p55 適正価格（100〜150万円）について
- スライド：「延床30坪前後・普及品の塗料で、**100〜150万円が適正**」。
- 2025〜2026年の一般的な相場情報では、30坪の外壁塗装（シリコン）は**およそ80〜120万円**、塗料や劣化状態によって50〜140万円程度と幅がある。
- つまり、**スライドの金額は「外壁だけ」としてはやや高め**。「外壁＋屋根」「付帯部・シーリング込み」なのか、**金額に含まれる範囲を書き足す**必要がある。範囲がはっきりしないと、受講者が他社の見積と比べたときに「この講座の業者は高い」と受け取られかねない。
- 費用の内訳（コスト構造）の説明は良い。具体的な割合の例を添えると伝わりやすい：足場代 15〜25万円、塗料代（材料費）、職人の人件費、高圧洗浄・下地処理、諸経費。

### p59 契約書・工程表・保証書（プレースホルダー）を埋める案
| 書類 | 法律・制度上のポイント |
|---|---|
| 工事請負契約書 | **建設業法第19条**で、工事の大きさに関係なく、すべての建設工事で書面での契約が義務になっている（工事内容、請負代金、着工と完成の時期、追加・変更があったときの扱いなど）。「契約書なし・口約束」は法律違反 |
| クーリング・オフ | 訪問販売（業者が家に来て契約した場合など）は、**契約書面を受け取った日から8日以内**なら無条件で解約できる（特定商取引法）。2022年6月からは**メールなど電磁的な方法でも通知できる**。※自分から店舗に出向いて契約した場合などは対象外 |
| 工程表 | 何日に何の工程をするかがわかるもの。手抜き（乾燥時間を取らない、塗る回数を減らす）を防ぐ |
| 保証書 | 保証の範囲（はがれ・ふくれなど）、年数、点検の時期。**会社の保証**と**メーカーの保証**の違い |

### p60 良い会社の14条件 ― 直すところと足すところ
直すところ：
- ⑦「スタッフの顔が**見ている**」→「見えている」
- ⑧「**判例**：サイディングに油性を提案する会社」→「**反例**」。そもそも「サイディングに油性を勧めるのは悪い例」と言い切れるかは製品と状態による。「家の外壁材や状態に合わない塗料を勧める会社」と言い換えるほうが安全
- ⑫「地元業者で地域密着の会社（対応が遅い、アフターが弱い）」→ 括弧の中が逆の意味になっている。「（遠くの業者は対応が遅く、アフターが弱くなりがち）」に直す
- ⑭ コロナ対策 → 外すか、「近隣への配慮・マナー」に差し替える
- 吹き出しのメモ「調整」が①〜③の文字に重なっているので消す

足すとよい条件（2026年時点）：
| 条件 | 理由 |
|---|---|
| **建設業許可**（塗装工事業）を持っている | 請負金額500万円未満（税込）の工事は許可がなくてもできるため、許可のない塗装業者も多い。許可があることは、一定の経営・技術の基準を満たしている目安になる |
| **一級塗装技能士**がいる | 塗装の分野で唯一の**国家資格**（厚生労働省の技能検定）。受験には原則7年以上の実務経験が必要 |
| アスベスト事前調査に対応している | 2023年10月から有資格者による調査が義務 |
| 法令に合った足場を使う | 2024年4月から本足場が原則義務 |

**資格の伝え方の注意**：講師の肩書の「外壁診断士」は、一般社団法人全国住宅外壁診断士協会が認定する**民間資格**（受験には住宅関連の実務5年以上が必要）。受講者から「国家資格ですか？」と聞かれたときに正しく答えられるようにしておく。「診断の専門資格（外壁診断士）」と「施工の国家資格（一級塗装技能士）」の両方がそろっている、と言えるのが理想。

## 第5章 質疑応答（p62）― 想定問答集

| # | 想定される質問 | 答え方のポイント |
|---|---|---|
| 1 | うちは築何年で塗り替えればいい？ | 初回は8〜10年が目安。ただし年数より**状態**（チョーキング・ひび割れ・目地）で判断する。無料の診断を案内する |
| 2 | 訪問してきた業者に「屋根がずれている」と言われた | 国民生活センターに多く寄せられている**点検商法**の典型的な手口。その場で契約しない・屋根に上がらせない。訪問販売での契約なら**8日以内はクーリング・オフ**できる |
| 3 | 火災保険で無料で直せると言われた | **経年劣化は火災保険の対象外**。台風などの自然災害による被害で、原則3年以内の申請が必要。「保険金で自己負担なし」とうたう勧誘はトラブルが多い。保険会社に直接確認するよう伝える |
| 4 | 見積は何社から取ればいい？ | 2〜3社。比べるのは総額ではなく、**外壁の面積（㎡）・塗料の製品名・塗る回数・保証**。条件をそろえて比べる |
| 5 | いちばん長持ちする塗料は？ | 一般には無機・フッ素系。ただし「あと何年住むか」で選ぶ（第3章 (2)）。耐用年数は保証年数ではない |
| 6 | 遮熱塗料は効果がある？ | 屋根では室温の上昇を抑える効果が期待できる。効果は家の断熱や立地によって変わるので、メーカーのデータを見せて説明する |
| 7 | 塗装ではなく張替えが必要なのはどんなとき？ | サイディングの反り・割れが大きい、下地まで傷んでいる、雨漏りしている場合など。p25・p51 の事例で説明する |
| 8 | 工事中は家にいないといけない？窓は開けられる？ | 立ち会いは必須ではない。養生中は窓が開けにくい期間がある。工程表で事前に知らせる |
| 9 | 工期はどのくらい？雨の日は？ | 一般的な戸建で2週間前後。雨の日や湿度が高い日は塗らない（品質のため）ので延びることがある |
| 10 | 近所へのあいさつは？ | 業者が着工前に行う（p44 ステップ7） |
| 11 | 補助金・助成金は使える？ | 自治体によっては、省エネ（遮熱・断熱）などを条件にした助成があることも。**年度や地域で内容が変わる**ので、最新の情報を自治体で確認するよう伝える |
| 12 | アスベストが入っているか心配 | 改修工事の前には有資格者による事前調査が義務。調査をしてくれる業者を選ぶ |
