## 4. ページ内の定型パーツ

### 4-1. セクションラベル（青いタグ）※29/45ページで使用
ヘッダー直下に置く小さな濃紺の長方形。そのページが「何の話か」を1行で示す。

| 項目 | 値 |
|---|---|
| 位置 | x = 0.08in / y = 0.73in |
| サイズ | 幅 2.83in × 高さ 0.32in |
| 塗り | `002060`（枠線なし） |
| 文字 | 16pt 太字 白 中央揃え Meiryo UI |
| 記入例 | `本日の流れ` `電気代の内訳` `再エネ賦課金の上昇` `※補足` `①エネルギー安全保障` |

> 注意：幅が2.83in固定のため、**全角10文字前後まで**。長いと文字がはみ出します。

### 4-2. サブ見出し（■の箇条書き）
ラベルの下（y ≒ 1.05〜1.15in）に、■付きの説明文を1〜3行。16〜18pt 太字 黒。
数字・キーワードだけ `FF0000` で赤くする。

### 4-3. 結論バー（最重要パーツ）※24/45ページで使用
ページの一番下に置く、**そのページの結論を1〜2行で言い切る**濃紺の帯。

| 項目 | 値 |
|---|---|
| 位置 | x = 0（左端）、y = 6.27in 前後 |
| サイズ | 幅 = スライド幅いっぱい（10.83in） × 高さ 0.85〜0.95in |
| 塗り | `002060` |
| 文字 | 20〜24pt 太字 白 中央揃え（2行まで） |
| 強調 | 最重要ワードだけ **32pt・`FFFF00`（黄）** に上げる |
| 記入例 | 「使う量が一緒でも、単価が自然と上がっていくため電気代は必然的に**上昇**しています」 |

> これがこの資料の一番の特徴です。**データを見せる → 下の帯で意味を言い切る**の反復で構成されています。

### 4-4. 出典表記
本文の下、結論バーのすぐ上（y ≒ 5.8in）に、**7〜8pt 太字**で1行。
`出典：経済産業省資源エネルギー庁「〜」（URL）`

### 4-5. 強調の作法
- 画像・グラフの注目箇所を **赤枠（`FF0000`・線幅3pt）の長方形**で囲む
- 上昇/流れは **赤のブロック矢印**（上矢印・右矢印）
- 文字強調は「赤字」＋「サイズを上げる」の2手のみ。下線や斜体は使わない

## 5. ページの型（6パターン）

| 型 | 使い方 | 構成 |
|---|---|---|
| **① 表紙** | 1ページ目 | 全面写真＋白抜き太字タイトル（44〜60pt）＋開催日。ヘッダー・フッターなし |
| **② 問いかけ（全面濃紺）** | 章の切れ目 | スライド全面を `002060` で塗り、白の太字 **54pt** を中央に3行。例：「なぜここまで国は強制的に高性能化を推進するのか・・・」 |
| **③ 大文字メッセージ（白地）** | 掴み・まとめ | 白地に黒の太字 **60〜72pt** を中央に。例：「太陽光・蓄電池は当たり前」 |
| **④ 目次** | 章の前ごとに再掲 | ①②③④ の丸数字＋32pt太字。**これから話す章だけ `FF0000` 赤**にする（現在地の明示） |
| **⑤ データページ**（主力） | 本編 | ラベル → ■サブ見出し → グラフ/図/写真 → 出典 → 結論バー |
| **⑥ 比較・整理ページ** | 本編 | 表（濃紺ヘッダー行＋白背景）、3分割カード、Before/After の2カラム、年表・ロードマップ |

## 6. 全体の流れ（構成テンプレート）

```
1  表紙（全面写真）
2  掴みの一言（大文字メッセージ）
3  自己紹介（顔写真＋実績）
4  本日の流れ（第一講座／第二講座／第三講座の3段カード）
5-6 問題提起（大文字 → 全面濃紺の「なぜ？」）
7  目次
──── 第1章 ────
8-9  感情に訴える写真＋赤い大文字
10-21 データページ（グラフ・地図・ニュース）×多数、各ページに結論バー
22   章のまとめ（全面濃紺の断言）
23   目次（第2章を赤に）
──── 第2章・第3章・第4章 ──── 同じリズムを繰り返す
43   まとめ（グラフ）
44   まとめ（再掲：冒頭の一言をもう一度）
45   ご清聴ありがとうございました
```
